# 기록에서 지도까지: 분할 처리 후보

기준은 f39ff57d566240e8c10c323698d9687b383793ec이다. 이 문서는 구현 중인 후보의 계약이며 배포·전체 수용 선언이 아니다. 기존 PC·Worker·Pages와 원문·키는 그대로 유지한다.

자동 연결은 기존 연결 경로를 사용한다. 붙여 넣기와 연결로 들어온 기록은 같은 지도 계약으로 처리한다. 합성 저장 회귀, 실제 모델 생성, 정상 화면 조작, 연결기 전송은 서로 다른 증거로 기록한다.

## AI 역할과 단계

1. DeepSeek가 원래 구간 별칭을 보존하여 단서를 찾는다. 최대 12구간, 동시에 2개. 조건·철회가 많은 실제 기록 때문에 임의의 12단서 제한을 24개로 조정했다. 원문이나 조건을 잘라 통과시키지 않는다.
2. Sol 6.1 High가 전체 원문과 단서를 대조하여 작은 설계를 만든다. 대상 식별·포함 관계·전역 조건을 결정하고 최종 지도 전체를 출력하지 않는다.
3. DeepSeek가 설계에 고정된 부분을 3개씩 작성한다. 최대 8그룹, 동시에 2개. 이름·부모·키 범위가 다른 그룹을 침범하지 못한다.
4. DeepSeek가 원문과 완성된 부분을 대조하여 관계·미정·요청 대응을 작성한다. 프로그램은 결과를 기계적으로 결합하고 기존 map.6/map.7 근거 검증을 적용한다.

추출 메모와 설계는 근거가 아니다. 마지막 지도는 원래 요청의 별칭만 인용한다. first6와 later7은 원래 각 계약·프롬프트·검증기를 유지하고 서로 다른 처리 판본에 결속한다. 후속 처리에는 현재 주장, 사용자 수정, 요청 snapshot, prior, 기록 출처와 날짜를 전달한다. 기존 map.7의 항목 제외 정책과 화면 고지를 유지하며, 의미 수용에서 중요한 조건이 제외되었는지는 별도로 본다.

전역 검토에 Astra High를 쓸 수 있게 모델 설정은 허용하지만 아직 이 사례에서 Astra·Terra를 실행하거나 우월성을 입증한 것은 아니다. 커뮤니티 후기는 개인 경험으로만 참고했고 세 모델의 직접 품질 비교로 취급하지 않는다. ## 저장·비용·실패

완료 단계는 요청 전체와 처리 판본에 결속하여 PC에 저장한다. 같은 작업 재조회·재전송은 새 생성이 아니다. 취소 후 늦은 결과는 자동 적용하지 않는다. 호출 전 비용 예약을 저장하고 OpenAI 기본 상한은 논리 작업당 1 USD, 월 20 USD이다. DeepSeek 요금은 이 USD 장부 밖이며 교정 포함 작업당 최대 30회로 제한한다. 완료된 부분 작성/전역 응답이 근거·형식 검사에서 거절된 경우에만 원 실패와 사용량을 먼저 보관하고 해당 단계에 교정 요청을 한 번 보낸다. 교정의 재귀 교정, 전송 불명·시간 초과의 자동 재전송, 공급자 fallback은 없다.

정상 거절(400/401/403/404/422/429)은 실행되지 않은 요청으로 구분한다. 응답을 못 받은 호출은 예약을 유지하고 같은 단계의 자동 재전송을 막는다. 사용자 주도 불명 단계 재시도는 이전 비용까지 보수적으로 계산하는 별도 계약이 필요하며, 일반 재클릭이나 자동 연결을 추가 과금 승인으로 해석하지 않는다.

OpenAI 키는 PC 서버만 개인 설정 파일에서 읽는다. 기존 환경값은 빈 문자열까지 우선하며 허용한 설정 키만 읽는다. 키를 브라우저나 공개 묶음으로 보내지 않는다. 이 구현은 Node의 내구 작업 호스트용이고 Worker에 같은 분할 처리를 제공했다고 주장하지 않는다.

## 현재 관측과 남은 판정

- 실제 사용자 기록 11,562 UTF-16자를 원문 그대로 보존하고 4구간으로 나눴다. 이 기록의 읽기 범위는 전체이며, 일반 입력 한도가 사라졌다는 뜻은 아니다.
- 초기 12단서 계약에서 13개·17개를 반환해 실패한 원본을 보존했다. 24단서 계약으로 그대로 재검증했고 조건 삭제 없이 통과했다.
- 처음 시도한 단일 Sol High 최종 통합은 180초 안에 끝나지 않았다. 성공한 추출을 재생했으며 새 추출 성공이나 최종 지도 성공으로 세지 않는다.
- 짧은 새 프로젝트의 실제 호출에서 JSON 출력 설정이 input에도 JSON 표시를 요구하는 결함을 발견하여 수리했다. 명확한 거절과 응답 불명을 구분했다.
- 작은 설계로 역할을 줄인 실제 Sol High는 106.3초에 완료했고 세 부분 작성도 완료됐다. 마지막 응답의 material이 이 프로젝트의 인용 보고를 제외 예시로 오분류하여 검증에서 거절했다. 후속 작성에서는 근거 개수 초과도 발견했다. 모두 원본을 보존하고, 완료된 설계·구간을 재생하며 해당 단계의 원인만 보완한다. 이러한 전달 성공·검증 거절·의미 미수용을 합산해 전체 성공으로 표시하지 않는다.
- 최종 설계·부분 작성 경로의 실제 의미와 정상 화면 검증은 진행 중이다. 작은 자동 검사 통과를 전체 제품 완성으로 해석하지 않는다.

Claude의 독립 설계 검토에서 계획의 완료 승격, 구간 경계의 철회, 끝 미전송, 사용자 수정·판본 보존, 불명 과금 문제를 회수해 반영했다. 내부 Sol High 담당들의 저장·통신·구간 계약과 별도 인수 회귀를 대조한다. 비공개 원문·모델 응답·키·전체 로그는 로컬에만 보관한다.
