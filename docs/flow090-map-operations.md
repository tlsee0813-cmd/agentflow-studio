# FLOW090-B1 — 공간 지도 조작 계약 (후보 `flow090/spatial-workspace`, 부모 `08119678`)

전체 공간은 사용자가 만들 서비스의 영역을 한눈에 보고 배치하는 지도다. AI 실행 노드 편집기가 아니다.

## 데이터와 상태
| 무엇 | 어디 | 바뀌는 때 |
|---|---|---|
| 영역 위치 | `space.layout.positions` (정수 좌표, 버전 `layout.1`, 백업·사본에 보존) | 손잡이 끌기 1회 = 이동 1회. 방향키는 20(Shift 60)씩 움직이고, 1.5초 안에 이어진 같은 영역의 방향키 이동은 1회로 친다. 새 영역은 저장 위치를 받는다 |
| 기본 위치 | 저장 위치가 없는 영역(구형·첫 후보 데이터) | 목록 순서로만 정해진다. 다른 영역의 추가·보관·복원으로 바뀌지 않는다 |
| 새 영역 위치 | 추가 시점 지도 중앙에서 가장 가까운 빈 칸(오른쪽→왼쪽→아래→위 순서) | 보관된 영역의 자리도 비워 둔다(되살리면 원래 자리). 좌표 한계 밖 칸은 건너뛴다(한계로 당겨 겹치지 않음). 다른 영역의 좌표는 건드리지 않는다. 화면 밖이면 보기만 옮긴다 |
| 보기(이동·배율) | 탭별 `agentflow.workspace.map`(프로젝트 ID 포함) | 빈 배경 끌기, ＋/－, 전체 맞춤. 저장 좌표를 바꾸지 않는다. 영역 왕복과 새로고침 뒤 복원된다(작은 배율도 그대로). 저장된 보기가 없으면 첫 진입 때 맞춘다 |
| 선택 | 같은 탭 상태 | 카드 본문 클릭. 짧은 속성 패널(이름·한 줄 구상 반영/취소, 영역 열기, 이 영역에 새 요청)을 연다. 영역을 열거나 현재 작업(`currentTaskId`)·초안 대상을 바꾸지 않는다 |
| 영역 열기 | — | 카드의 ‘영역 열기 ↗’ 한 번(사전 선택 불필요). 끌기 종료는 열기·선택·새 요청이 되지 않는다 |

## 위치 되돌리기 (제한된 Undo)
- 되돌리는 것은 영역 위치 한 칸뿐이다. 버튼에는 ‘위치 되돌리기 · 영역 이름’이라고 표시한다. 이름, 설명, 관계, 요청, 보고, 외부 실행은 되돌리지 않는다.
- 프로젝트 스냅샷을 복구하지 않는다. 현재 프로젝트에 그 위치 필드만 역으로 적용한다. 그 사이 도착한 보고나 다른 수정은 그대로 남는다.
- 그 영역이 그 이동이 놓은 자리에 아직 있을 때만 적용한다. 그 뒤 다시 옮겨졌거나 다른 탭에서 바뀌었으면 덮지 않고 안내한다.
- 저장은 기존 commit/persist(Web Locks, stale-save 검사)를 그대로 지난다.
- Ctrl/Cmd+Z: 입력칸·텍스트 영역에서는 문자 편집 되돌리기가 먼저다. 지도에서만 위치를 되돌린다. 되돌리기 기록은 탭 메모리에만 있고, 프로젝트를 바꾸면 비운다.

## 맞춤과 배율 (B1-R1)
- ‘전체 맞춤’은 실제로 그려진 카드 크기(긴 이름·구상으로 높아진 카드 포함)를 재서, 모든 카드가 지도 안에 들어오는 배율을 고른다. 필요하면 매우 작은 배율(최소 0.0005)까지 허용한다. 좌표 한계 양 끝에 있는 카드도 들어온다.
- ＋/－ 버튼은 40%~160% 범위다. 다만 맞춤으로 정한 더 작은 배율을 40%로 다시 올리지 않는다. 저장된 보기는 0.0005~160% 범위에서 그대로 복원한다.
- 지도는 보이게 만든 뒤 크기를 잰다. 숨겨진 상태의 0 크기로 맞추지 않는다.

## 관계 선
- 기존 관계 데이터를 읽기 전용 점선, 끝 표시, 종류 칩(이어서 사용·먼저 필요·같은 요구 공유·관련)으로 보여준다.
- 애니메이션이나 진행 표시가 없다. 실행 순서나 세션 통신이 아니다.
- 관계 편집은 아래 ‘영역 사이 관계’ 섹션에서 기존 그대로다. 관계가 없는 영역도 정상 상태다.

## 키보드·좁은 화면
- Tab으로 카드의 ⠿(이동), 본문(선택), ‘영역 열기’에 간다. ⠿에서 방향키로 이동하고, ‘영역 열기’는 Enter로 연다.
- 760px 이하에서는 속성 패널이 닫을 수 있는 아래쪽 시트(최대 화면 절반)가 된다. 새로고침 뒤에는 시트를 자동으로 열지 않는다. 지도는 ‘전체 맞춤’으로 모든 영역을 볼 수 있다.
