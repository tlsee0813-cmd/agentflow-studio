# AgentFlow Studio 사용 안내

AgentFlow Studio는 AI와 개발한 기록을 프로젝트 지도와 근거로 읽고, 다음 작업을 요청한 뒤 돌아온 보고를 비교하는 PC 도구입니다. 지도에 보이는 내용은 기록을 읽은 AI의 해석입니다. 구현 완료나 실제 동작 확인과 구분해서 보여 줍니다.

## 어디서 시작하나요?

| 사용할 곳 | 할 수 있는 일 |
| --- | --- |
| [공개 예제 체험](https://tlsee0813-cmd.github.io/agentflow-studio/) | 예제 지도, 부분과 근거 읽기, 인수인계 화면을 살펴봅니다. AI 서버가 없어서 새 지도를 생성하거나 질문할 수 없습니다. |
| 이 PC의 Studio (`http://127.0.0.1:4317`) | 이 PC의 Claude Code·Codex 기록을 연결하고, 지도 정리·변경 요청·보고 비교를 합니다. 아래 실행 방법으로 켭니다. |
| [웹 Studio](https://agentflow-studio.tlsee0813.workers.dev/) | 기존 접속 코드로 AI를 쓰고, GitHub 인증한 웹 AI 커넥터를 연결합니다. 아래 웹 AI 연결 안내를 확인하세요. |

프로젝트는 사용한 브라우저와 주소에 저장됩니다. 공개 예제와 PC에서 같은 프로젝트가 저절로 공유되지는 않습니다. 브라우저나 PC를 바꾸기 전에는 프로젝트 백업을 내보내세요.

## PC에서 켜기

이 PC에서는 바탕화면의 **AgentFlow Studio** 바로가기를 열면 됩니다. 이미 실행 중이면 같은 Studio 화면으로 연결합니다.

저장소의 `app` 폴더에서 PowerShell로 실행합니다. 기존 환경 파일은 그대로 사용하세요. 키와 접속 코드는 채팅이나 GitHub에 붙여 넣지 않습니다.

```powershell
node continuity/scripts/build.mjs
./continuity/scripts/start-local.ps1
```

키를 다른 파일에 보관했다면 기존 파일의 전체 경로를 `-EnvFile`로 지정합니다. 키가 없으면 기록 읽기와 예제는 가능하지만 AI 정리는 꺼져 있습니다. 자세한 실행·환경 설정은 [앱 설명](../app/continuity/README.md)에 있습니다.

## 기록 상태에 따라 시작하기

| 지금 상태 | 시작과 다음 기록 |
| --- | --- |
| 다른 곳에서 이미 진행한 프로젝트 | 새 프로젝트에 이전 대화나 현황 기록을 붙입니다. 완료 보고, 아직 안 한 일, 철회한 결정이 함께 있어도 원문 그대로 넣습니다. 첫 지도가 나온 뒤 근거를 확인합니다. |
| 만든 지도를 계속 수정하는 프로젝트 | 같은 프로젝트에 새 작업 보고를 추가합니다. 직접 고친 이름·메모·역할은 유지하며, 정정은 이전 주장의 이력을 남깁니다. 보고가 어느 요청과 판본에 관한 것인지 함께 적으면 구분에 도움이 됩니다. |
| 처음부터 연결하는 프로젝트 | 첫 요구부터 기록으로 받습니다. 요구만 있는 기능을 구현 완료로 표시하지 않습니다. 이 PC의 작업 폴더를 연결하면 이후 세션 기록이 이어서 들어옵니다. |

다른 노트북의 Claude Code를 원격 대화창으로 조작해도, 이 PC의 폴더 연결이 그 노트북의 파일을 읽는 것은 아닙니다. 그 세션의 기록을 붙이거나 백업 파일로 가져옵니다. 프로젝트를 바꿀 때는 원래 프로젝트에 새 기록을 이어 붙였는지 확인합니다.

PC의 지도 정리는 기록 구간 읽기 → 전체 조건 대조 → 부분 정리 → 마지막 확인으로 진행합니다. 창을 새로고침하거나 다른 프로젝트를 읽어도 PC 실행기가 켜져 있으면 작업은 계속됩니다. 돌아온 결과는 원래 프로젝트에서 확인해 반영합니다. 실패하면 기존 지도와 원문을 유지합니다.

분할 실행은 PC용입니다. 기본 배치는 DeepSeek의 구간 읽기, Sol 6.1 High의 설계, Terra 6.1 High의 부분 작성·대조입니다. OpenAI 키는 이 PC의 서버 전용 별도 파일에서 읽으며 브라우저나 프로젝트 백업에 넣지 않습니다. 기본 OpenAI 상한은 정리당 $1·월 $20이고 DeepSeek 요금은 별도입니다. 전송이나 과금 여부를 확인하지 못한 단계는 자동으로 다시 결제하며 재시도하지 않습니다. 이런 단계의 추가 비용 승인·재개 화면은 아직 제공하지 않습니다.


## 내 프로젝트로 한 번 이어가기

1. **내 프로젝트 만들기**에서 이름을 정합니다.
2. 이전 기록은 **기록 붙여넣기**로 넣습니다. 이 PC의 세션을 계속 받으려면 **내 AI 세션 자동 연결**을 열고 작업 폴더를 선택합니다. 로컬 서버가 이 PC의 Claude Code·Codex 세션을 읽습니다. 처음에는 최근 14일, 최대 10개 세션을 가져옵니다.
3. 지도 정리가 끝나면 부분 하나를 열어 현재 상황과 **원문 근거**를 함께 읽습니다. 제외된 항목 안내가 있으면 원문과 이유를 확인합니다. 제외된 내용은 확인된 사실로 지도에 추가되지 않습니다.
4. 원하는 변경을 적고 분석 결과를 읽은 뒤 요청문을 만듭니다. 요청문은 작업할 AI 세션에 직접 전달합니다.
5. 그 세션의 작업 기록이 들어오면 원래 요청과 비교합니다. AI의 완료 보고와 실제 검사 결과는 서로 다른 근거입니다. 아직 구현하지 않은 작업을 완료로 취급하지 않습니다.
6. 다른 세션에서 이어갈 때 **인수인계** 문서를 복사합니다. 다음 세션에 문서와 이번 요청을 함께 전달합니다. 문서의 끝 표식까지 복사하면 같은 내용이 중복 기록되는 일을 줄일 수 있습니다.

자동 연결은 프로젝트가 열린 동안 새 기록을 확인합니다. 대화가 약 2분간 잠잠해진 뒤 가져오며, AI 지도 갱신은 5분 간격·하루 30회까지입니다. 취소한 지도 갱신은 새 기록 없이 자동으로 다시 실행하지 않습니다.

## 웹 AI에서 이어가기

Claude의 **커넥터 → 내 항목 → AgentFlow Studio**가 연결됨인지 확인합니다. 서버 주소는 `https://agentflow-studio.tlsee0813.workers.dev/mcp`이고, OAuth의 **지금 로그인·자동으로 등록**을 사용합니다. AgentFlow는 GitHub에서 계정 이름과 번호만 확인하며 저장소 접근 권한을 요청하지 않습니다.

PC에서 작업 폴더를 연결해 프로젝트를 한 번 열어 두면 인수인계가 준비됩니다. Claude 새 대화에 프로젝트의 정확한 이름과 함께 다음처럼 요청하세요.

> AgentFlow에서 “내 프로젝트 이름”의 인수인계를 받아 이번 작업을 이어 주세요. 요청 하나를 마칠 때 요청 원문과 한 일을 같은 프로젝트의 AgentFlow 기록으로 남겨 주세요.

PC Studio가 켜져 있으면 웹 기록은 약1분 간격으로 PC에 보관됩니다. 프로젝트가 열려 있을 때 기록이 화면으로 들어오고 지도 정리로 이어집니다. 웹 AI가 기록 도구를 호출해야 전달되며, 전체 웹 대화가 항상 자동으로 복제되는 기능은 아닙니다.

처음 PC를 연결할 때만 웹 Studio의 PC 연결키 발급 화면을 사용해 `AGENTFLOW_CLOUD_URL`과 `AGENTFLOW_CLOUD_KEY`를 기존 환경 파일에 추가합니다. **이미 연결된 PC라면 키를 다시 만들 필요가 없습니다. 새로 발급하면 이전 키는 사용할 수 없습니다.** 2026-11-01 이 PC의 실제 연결 상태와 확인 결과는 [전달 결과](releases/2026-11-01/RESULT.md)를 따릅니다. 키는 채팅에 붙이지 않습니다.

## 기록이 없거나 정리가 끝나지 않을 때

- 연결한 작업 폴더와 사용한 AI 도구를 먼저 확인합니다. 다른 폴더의 세션은 자동으로 합쳐지지 않습니다.
- 원본 기록은 남겨 둡니다. 정리 실패나 제외 안내를 읽고, 근거가 부족한 항목은 원문에서 확인합니다.
- 재시도 전에 현재 작업 상태를 확인합니다. 같은 자료를 여러 번 다시 보내서 성공 여부를 가리지 않습니다.
- 백업은 프로젝트 기록과 지도 이력을 옮기는 방법입니다. API 키나 서버 설정을 옮기는 기능은 아닙니다.

현재 배포 판본, 확인한 범위와 남은 제한은 [ACTIVE](cycles/ACTIVE.md)와 [열린 질문](QUESTIONS.md)에 기록합니다. 과거 사이클의 통과 기록을 전체 제품 완성으로 해석하지 않습니다.
