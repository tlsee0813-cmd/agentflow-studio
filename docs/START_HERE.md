## 설치 없이 첫 흐름

1. [공개 MOCK](https://tlsee0813-cmd.github.io/agentflow-studio/)을 엽니다. 실제 AI 호출이나 자동 개발 실행은 없습니다.
2. 프로젝트의 목적(선택)과 이번 요청을 적고 **작업문 준비하기**를 누릅니다. 목적은 배경이며 요청 원문·확정 조건과 구분됩니다.
3. 공간의 영역·작업을 살펴보고 이번 요청, 별도 조건란, 열린 질문·보류, 다음 행동을 확인합니다. 조건란이 비어 있어도 원문 속 조건·금지가 없다는 뜻은 아닙니다. MOCK 질문은 의미 이해나 완전한 조건 추출을 보장하지 않습니다.
4. 작업문을 확인·직접 수정한 뒤 복사하거나 Markdown으로 저장해 외부 AI/개발 도구에 직접 전달합니다. 복사 자체는 실행·권한 부여·완료가 아닙니다.
5. 돌아온 보고를 맞는 작업에 붙여넣거나 지원 형식의 결과 파일로 가져옵니다. 작업·결과·기준을 확인하고 필요한 정정과 다음 요청을 작성합니다. 보고가 저장됐다고 외부 구현이 검증된 것은 아닙니다.

저장은 현재 브라우저의 로컬 데이터입니다. 다른 계정·기기로 자동 동기화하지 않습니다. 백업·복구를 활용하고, 저장 용량 오류에서 메모리에만 남은 변경은 탭을 닫기 전에 복구 사본을 저장하세요. 개별 결과 원문 수정·삭제·제외·연결 해제는 지원하지 않아, 정정 요청을 추가해도 기존 원본과 연결이 남을 수 있습니다.
