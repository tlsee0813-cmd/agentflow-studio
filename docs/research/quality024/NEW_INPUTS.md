# QUALITY024 신규 합성 사용자 입력

이 문서는 고객 조사를 재현한 것이 아닌 개발자가 설계한 두 입력이다. 실제 모델 호출은 하지 않았다. 각 변형은 독립 프로젝트이며 제목은 둘 다 `공연장 안내`다. 식별자/문서 머리말은 모델에 전달하지 않고 해당 request 문자열만 정상 domain submit으로 입력한다. 판단 기준은 EVALUATION.md에 분리되어 있다.

## N01

작은 동네 공연장입니다. 출연자가 낸 소개글을 행사 홈페이지에 옮길 때 같은 내용을 다시 적는 일을 줄이고 싶어요. 담당자가 내용을 확인하고 게시를 선택한 뒤에만 홈페이지에 공개하는 현재 방식은 그대로 두세요. 소개글을 다시 입력하는 일만 줄이면 됩니다. 실제 코드나 파일 구조는 여기 제공하지 않았습니다. 코드는 잘 모르니 먼저 만들 작은 작업으로 적어 주세요. 운영 홈페이지에 바로 배포하지는 마세요.

## N02
