# RESEARCH021 공유 범위

2026-10-12 생성된 조사 문서17개를 UTF-8 원문과 상대 경로 그대로 보존했다. 출처 지도·출처 JSON·재사용 및 실사용 원장·세 작업 인계·후속 연구·작성자가 수행한 패키지 확인을 포함한다. 외부 소스·교재·사진·긴 외부 원문 복제는 이 문서 묶음에 없어 제외한 파일은 없다. 필요한 출처 링크·고정 커밋·열람 범위·접근 제한은 유지한다.

연구는 지정 커밋 `6666c6bd35a1a01419d3a082b6dfc776ce3db717`과 당시 자료를 읽은 제안이다. 조사 당시의 미회수·미검토 안내를 현재 진행 상태로 해석하지 않는다. 최신 UI001·CONNECT001 rev1·IDEA020 보충 검토·IDEA022 상태는 [PROJECT_STATUS](../../PROJECT_STATUS.md)와 [설계 인계](../idea020-connect001-handoff.md)를 따른다.
