## 범위의 한계

외부 링크의 영구 가용성은 보장하지 않으며, 모든 URL을 패키징 단계에서 다시 다운로드한 것은 아니다. 정확한 원문 열람 방식과 실패는 출처 지도에 있다. 사전 가설·본문·인계안을 사람이 읽듯 다시 검토했지만 이는 동일 세션의 자기 점검이며 독립 리뷰가 아니다.

제품 코드 빌드/테스트, 라이브 브라우저 제품 사용, CLI 설치/연결, 모델 호출, 비용 측정, 사용자 실험은 하지 않았다. 기존 기록의 테스트 결과는 기존 기록으로만 언급했다. 외부 소스/사진/폰트/교재/키/개인 세션 로그는 ZIP에 포함하지 않았다.

## Manifest 규칙

`MANIFEST.sha256`은 자신을 제외한 모든 배포 파일의 SHA-256을 기록한다. 경로는 이 최상위 폴더 기준이다. manifest는 파일 동일성을 확인하기 위한 것이며 공식 서명이나 외부 사실의 검증 증거는 아니다.
