# 지도 읽기28 — 작성자 연구 후보 v0

기준 `6b96543fdf980ff45f0e1b67f83e8a0a561a1542`의 격리 후보이며 제품 통합이나 가독성 합격을 뜻하지 않는다. 최초 `STATIC_PROPOSAL.md`는 구현 전 산술 검토다. 이후 총괄의 제한된 비교 승인에 따라 `candidate/`에 두 파일만 변경했고 최종 값은 `CANDIDATE_RECEIPT.json`에 기록했다.

app.ts는 지도에 연구용 상시 클래스를 붙이고 실제 직접부모 이름·깊은 경로 생략 표식만 추가했다. styles.css는 그 클래스 안에서 제목24px/행간27px·원문 순서 최대2줄을 적용하고 구상 문장·구상미기재 표시·일반 요청/결과 집계만 숨긴다. 좌표,240×180,fit,관계,실제 소속,정보·이동·분기 조작,키보드 이벤트,기존 이어갈작업·갱신·질문·현재설명·보류·이전기준의 존재 조건과 값은 변경하지 않았다. 신호가 모두 있을 때 잘릴 가능성은 추가 보정 없이 실제 비교의 실패 반례로 남겼다.

작성자는 기존 Node24.19.0·TypeScript5.8.3으로 타입 검사와 continuity 빌드,차이 검사를 수행했고 각각 exit0이다. 설치·단위 검사·서버·브라우저·원격 쓰기는 하지 않았다. 실제 Cloud 비교와 Node22/CI 수용은 별도다. 타입/빌드 성공으로 읽기나 클릭 성공을 주장하지 않는다.

처음 타입/빌드 로그6개를 저장할 때 상대 경로가 한 단계 높아 `work/`에 새로 생성되었다. 각 파일의 생성시각이 해당 실행과 일치함을 확인하고 덮어쓰기 없이 이 폴더로 옮겼다. 명령 실패는 아니며 원 로그·exit 바이트는 유지했다. 이후 예전 payload 형식을 읽으려던 한 조회는 존재하지 않는 expected 파일명으로 실패했고 실제 `upload-tree-v0-expected-blobs.json`을 읽어 형식만 확인했다. 이 조회는 제품·검사·업로드 실행이 아니다.

작성자 증거에는 작은 메타데이터·문서·패치·원 로그만 포함한다. 후보 전체 소스는 별도 source payload이며 baseline/src/dist/node_modules를 증거 접두사에 중복하지 않는다. 후보 파일과 증거의 UTF8 재인코딩 바이트·SHA256·Git blob은 각각의 expected 목록으로 전수 대조했다. 원격 작성은 총괄만 수행한다.
