## 작성자검사 (실제 실행, run-03)

  - 글자 유효 크기(computed font-size × 배율)는 노출 판정과 따로 관측값으로 남겼습니다.

  - 초기에 스크롤·맞춤 없이 세 카드 전체, 두 호출 양끝, 라벨이 지도 영역 안에 있었고, 이름·역할·이동 단서도 hit 판정으로 확인했습니다. 유효 글자는 세 폭 모두 이름 16px, 역할 12.5px였습니다.
