# 총괄 대표 화면 검토
2026-10-22. 고정 before 증거 c7981de616f275b97b1ccc28dd316a778a075f7d, 제품ba9. 실제 독립 조작과 별도의 이미지 검토다.

총괄은 c7981de의 1280 actual-child, 1440 returned-relation-reader, 1280 long-panel-fixed-actions PNG를 GitHub 원본 브라우저에서 직접 열어 보았다(실제 제품 조작 재실행 아님). 닫기/영역열기/새요청은 긴 내용에서도 별도 고정행으로 유지되고 관계읽기는 지도 옆 같은 패널에 머문다. 사용자 구상과 받은 설명의 출처 구별은 유지된다. 다만 1280×720 actual-child에서 상단 프로젝트/안내/목적/복귀/도구가 약413px를 쓰고 지도는 약290px만 남는다. 긴 표본도 지도 시작 약362px이다. 잔여 높이 사용과 중요한 행동 접근이라는 한정 개선이며 Dify 수준의 PC 작업공간 밀도/가독성을 달성했다고 수용할 수 없다. 후속은 새 메커니즘 추가보다 중복 상단 맥락을 압축해 기본 지도와 현재 설명을 함께 읽는 공간을 확보하는 좁은 비교로 삼는다. 화면 밖 카드 수와 최소 reveal은 전체지도 항상동시가시성/임의pan에서모든카드접근을 보증하지 않는다.

추가로1280-non-descendant-frame-fallback PNG도 확인했다. 비자손을 감싸는 큰 닫힌 프레임을 생략한 장면은 확인되지만 전체맞춤37%의 작은 카드 문자는 상세 패널을 열지 않고 읽기 어렵다. 프레임 오해 방지와 모든 배율 가독성 완성은 구별한다.
