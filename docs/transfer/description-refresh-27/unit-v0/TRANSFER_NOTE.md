# 27 검사 증거 전송 경계

새 .test.mjs 8개와 관련 기존 91개가 첫 실행에서 99/99 통과했다. Node24.19.0/TypeScript5.8.3 보조 검사이며 Node22 Cloud/CI와 구분한다. 전체 wildcard는 다른 검사의 HTTP listener 때문에 실행하지 않았다. 실제 브라우저·로컬 서버·유료 AI는 미실행이다.

이 결과는 v0 domain/app 기준이다. fix1은 같은 domain의 UI disclosure 종료 수정이며 이 단위 검사를 다시 실행한 것으로 세지 않는다. 검사 작성·실행 역할이지 독립 제품 수용이나 AI 의미 품질 검증이 아니다.

추가 browser-compat 자료는 기존 understanding17_browser.py 265행의 global notice 기대만 클릭 후 정확 영역 inline 상태의 실제 visible/거절 문구로 바꾼다. 나머지 전체 바이트와 뒤 revision/data/draft 단언은 그대로다. 이 Python 파일은 AST만 통과했으며 브라우저 실행 결과가 아니다. 원본·수정본·patch·receipt·원 명령 로그를 보존한다. 원 RECEIPT/REPORT는 당시 동결 상태 그대로다.
