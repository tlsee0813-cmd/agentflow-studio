# 공개 원시 로그 사본의 개인 경로 표시 정리

이번 변경은 공개 근거의 포장 수정이다. 제품·검사 소스는 동결 상태를 유지했고 타입·빌드·브라우저 검사를 다시 실행하지 않았다. 기존 공개 이력 `02fb927b…`를 비밀 파일이나 인증정보 유출로 판정하는 자료가 아니다.

로컬 원본 `evidence/RAW_CHECKS.json.gz.base64`와 개별 원시 로그는 그대로 보존했다. 압축을 푼 원본은 63개 파일(stdout·stderr·exit 기록), 11,193자 / UTF-8 11,331바이트이다. 원본에서 개인 경로 패턴은 46회 일치했다.

공개 사본에는 다음 두 절대 경로 접두사만 표시 치환했다. JSON 안의 역슬래시 이스케이프와 슬래시 표기를 함께 처리했다.

- 작업 장소 접두사 → `<LOCAL_WORKSPACE>`: 2개 경로
- 기존 런타임 접두사 → `<LOCAL_RUNTIME>`: 21개 경로

변경된 원시 파일은 명령 경로가 들어 있는 exit JSON 21개다. 명령의 나머지 인수, 시각, exit 값, JS source hash 등 비경로 필드는 동일함을 비교했다. 모든 stdout·stderr 바이트도 원본과 동일하다. 로그 이름과 63개 파일의 집합은 유지했다.

공개 gzip/base64를 실제 파일에서 다시 읽고 압축을 풀어 `C:[/\\]+Users`(대소문자 무시)와 개인 사용자 이름을 검사한 결과는 **0건**이다. 개인 이름 자체는 이 안내에 다시 기재하지 않는다. 공개 사본은 9,847자 / UTF-8 9,847바이트이며, 압축 왕복 후 그 내용과 정확히 일치했다.

| 표현 | 로컬 원본 bytes / SHA-256 | 공개 사본 bytes / SHA-256 |
|---|---|---|
| base64 파일(끝 LF 포함) | 1,837 / `00767e32d8a479a4e4c4879cc10905bdad0e495ae394d9e264e62755da0a0bc5` | 1,709 / `07c86ebedfb82ea442866f51dd3d185d63647dfd2ae8f6ae0e9d7a6d2588a8bb` |
| gzip 바이트 | 1,376 / `08f229811683fa560316c2c7eebd3c4dc9f1841a464ce2221793c8eb8b1ff86e` | 1,279 / `633cf4e954411276de7296973a2c3688864c13e797d80a974085a530244cf49f` |
| 압축 해제 UTF-8 JSON | 11,331 / `ad78a4a736159de10b1a195ac9aceb7738ac063f09e00030480b676ab30ff661` | 9,847 / `dd6ba676a694f1cd7bced71cd46c31a50cc90b9f01951b0b812d379a77fa2b59` |

RECEIPT의 publicEvidencePackaging에 같은 측정값을 추가했다. 이 공개 사본의 hash는 원시 로컬 사본과 다르며, 경로 표시를 정리한 파생 자료임을 명시한다. 원격 게시와 기존 공개 이력에 대한 처리는 root가 별도로 담당한다.
