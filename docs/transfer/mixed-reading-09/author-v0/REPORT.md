## 재현
`node scripts/collect.mjs <runId>; echo $? > runs/<runId>/collector-exit.txt`
- 필요 조건: Node 22, `playwright` 모듈 경로 `/opt/npm-tools/node_modules/playwright`, Chromium.
- 다른 환경에서는 `check.mjs`의 import 경로를 바꿔야 한다.
- 출력: `runs/<runId>/<뷰포트>/{raw.json, log.txt, child-stdout.txt, *.png}`, `collector.json`.
