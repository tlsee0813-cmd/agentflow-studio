# cycle11 author-fix1 — 초안 미리보기와 복사문 불일치(P2) 수정

v0 위에 덮어 쓰는 작은 묶음이다. 연구용 작성자 검사이며 결과는 잠정적이다. v0 ZIP(`23a915eb…`), 원본 r01–r05, 제품·main·배포는 바꾸지 않았다.

## 결함과 수정

**결함(재현됨).** v0 `engine.js` 354·362행의 동작이다.
- 미리보기를 연 채 입력을 비공백에서 다른 비공백으로 고치면, input 처리기는 버튼 상태만 갱신한다.
- 그래서 열린 `#draftPreview`는 이전 문장에 머문다.
- 복사는 `draftPreviewText()`로 최신 문장을 쓰므로, 보이는 미리보기와 복사문이 달라진다.

**수정.** 1줄을 바꿨다(diff: 삭제 1 / 추가 1, `v0-to-fix1.diff`). 바꾼 곳은 `syncDraftBtns()` 하나다.
- 입력이 비공백이고 미리보기가 열려 있으면, 미리보기 내용을 `draftPreviewText()`로 바로 갱신한다.
- 입력이 비거나 공백뿐이면, 기존처럼 미리보기를 숨기고 그 내용도 비운다.

**이 방식을 고른 이유.** 미리보기를 닫는 대신 갱신하면, 사용자가 보고 있는 글과 복사될 글이 항상 같은 함수에서 나온다. 수정 범위도 이미 모든 입력 변화에서 불리는 한 곳으로 끝난다.

## 같은 회귀 검사로 확인: v0 재현 실패 → fix1 통과

**구성**
- 검사 코드: `tests-fix1/regress-preview.mjs`(`f991a155…`), `tests-fix1/collect-fix1.mjs`(`37fac76d…`)
- 같은 검사를 v0 원본 app과 fix1 app에 각각 1280×720·1440×900으로 돌렸다. child는 4개다.
- 조작은 실제 마우스 클릭(화면 안·대상 위 확인 후)과 키보드 입력만 썼다. 사례 전환만 `selectOption`이다. DOM 값 대입과 DOM 스크롤은 쓰지 않았다.

**사례마다 밟은 단계**(FLOW091 작업문과 미리보기, PowerToys 키 검색·선택)
1. E1 입력 → 미리보기 열기
2. 미리보기를 연 채 E1+E2로 편집(비공백 → 비공백) → 복사
3. 전체 삭제(빈 입력)
4. 공백만 입력
5. E3 다시 입력 → 복사 → 미리보기 다시 열기
6. 미리보기를 연 채 E3+E4로 편집 → 복사

**필요한 범위의 회귀 확인**
- 두 사례 초안을 닫고 사례를 왕복한 뒤 다시 연다.
- 각 사례의 초안이 보존되는지, 서로 섞이지 않는지, 미리보기가 닫힌 채 다시 열리는지 본다.

**실행 f01**
- 수집자 exit 0. 조건은 v0가 재현 실패로 끝나고, fix1 child가 모두 0이며, 실행 전후 해시가 같은 것이다.

| app | 1280×720 | 1440×900 |
|---|---|---|
| v0 | child exit **1**, 52개 중 6개 실패 | child exit **1**, 52개 중 6개 실패 |
| fix1 | child exit **0**, 52/0 | child exit **0**, 52/0 |

- v0의 실패는 두 폭·두 사례 모두 같은 세 항목이다.
  - ‘2) 열린 채 편집 뒤 보이는 미리보기가 최신 입력’
  - ‘2) 복사문 = 보이는 미리보기’
  - ‘6) 열린 미리보기와 복사문 일치’
- 빈 입력·공백(3·4단계), 다시 입력한 뒤 복사(5단계), 전환 뒤 보존(7단계)은 v0에서도 통과했다. 이번 결함과 무관한 동작에는 회귀가 없다.
- fix1에서는 모든 단계가 통과했다.
  - 2·6단계: 보이는 미리보기 = 클립보드 = 최신 입력
  - 3·4단계: 미리보기 숨김, 미리보기·복사 비활성
  - 5단계: 다시 연 미리보기 = 방금 복사한 글
- 매 child마다 HTTP 응답 5개 파일의 SHA가 디스크와 같았다. 브라우저가 받은 engine.js는 v0 `d945331c`, fix1 `d3699ac7`이다.
- console.error와 pageerror는 0건이고, 실행 전후 소스와 검사 코드 해시는 같았다.
- 각 child 52개 중 30개는 클릭 지점 전제 검사다. v0의 299 계열 수와 합산하지 않는다.
