# 입력 형식 (schemaVersion 1) — 연구용 두 층 부분 지도

같은 `index.html` + `engine.js` + `style.css`가 이 형식의 JSON을 읽어 그린다. 렌더러는 구조와 필드가 있는지만 보고 표시를 정한다. 사례 이름, 노드 ID, 업무 문구에 따라 동작을 바꾸지 않는다. 임의 기록을 자동으로 해석해 이 형식을 만드는 기능은 없다. 입력은 사람이 근거를 보고 작성한다.

## 최상위

| 필드 | 필수 | 뜻 |
|---|---|---|
| `schemaVersion` | ✓ | `1` |
| `caseId` | ✓ | 사례 식별자. 초안과 보기 상태를 사례별로 나누는 키에 쓴다 |
| `title` / `scope` / `nature` / `basisTime` | ✓ | 제목, 범위(무엇의 일부인지), 자료 성격(원문 종류와 없는 것), 기준 시점 |
| `groupingNote` |  | 묶음이 무슨 뜻인지(보기 구분인지 등) |
| `nodes` | ✓ | 부분 목록. 배열 순서가 자식 표시 순서다 |
| `relations` | ✓(빈 배열 가능) | 기록에 적힌 관계 |
| `evidence` | ✓(빈 배열 가능) | 근거 기록 |
| `initialView` |  | 처음 보기: `expanded`(처음에 펼칠 묶음 ID), `layout`(넓은 화면 격자) |

## nodes[]

- `id` ✓: 고유 문자열이다. relations·evidence의 ID와 겹치면 안 된다.
- `parent` ✓: 루트는 `null`이다. 그 밖에는 루트의 ID만 올 수 있다(두 층까지만). parent는 보기의 포함을 뜻하며 relations와 별개다.
- `name` ✓, `role` ✓: 역할 한 문장. 선택하면 이 문장을 먼저 보여 준다.
- `short`: 지도 카드의 짧은 설명.
- `tag`: 묶음 밖 부품처럼 성격 표시가 필요할 때 쓴다(지도 카드 위 작은 글자, 점선 테두리).
- `evidence`: 근거 ID 배열.
- `change`(선택): 이 기록에서 달라진 부분이다. 없으면 변경 표시, 빈 행, 대체 문구를 하나도 만들지 않는다.
  - `label`: 예) 요청에 따른 수정, 지원 변경 · 별도 요구 아님.
  - `summary` ✓: 변경 한 문장.
  - `before` / `after`: 전과 후.
  - `basis`: 비교 기준.
  - `evidence` ✓: 1개 이상.

## relations[]

- `id`, `from`, `to`: 실제 끝점이다. 접힌 묶음이 있으면 지도에서는 대표 자리로 모아 그리지만, 설명과 참고에서는 실제 끝을 보여 준다.
- `kind` ✓, `condition` ✓: 전체 조건이다. 관계 참고와 근거 상세에서 생략하지 않는다.
- `short`, `evidence`.
- 관계는 기록에 적힌 것만 넣는다. 실행 순서나 인과를 뜻하지 않는다.

## evidence[]

- `id`, `type`: 원문 종류. 예) 개발 계약 문서 · 고정 커밋, 사람 리뷰 댓글 · 재현 보고, 고정 커밋 코드 차이.
- `source.label`, `source.url` ✓, `source.pin`: 고정 커밋이나 ID.
- `summary`.
- `quote`: 정확 원문. 없으면 `null`이고, 이 경우 화면은 링크로만 안내한다.
- `limits`: 확인 한계. 이 근거가 증명하지 않는 것.

## initialView.layout (보기 제안)

- `columns`: CSS 격자 열 너비 배열.
- `areas`: 격자 영역 문자열 배열.
- `place`: `{ 루트ID: { area, align } }`.

배치는 입력 쪽이 제안하는 보기이며 의미를 바꾸지 않는다. 좁은 화면(700px 이하)에서는 모든 사례를 한 열로 쌓는다.

## 입력 검사

다음은 오류로 표시하고 지도를 그리지 않는다. 자동으로 고치지 않는다.
- 중복 ID, 없는 parent나 자기 자신을 parent로 둠, parent 순환, 3층 이상 깊이
- 없는 끝점, 양끝이 같은 관계, kind/condition 누락
- 없는 근거 참조, 근거가 없는 change
- 없는 노드를 가리키는 `initialView`

## 화면이 보관하는 상태 (메모리만)

- 사례별 보기: 깊이, 배율, 지도·본문·설명 스크롤, 선택. 키는 사례 순번과 `caseId`다.
- 사례+대상별 ‘내 다음 요청’ 초안: 자유문 한 칸.
- 새로고침하거나 다른 세션에서는 남지 않는다. 송신, 작업 생성, 수락 기능은 없다.
