# run-04 — 첫 앱 결함 발견 (보존)
child exit 1, FAIL 1: 1440에서 자연 최대 읽기 위치(102px)에서 ‘행사 홈페이지’ 위치 보기 후 읽기 위치·초점은 그대로였지만 **행 rect가 바뀜**.
원인(앱): 큰 화면은 위치 보기 결과를 각 맥락 행 아래 상태 문구로 보여 주는데, 앞 행(출연자가 낸 소개글)의 문구를 지우고 이 행에 새로 쓰면서 위쪽 행 높이가 줄어 읽던 행이 위로 밀렸다. 또 긴 문구가 두 줄로 줄바꿈되어 높이가 변했다.
수정(run-05): 상태 문구 자리를 항상 한 줄로 확보하고 문구를 짧게 함. 검사 코드는 같은 단언에 실제 rect 전후값을 detail로 남기도록만 보강.
