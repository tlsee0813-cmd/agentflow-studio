# 1280 첫 재진입 판독 — 세부 열기 전 기록

준비자가 A/B/Q의 정답을 알고 있다. 아래는 준비 지식을 화면에서 새로 발견한 성과로 세지 않고, 실제 첫 화면에서 읽히는 정보만 적는다.

- 목적: 도서 대출 예약 서비스, 중복 예약 방지와 예약 결과 알림.
- 접힌 `예약`: 하위2개 펼치기, **기록된 질문1 · 현재 설명1**. 이 수를 미열람1이나 최근 발생1로 읽지 않는다. 어떤 자식이 소유하는지는 첫 카드만으로 아직 모른다.
- 접힌 `알림`: 하위1개 펼치기, **기록된 질문0 · 설명 보류1**. 보류가 현재 설명이라는 근거는 없다. 어떤 기준이 바뀌어 보류됐는지는 세부 확인이 필요하다.
- 전역 `이어 볼 기록3개 · 답 기다림1 · 후속 작업문 없는 보고2`는 unread 수가 아니다. sidebar는 작업6의 후속 확인 초안을 표시하지만, 그 사실만으로 알림 보류나 예약 질문이 더 최근이라고 판정하지 않는다.
- 현재 선택 없음. 첫 선택은 `예약 정보`로 한다. 중복 예약을 막는 목적과 관련 있고, 질문과 현재 설명이 서로 다른 소유 부분인지 먼저 구분하려는 이유다. 알림 보류를 먼저 읽는 선택도 가능하며 우선순위의 유일한 정답을 주장하지 않는다.
- 이전 baseline에서도 예약에 현재 설명1이 있었다. **마지막 열람 이후 새 설명으로 갱신된 것인지 이 첫 화면만으로는 알 수 없다.** 준비 지식으로 A2를 안다고 해서 화면이 알려 줬다고 쓰지 않는다. 이는 lastSeen 기준이 없는 정직한 한계이며 기능 결함 확정이 아니다.
- 화면 밖 영역2개 chip도 보이나 이를 새 변경2개로 해석하지 않는다. 상세를 열고 실제 자식/근거를 대조할 예정이다.
