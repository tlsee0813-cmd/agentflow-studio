# 독립 정적 검토 반영

`resume_product_judgment_astra`는 최초 4485 판본을 읽고, body 위치 보존과 첫 키 입력 측정이 어떤 화면 보정보다 먼저 수행되는 점, 실제 wheel 교집합·소유자·양수 delta 및 scroll 이벤트 확인 범위가 단일 body 계약과 맞는 점을 확인했다.

단, 원문 anchor helper가 매번 현재 보이는 첫 글줄을 새로 골라 동일성을 요구하면 안내 높이·페이지 위치 변화만으로 거짓 실패를 만들 수 있다고 지적했다. 최초에 저장한 text와 lineIndex에 해당하는 동일 Range만 다시 검사하도록 보완했다. 그 줄이 가렸다면 다른 가시 줄로 대신 통과하지 않으며 inside·hit·cover를 기록한다. body를 그 줄로 직접 스크롤하지 않는다.

담당자는 최종 실제 SHA256 `9713415a8acb0b6b700ab460119d6b8dbd666bad0dc6c4106a99d3164be4f4bf`를 확인하고, 4485 보존본과의 delta가 expected 처리와 호출 인자 전달뿐임을 직접 대조했다. 제기한 문제가 해소됐으며 추가 수정 사항 없이 정적 동결 가능하다는 의견을 받았다. 실제 브라우저 결과와 기존 AREA17 실패는 별도 판단이라고 명시했다.

이 문서는 작성자가 협업 메시지를 요약한 메모이며, 독립 담당자가 직접 작성한 별도 원문 보고서로 가장하지 않는다. 정적 수용을 UI 통과로 쓰지 않는다.
