- v1과 fix2의 check.py 원문을 직접 대조했다. 후보 경로 home15-read-candidate/app → home15-read-fix2-candidate/app 한 줄 외 로직이 동일하다. comparison.json의 50개 순차 관측 대응과 일치한다(반복 close 관측 ID를 독립 고유 테스트 수로 세지 않는다).
- SOURCE_BINDING은 정확 후보와 계약을 가리키며 178개 파일 pinned-before/disk-after 해시가 모두 같다. 실제 HTTP 바인딩은 실행 자료의 별도 무결성 감사이며 UI 검사 수에 더하지 않는다.
