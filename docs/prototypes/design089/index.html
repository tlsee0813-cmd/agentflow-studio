이 시안에서 확인할 것
전체 구조도 → 영역 전용 화면의 작은 클릭 시안입니다. 공간은 전체와 영역의 두 단계뿐입니다.
  • 예약에서 API 초안을 작성한 뒤 취소·알림·전체로 이동해 보세요.
  • 상단의 작성 대상과 열린 영역, 보고에 적힌 대상 작업은 서로 다릅니다.
  • 공유 요구를 수정해도 이미 전달한 옛 작업문과 보고 원문은 바뀌지 않습니다.
  • 지도의 가로·세로 스크롤, 선택 및 화면별 스크롤을 이 열린 페이지에서 복원합니다. 팬·줌은 없습니다.
  • Tab·Shift+Tab·Enter/Space로 조작하고 Escape로 대화상자를 닫습니다. 지도는 포커스 후 방향키로 스크롤할 수 있습니다.
  • 입력·초안은 메모리에만 있습니다. 새로고침·닫기·브라우저 재시작 시 초기화됩니다. 자동 AI 처리·외부 전달·실제 실행은 하지 않습니다.
