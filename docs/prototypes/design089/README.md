# DESIGN089-P — 전체 구조도에서 영역 전용 공간으로

상태: 정적 클릭 시안 / 검토 대기. 실제 제품 통합·AI 연결·배포본이 아닙니다.
작성일: 2026-10-14.

## 열기

`index.html` 한 파일을 브라우저에서 여는 방식으로 구성했습니다. CSS·JavaScript·SVG를 모두 내장하고 외부 폰트·CDN·라이브러리 설치를 사용하지 않습니다. HTML 실행에 Python이나 테스트 도구는 필요하지 않습니다.

이 작업 환경의 관리 정책은 `file://` 및 loopback HTTP 탐색을 차단했습니다. 같은 HTML을 Chromium의 about:blank에 Playwright `set_content`로 주입하여 클릭 검사를 했습니다. 직접 파일 열기까지 검증한 것으로 읽지 마세요. 자세한 범위는 CHECKS.md에 있습니다.

## 한 번 따라가기

전체 구조도 → 예약 → `API 다음 지시 준비` → 초안 일부 편집 → 취소 → `최신 요청과 보고 비교` → 옛 보고 원문 → 알림 → 선택적으로 `이 영역 구체화`와 모르겠음/보류 → 전체 복귀 → 상단 `초안 이어쓰기`.

회원은 예약의 관련 영역 링크로 열 수 있습니다. 두 곳의 `공유 요구·이력 보기`는 같은 REQ-01을 참조합니다. 시안 안에서 요구를 수정해도 과거 API 작업문과 보고, 작성 중 초안은 자동 변경되지 않습니다.

## 저장과 탐색

- 데이터는 이 열린 HTML 문서의 메모리에만 유지합니다. 새로고침·페이지 닫기·브라우저 재시작 시 편집·메모·질문 상태가 초기화됩니다. localStorage/sessionStorage/DB를 사용하지 않습니다.
- 전체/영역의 두 단계입니다. 영역 이동은 설계 확정, 작업 생성, 실행, 최신 지시 변경을 뜻하지 않습니다.
- 지도 팬·줌 및 드래그 편집은 없습니다. 좁은 화면은 지도 내부를 스크롤하거나 영역 바로가기를 사용합니다. 같은 열린 페이지에서 지도 가로·세로 스크롤·선택, 화면별 스크롤, 브라우저 뒤로/앞으로 탐색을 복원합니다. 창 크기가 바뀌어 범위를 벗어난 스크롤은 브라우저가 제한할 수 있습니다.
- 예약 초안의 TASK-API-01/X-01 대상, 현재 열린 영역, 읽은 보고의 대상은 분리합니다. 다른 영역을 방문해도 초안은 유지합니다.
- 알림에는 빈 탭이나 빈 작업 그래프가 없습니다. 미리 작성한 질문 하나를 선택적으로 열 수 있으며 모르겠음·보류는 미정, 답변은 초안으로 남깁니다.
- 복사는 실제 외부 전달/실행이 아닙니다. Clipboard API를 사용할 수 없으면 텍스트를 선택하고 수동 복사를 안내합니다.

## 가상 자료와 제한

회원/예약/취소/알림 4영역, 3개의 고정 작업 및 3개의 가상 세션을 사용합니다. Claude/Codex는 가상 담당 도구 이름이며 어떤 외부 계정에도 접속하지 않습니다.

REQ-01 r2는 비회원 예약 허용, 과거 API 전달 작업문 r1은 로그인 필수입니다. Claude의 화면 반영 보고는 미검증, Codex 실제 실행 상태는 미확인입니다. 취소에는 최신 버튼 문구 요청과 이전 전체화면 작업의 늦은 보고를 대조합니다.

공유 요구 수정은 한 원본 참조/과거값 보존을 보여주는 시연입니다. 자유로운 요구 변경의 의미 분석이나 자동 영향 계산은 하지 않습니다. 화면 설명과 초안 템플릿은 이 가상 예약 사례에 한정됩니다. 실제 프로젝트 payload, 원격 보고 수집, 인증, 서버, 저장소 편집, 실행, 제품 코드 통합은 없습니다.
