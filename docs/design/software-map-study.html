이 사례

VS Code 공개 자료에서 의미 차이를 뽑아 만든 설계용 합성 사례입니다. VS Code 제품 구조를 재현한 것이 아닙니다. 기본 구성 공간과 A·B·C 실험은 같은 구성·관계 데이터를 씁니다.

사례를 만들 때 참고한 출처 (이 보드에서 다시 확인하지 않음)

  • 텍스트 편집과 시각 편집이 같은 문서를 다루는 방식, 한 문서를 여러 편집창에서 여는 경우
    code.visualstudio.com/api/extension-guides/custom-editors
  • 확장이 명령을 등록해 제공
    code.visualstudio.com/api/extension-guides/command
  • 확장이 로컬·웹·원격 실행 환경 중 정해진 곳에서 실행
    code.visualstudio.com/api/advanced-topics/extension-host
  • 여러 문서에 걸친 변경을 묶어 되돌리는 요소 (고정 커밋)
    microsoft/vscode@784ce22 · src/vs/platform/undoRedo/common/undoRedo.ts

합성 가정

  • 문서 상태 관리 안의 세 부분(문서 버전·변경 반영·표현 연결)
  • 규칙: 요청한 버전보다 문서가 새로우면 늦게 온 응답은 반영하지 않음
  • 동작 장면의 단계와 버전 번호(v12·v13·v14)
  • A·B·C 실험에는 부분별 상태·담당 세션·미정 질문 가정이 더 들어 있음. 기본 구성 공간에는 쓰지 않음
