이미 설치된 Playwright와 Chromium을 쓴다. 필요시 CHROMIUM에 해당 환경 실행 파일 경로를 전달한다. 스크립트는 자기 문서 디렉터리만 임시 127.0.0.1 서버로 제공하고 브라우저 종료 후 서버를 닫는다. 외부 실행 하네스가 아니다. 출력은 인자로 지정한 경로에만 남긴다.

## 검사 중 만난 실패

- 기본 샌드박스 Chromium은 socket 권한 오류. 허용된 실행 권한으로 전용 임시 프로필 실행 성공.
- file:// 탐색은 관리자 정책 차단. 파일 방식은 중단하고 자체 시안을 localhost로 제공. 브라우저/네트워크 정책을 수정하지 않음.
- 수정 후 검사 스크립트에 숫자 속성 선택자의 따옴표 누락이 있어 한 번 실패. 테스트 선택자를 고친 뒤 72개 완료. 이를 제품 결함이나 성공으로 숨기지 않음.
- 공개체험 URL은 웹 조사 도구 접근 실패. 공개 배포 화면을 직접 검사했다고 주장하지 않음.

실제 CSV 반입/파서 설치/빌드/50MB 처리/성능/인코딩 재현/예약 중복·보안 검사, 운영앱 테스트, 새로운 고객 인터뷰, 사람 A/B 사용성 비교, 스크린리더/Firefox/Safari, 외부 Claude·Pro 실행/전달, 유료 AI, 배포·병합을 하지 않았다. 정상/오류 CSV의 T1/T2와 실패 F1은 **제안 또는 가상 기록**이다.

72개 확인이 보장하는 것은 이 HTML 예시의 검사한 동작뿐이다. 사용자의 이해도, 실제 라이브러리의 적합성, 새로운 DB의 필요성, 운영앱 통합 안정성은 입증하지 않는다.
