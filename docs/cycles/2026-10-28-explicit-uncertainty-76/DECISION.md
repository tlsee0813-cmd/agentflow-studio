## 선택한 변경

같은 원문 범위의 겹침은 의미 충돌의 근거가 아니다. 새 응답 계약에서만 후보가 무엇을 보류하는지 명시한다. 대상은 특정 진술의 귀속, 두 대상의 동일성, 특정 부모 연결, 특정 진술의 성립으로 제한한다. 응답 내부의 작은 참조를 사용할 수 있지만 전역 명제 모델은 만들지 않는다.

같은 영향대상을 확정과 미정으로 동시에 출력하거나 잘못된 대상을 참조하면 적용 전에 응답 전체를 거절한다. 후보는 기존 사실을 철회하지 못한다. 독립적인 사실은 같은 문단에 있어도 보존한다. material 예문과 제품 근거를 동시에 사용한 모순도 조용한 필터링으로 성공 처리하지 않는다.

구판 wire·저장 계약과 기존 기록의 의미는 보존한다. 과거 실패를 새 규칙으로 성공 재분류하거나 누락 사실을 소급 복원하지 않는다. 운영 모델·thinking·한도는 유지한다. 재생성 정책은 이번 계약과 실제 응답 의미를 확인한 뒤 별도 판단한다.
