## 산출물과 범위
바닐라 단일 purpose-study.html. 1440×900 /390×844에서 ‘전체 목적→소개글 재사용의 역할→필요시 원문/작은 계획 준비→진입 전 지도 복귀’를 조작할 수 있게 한다. 기존 composition05 원본 https://github.com/tlsee0813-cmd/agentflow-studio/blob/10d1f03f6944a2787079cdb49cf009c6b1fbd302/docs/transfer/composition-05/author-v0/composition-study.html 의 보존 동작을 참고하되5묶음/6관계/C32변경과 분기 없는 코드 복사는 하지 않는다. 이전검사 통과가 새파일 통과는 아니다.

전체 제품은 AI로 만드는 프로그램의 구상·구성·관계를 공간에서 이해하는 도구다. 이번 작은 입력은 **전체 공연장 사이트 구조가 아니라 기능 제안 하나의 맥락**이다. 혼합 깊이 예시를 억지로 만들지 않는다. 검사수/식별자/증거 목록/긴 상태 보고는 기본 화면에 놓지 않는다. 읽기 부담을 줄이는 여백·시각 위계·짧은 설명에 디자인 판단을 쓴다.

## 고정 내용과 구별
목적: 공연장 소개글을 홈페이지로 옮길 때 같은 내용을 다시 적는 일을 줄이기.
프로그램 부분 후보1개: **소개글 재사용**. 역할: 받은 소개글을 홈페이지에 옮길 때 다시 활용하도록 돕는 부분.
맥락2개: **출연자가 낸 소개글**은 업무 자료, **행사 홈페이지**는 옮길 대상. 프로그램 내부 모듈과 같은 카드 의미/모양으로 표현하지 않는다.
연결2개: 자료↔후보 ‘활용할 원자료’, 후보↔대상 ‘내용을 옮길 대상’. 제목·포함·이 두 연결의 도식은 AI 제안 해석이다. 실행 가능한 자동 연동이나 게시 순서가 아니다.
유지조건: **담당자가 내용을 확인하고 게시를 선택한 뒤에만 공개**. 공개를 건너뛰지 않는다는 조건을 역할 가까이 둔다. 실제 구현된 승인 모듈로 표현하지 않는다.
제안 이유: 받은 글을 다시 활용할 수 있게 하면 재입력을 줄이는 데 도움이 될 것이라는 생각. 효과는 미확인.
미정: 실제 코드·파일 구조·소개글 전달/저장 방식·홈페이지 적용 방식은 제공되지 않았다. 모르는 것을 가짜 결함/미결 이벤트/연결 단절로 만들지 않는다.
입력은 개발자 합성 초기 구상이다. N02와 연결하거나 변경 전후·완료·담당AI·기록시각·사용자승인을 만들지 않는다.
짧은 기본 설명과 구체적 조건을 먼저, 원문/해석 경계는 필요시 읽게 한다. 출처 설명을 매 문장에 반복하지 않는다.

## 실제 동작
- 같은 대상 식별자를 지도·역할·상세·준비에서 유지. 일반 선택은 지도 배치/배율을 바꾸지 않는다. 맥락 대상을 기능 구현 대상으로 준비시키지 않는다.
- 큰 화면은 공간 지도 중심. 좁은 화면에서는 선택 부분의 짧은 역할과 두 맥락 명칭을 지도를 덮지 않는 예약영역에 둔다. 화면을 모두 문장으로 채우지 않는다.
- 좁은폭에서 **지도에서 위치 보기 / 읽던 곳으로** 같은 명시 왕복. 같은 지도/native scroll을 사용하고 독립 지도를 만들지 않는다. 상대 위치는 시야만 옮기고 원래 선택을 유지한다. 본문읽기 위치는 따로 보존한다. 자연스레 이미보이는 대상을 이동한척하지 않는다.
- 전체맞춤이 필요하면 새 시야 계산으로 명시한다. **진입 전 보기 복귀**와 섞지 않는다. 기능이 불필요하면 fit-all을 새로 만들 필요없다. 폭 전환까지 보장하지 않으면 제한을 명시.
- 집중 진입 때 선택/지도 위치/배율/native scroll을 저장하고, 여러 맥락 왕복이 최초 저장값을 덮지 않는다. 돌아올 때 실제rect도 확인. 이 표본에는 접기깊이가 없으므로 depth검사를 통과로 세지 않는다.
- 원문 미리보기는 열기/닫기/같은근거 재열기/Escape를 지원하며 닫힌 실제 본문·링크·버튼이 남지 않게 한다. 읽던 위치와 출발초점을 유지한다.
- ‘작은 계획 준비’는 편집가능하다. 먼저 만들 작은 작업을 정리해보는 요청이고 실제 실행/전송/배포/수락이 아니다. 직접수정은 닫기/재열기/전체복귀 후에도 남는다. 유지조건과 운영홈페이지 직접배포금지 경계를 기본문에 포함한다. 자동게시 지시·지도전체구현목록을 생성하지 않는다.
