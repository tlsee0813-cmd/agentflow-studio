# Cycle06 입력 후보 — 공연장 소개글 재입력 줄이기 (N01)

**추천: 목적과 한 부분의 역할을 설명하는 연구용 합성 표본. 실제 사용자 발화나 실제 요구 변경 이력으로 채택하지 않는다.** 고정 자료 두 파일만 읽었다: 제품 방향 2~5절과 QUALITY024 NEW_INPUTS. 다른 요청 모음·코드·대화는 열지 않았다.

1. **출처 성격.** [NEW_INPUTS L1–3](https://github.com/tlsee0813-cmd/agentflow-studio/blob/9b4a422f4e46085acb0841e9d9201c7ff86d6b81/docs/research/quality024/NEW_INPUTS.md#L1-L3)은 개발자가 설계한 합성 입력이며 고객 조사 재현이 아니라고 명시한다. 이 문서 작성 시 실제 모델 호출도 없었다. 말투가 1인칭이어도 사람의 원발화라고 인용하지 않는다.
2. **후보는 N01 한 개.** [N01 L5–7](https://github.com/tlsee0813-cmd/agentflow-studio/blob/9b4a422f4e46085acb0841e9d9201c7ff86d6b81/docs/research/quality024/NEW_INPUTS.md#L5-L7)의 목적은 출연자가 낸 소개글을 행사 홈페이지로 옮길 때 같은 내용을 다시 적는 일을 줄이는 것이다. 홈페이지 전체 개편이나 게시 자동화로 확대하지 않는다.
3. **보존할 조건.** 담당자가 내용을 확인하고 게시를 선택한 뒤에만 공개하는 방식은 유지한다([L7](https://github.com/tlsee0813-cmd/agentflow-studio/blob/9b4a422f4e46085acb0841e9d9201c7ff86d6b81/docs/research/quality024/NEW_INPUTS.md#L7)). 이는 합성 상황 안에서 명시된 현재 조건이지 실제 운영 절차를 검증한 결과가 아니다.
4. **현재 요청의 수준.** 코드를 모르는 사람을 위한 ‘먼저 만들 작은 작업’ 정리가 요청됐고, 실제 코드·파일 구조는 제공되지 않았으며 운영 홈페이지 직접 배포는 금지됐다([L7](https://github.com/tlsee0813-cmd/agentflow-studio/blob/9b4a422f4e46085acb0841e9d9201c7ff86d6b81/docs/research/quality024/NEW_INPUTS.md#L7)). 요청 자체를 이미 허가된 구현·배포·인계 수락으로 바꾸지 않는다.
5. **확인된 순서와 없는 시간.** 소재인 출연자 소개글 → 홈페이지로 옮기는 일, 담당자 확인·게시 선택 → 공개라는 관계까지 읽을 수 있다. 메시지는 한 개뿐이므로 이후 요구 변경·AI 수행·사용자 승인·수정 전후 결과나 시간 순서를 추가하지 않는다. N02는 독립 프로젝트 변형이라고 명시됐으므로 N01의 변경 후 상태로 이어 붙이지 않는다([L3–11](https://github.com/tlsee0813-cmd/agentflow-studio/blob/9b4a422f4e46085acb0841e9d9201c7ff86d6b81/docs/research/quality024/NEW_INPUTS.md#L3-L11)).
6. **허용할 구성 해석.** ‘소개글 재사용’ 같은 기능 이름을 AI 제안으로 두고, 그 역할을 ‘재입력 감소에 기여하면서 확인·게시 선택을 건너뛰지 않음’으로 설명할 수 있다. 담당자 확인·게시가 관련 맥락이라는 것은 원문에 근거하지만, 별도 모듈/포함 구조·입력 폼·저장 방식·CMS·자동 연동·담당 AI는 정해져 있지 않다. 제안 자체를 금지하지 않되 사실과 구별한다.
7. **연구 적합성과 한계.** [방향 3절 L54–62](https://github.com/tlsee0813-cmd/agentflow-studio/blob/9b4a422f4e46085acb0841e9d9201c7ff86d6b81/docs/PRODUCT_DIRECTION_AND_RESEARCH_PLAN_KO.md#L54-L62)의 프로그램 구성·전체와 부분·코드 이전 구상에 맞춰, **전체 목적을 본 뒤 선택한 부분이 왜 필요한지와 무엇을 바꾸지 않는지가 읽히는가**를 볼 수 있다. FLOW091의 시스템 내부 사본 계약과 달리 외부 생활 업무의 목적/보존 조건을 다루므로 입력 성격을 바꾼다. 다만 합성 표본이므로 실제 업무 대표성·변경 추적·자동 정리 정확도·사람 이해도를 입증하지 못한다.

이 후보는 지도 설문이나 승인 숙제를 새로 요구하지 않고 목적→부분 역할→보존 조건을 설명하는 최소 입력으로만 사용한다. 실제 구현 이력이나 완성 모듈 트리를 덧붙이지 않는다.
