# UI-02 수용 기준·fix3 증거와 독립 화면 검증 상태

기준: [UI_NEXT.md](UI_NEXT.md), [UI_RESEARCH.md](UI_RESEARCH.md). 초기 6개 수용 기준을 보존하면서 현재 `canvas-study.html` fix3의 작성자 실행, 독립 상태 검사, 정적 화면 관찰과 **독립 클라우드 실제 브라우저 실행의 원본 감사**를 구분한다. manifest의 13개 파일 크기·해시와 PNG 5장의 직접 열람을 포함한 [원본 감사](evidence/ui02/cloud-fix3/REPORT.md)가 완료되었다. 6개 화면 기준 전체의 통과를 뜻하지 않는다.

- **보존한 이전 근거:** [fix1 작성자 근거](evidence/ui02/author-fixed/REPORT.md)와 [fix1 독립 5개](evidence/ui02/independent/REPORT.md)는 HTML 해시 `869C76A45F16042EC0A5063C81D1E638D21A2A3E87CE079B6BC5A60843632157`의 당시 범위다. [초도 정적 검토](UI02_VISUAL_REVIEW.md)는 초도 해시 `D0F3B7D378563B620AAA0EBFEC34397F416B5D62B8D2F9D14DF576B4F507840A`의 PNG 13개 중 7장을 열람한 기록이다. fix1 PNG 17개나 fix3 4장과 합산하지 않는다.
- **독립 실제 브라우저 실행:** [고정 전달 원본](https://github.com/tlsee0813-cmd/agentflow-studio/tree/9afe18444d92cf5930e0af5406ad7efce309d7c7/docs/transfer/ui02-fix3/)의 실제 Chromium 154.0.8037.57 / Playwright 1.57.0 HTTP 실행이다. 1440×900·390×664·390×844의 S1/S2/S3를 실행했으며 [원본 감사](evidence/ui02/cloud-fix3/REPORT.md)에서 재집계한 최초 결과는 **85 통과 / 1 실패**, 최종은 **86 통과 / 0 실패**다. 이는 이 스크립트의 확인 묶음 수이며 위 작성자·Node 수치와 합산하지 않는다. 감사자는 원본 코드·JSON·PNG를 대조했으며 브라우저를 새로 재실행한 것은 아니다.

**기존 합격 기준 9의 위치별 누락은 fix3에서 수정되었고 해당 독립 상태 검사는 통과했다.** 클라우드 스크립트는 L1/L2/L3의 A2 행 배지와 이동·복귀, B 미결의 소유·직접 이동, C의 `cv-open` 이동·복귀를 실제 브라우저에서 확인했다. 다만 C의 `cv-chg` 및 소유 문구는 별도 단언하지 않았고, A4/A6 비전파는 상세의 미결 칩·상단 변경 칩만 검사했다. 모든 카드·끝점 행의 비전파나 6개 화면 기준 전체의 통과로 넓히지 않는다.

최초 실패는 390×664 S3의 A2→B 버튼 hit-test 실패이며 sticky header 가림으로 보고되었다. HTML은 바꾸지 않고 검사 helper에 `scrollIntoView({block:'end'})` 재배치를 추가한 뒤 최종 실행이 통과했다. 목록 위치도 DOM `scrollTop=120` 대입으로 설정했다. 따라서 추가 DOM 스크롤 뒤의 도달·클릭·복원을 확인한 것이며 **휠·터치 입력은 미실행**, 모든 스크롤 위치의 sticky header 가림 없음은 미확인이다. 새 Cloud 작업에서 환경을 복원한 실행도 아니다.

원본 검사기의 `finally` 안 `sys.exit`가 `run()` 밖 예외를 정상 종료로 덮을 수 있는 한계도 발견했다. 최종 JSON에는 예정된 86개 확인 묶음이 모두 있어 이 결과가 조기 중단됐다는 정황은 없으며, 결과를 폐기하지 않는다. 그러나 종료 코드만으로 완주·예외 검출을 보증할 수 없다. 최초 85/1의 JSON·로그는 보존되었지만 당시 helper 코드의 별도 스냅샷은 없어 정확한 전후 코드 차이를 독립 복원할 수 없다.

의미 보존 검사는 데이터의 관계 수·소유·버전·인계 내용을 판정한다. 이 평가는 같은 내용을 사용자가 화면에서 구별하고 찾아가며 돌아올 수 있는지를 판정한다. Dify 이상의 완성도 목표를 카드 장식이나 색상 유사성으로 평가하지 않는다. 아래를 통과하더라도 최종 제품 완성도나 Dify보다 우수함을 증명한 것은 아니다.

## 공통 관찰 조건

## 판정 규칙

각 항목의 **통과 / 실패 / 미실행**은 대상 해시·실제 수행 범위·화면 근거에 한정해 판정한다. 현재 표는 상태 검사·실제 브라우저 실행·남은 감사와 미관측을 함께 기록하며, 전 항목 미실행이나 전 항목 통과로 요약하지 않는다. 작성자 실행 횟수, 독립 상태 검사 수, 클라우드 확인 묶음 수, 읽은 이미지 수를 합산한 ‘총 통과 수’도 만들지 않는다.

캡처 한 장이나 작성자의 코드 설명만으로 상호작용을 통과 처리하지 않는다. 실패는 외관 취향과 구별하여 ‘어떤 조작에서 어떤 정보·맥락을 잃었는지’로 적는다. 핵심 행동을 막거나 구조·변경을 오해시키는 실패가 남으면 해당 표현의 수용은 보류한다. 이 틀은 첫 시안의 반복 개선 기준이며 사용자 이해도 검증을 대신하지 않는다.


검증기 종료 처리도 별도로 보완했다. [보완 코드·원본 결과](https://github.com/tlsee0813-cmd/agentflow-studio/tree/b03f908c9a1ac23b56218d0fccc43fa3747fe061/docs/transfer/ui02-fix3/evidence-hardening)와 `check.hardened.py`는 기존 자료를 덮지 않고 추가됐다. 정상 실행은 동일 86그룹·exit 0, 의도적 설정 예외는 0그룹·미완주·fatal 기록·exit 1이며 외부 프로세스 종료코드도 일치했다. 이는 검사기의 오류 종료 보완이고 위 화면 검사 범위를 넓힌 결과는 아니다. 상세 코드·JSON 감사는 [클라우드 감사 보고](evidence/ui02/cloud-fix3/REPORT.md)의 별도 절을 따른다.
