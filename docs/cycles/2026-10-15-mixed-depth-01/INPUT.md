# 혼합 깊이 탐색 비교 입력

모든 A/B 내용·이벤트·열람 기준·배정 식별자는 합성이다. 실제 GitHub 표본과 섞어 실측으로 보고하지 않는다.

## 고정된 의미

프로젝트 목적은 작은 도서 대여 서비스를 구상하고 부분을 외부 개발 세션에 이어 맡기는 것이다. A는 대여 경험, B는 알림 구상이다. A의 자식은 A1 도서 찾기, A2 대여 신청, A3 내 대여 목록, A4 반납, A5 운영 검토, A6 연체 처리다. B는 아직 세분화하지 않았다. 구조 노드와 작업, 세션은 별개다.

| 순서 | 합성 원본 내용 | 반드시 보존할 것 |
|---|---|---|
| E01 | A와 B는 관련 있다. 어떤 자식이 관련되는지는 아직 정하지 않았다. | 상위 범위 관계, 하위 대상 미확인 |
| E02 | A를 A1~A6으로 상세화한다. B에는 자식을 만들지 않는다. | A의 포함 관계만 추가. A1~A6에 B 연결을 자동 복제하지 않음 |
| E03 | 기존 A–B 관련성의 구체 대상은 A2·A4·A6이다. A1·A3·A5와 B의 연결은 이번 관측에 없다. | 실제 관측 관계는 세 개. 관측 없음은 미래에도 관계 없음이라는 주장과 다름. 기존 상위 관계는 구체화된 이력으로 보존 |
| E04 | A2 설명을 ‘신청 즉시 확정’에서 ‘재고 확인 뒤 확정’으로 바꾼다. 결정 D2는 ‘신청 시 알림’에서 ‘대여 확정 후 알림’으로 대체한다. 실패 알림 정책은 아직 결정하지 않았다. | 이전/현재 설명·결정, 변경 이유(재고 불일치 방지), 미결 정책, A2–B 관계 유지 |
| E05 | 사용자가 E03까지 보았다고 가정하고 돌아온다. E04를 보고 A2의 실패 알림 정책 검토를 새 세션 후보 SESSION-02에 인계문으로 준비한다. | 마지막 열람은 합성 로컬 기준. 작업 W2 범위는 A2, B는 관계 맥락. 현재 결정·미결·근거 포함. 인계 준비는 실제 전달/수락이 아님 |

세 장면: S1=E01~E02, S2=E03~E04, S3=E05. 세 장면은 비교용 독립 스냅샷이며 순서대로 눌러도 마지막 열람 기준을 갱신하지 않는다. S3에 들어가면 항상 합성 열람 기준 E03/현재 반영 E04로 시작한다. 확대 비율을 바꿔도 내용의 상세 수준은 바뀌지 않는다.

## 동일 내용의 비교안

- 안 A: 전체 구상에서 영역별 펼침. A를 펼쳐도 B를 같은 화면에 유지. E03 이전에는 접거나 펼쳐도 ‘A–B 관련, 세부 대상 미확인’으로 표시한다. E03 이후 A를 접으면 ‘A 하위 3곳이 B와 관련’이라고 표시하고 실제 A2·A4·A6 목록으로 바로 이동. 선택 패널에서 설명·결정·변경·인계.
- 안 B: 선택 영역에 진입하고 경로로 복귀. A 내부를 볼 때 B를 외부 관련 부분으로 남기며, 원본 B와 같은 식별자를 참조한다. 관계 목록을 펼쳐 실제 출발점으로 이동. 전체 복귀 시 직전 위치·선택을 유지.

현재 잠정 선택은 A를 기본으로, 내용이 많거나 A2에 집중할 때 B를 보조 경로로 제공하는 조합이다. 연구 결과와 반례 검토에 따라 변경한다. 전역 상세 단계·자동 의미 줌은 기본 조작으로 채택하지 않는다.

## 합격 기준과 선택을 바꾸는 반례

1. S1: A의 세분화만으로 하위 관계가 생성되지 않고 B가 사라지거나 가짜 자식이 생기지 않는다.
2. S2: 접기/펼치기 왕복 뒤 실제 세 관계와 A2 결정 대체 이력이 유지된다.
3. S3: 마지막 열람 이후 변화, 반영 범위, 미결을 이해하고 전체를 다시 읽지 않고 A2 인계문을 준비할 수 있다.
4. 집계 연결의 숫자는 실제 끝점 수이며 실행 순서·완료율이 아니다. 실제 목록을 한 번에 열 수 있다.
5. A2 인계에는 프로젝트 목적, A2 범위/기준, B 관계, 현재 결정, 이전 결정 대체, 미결, 근거, 작업·후보 세션을 담되 SESSION-02가 수신했다고 주장하지 않는다.
6. 알려진 상위 관계만 있을 때와 자식 관계가 확인된 때를 구별한다.
7. 시안의 통과는 합성 입력의 동작 검증이다. 실제 자동 추출 품질·사람 사용성·외부 전달 성공을 입증하지 않는다.
8. E03 이후 원래 A–B는 구체화 이력으로 남기고 네 번째 실제 관계로 집계하지 않는다. 이는 이 합성 사례의 명시적 구체화 조건이며 모든 상위 관계를 자동 소거하는 일반 규칙이 아니다.
9. 접힌 A·실제 끝점 목록·B의 상세에서도 ‘A2 관련 결정 변경 1건’과 A2 소유 미결의 참조를 제공한다. 관련 결정 변경을 관계 자체의 추가·삭제로 바꾸거나 A4·A6의 변경으로 전파하지 않는다.
10. 안 B에서 전체로 복귀하면 직전 펼침·선택을 보존한다. 새로 선택한 외부 부분이 원본 복제본이 되지 않는다.
