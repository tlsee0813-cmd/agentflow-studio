# 다음 작은 작업: 실제 캔버스 표현 연구

작업 ID UI-02 · 담당 Claude Opus · 원격 쓰기 없음 · 반환 파일 canvas-study.html 및 작성자 검사 근거

## 목적·입력

첫 의미 시안의 합성 INPUT을 유지하면서 Dify에서 참고한 정보 밀도·선택 상세·공간 조작을 AgentFlow의 계층 탐색에 맞게 표현한다. 현재 시안의 긴 설명 카드들을 그대로 예쁘게 꾸미는 것으로 끝내지 않는다. 전체 제품이나 최종 UI를 확정하는 작업도 아니다.

INPUT.md, UI_RESEARCH.md, RESEARCH.md와 현재 prototype.html이 기준이다. 의미 시안은 별도 보존하고 canvas-study.html 하나를 새로 반환한다. 라이브러리 설치·제품 소스 수정·배포·원격 쓰기·다른 세션 배정은 하지 않는다. 직접 작성한 HTML/CSS/SVG/JS만으로 독립 열기가 가능하게 한다. Dify의 코드를 복사하지 않는다.

## 비교할 경험

같은 S2에서 A4를 보다가 A2의 결정 변경과 B 관계를 읽고 A4로 돌아온다. 전체 공간의 부분 펼침과 A 내부 집중+외부 B 참조를 비교한다. 전환은 명시적 조작으로 하며 배율만으로 포함 깊이가 바뀌지 않는다. 긴 설명을 읽는 집중과 관계를 비교하는 펼침의 차이를 분명히 만든다.

## 반드시 지킬 의미

- A만 여섯 하위 부분, B는 미세분화. S1의 상위 관계는 자식 대상 미확인이며 자식 관계를 만들지 않는다.
- S2 이후 A2/A4/A6–B 세 실제 끝점만 존재한다. 포함 경계·의미 관계를 구별하고 근거 없는 화살표를 쓰지 않는다.
- 접힌 A는 '연결된 하위 3곳'에서 이름과 실제 원래 관계를 확인할 수 있다. 상위 관측 이력은 네 번째 현재 관계가 아니다.
- A2의 결정 변경은 A2 소유. B에는 관련 참조로 보이고 A4/A6에 변경을 전파하지 않는다.
- 카드에는 짧은 정보만, 선택 상세에는 설명·현재 결정·변경 전후·이유·근거·미결. 구조·작업·세션 식별자를 섞지 않는다.
- S3 E03 열람/E04 반영 고정, W2/A2 인계는 프로젝트 목적과 작업 목적·B 참고·SESSION-02 후보·준비/미전달을 유지한다.
- 돌아오면 목적지별 선택·펼침·목록·위치/배율이 복원된다. 데이터 변경을 되돌리는 동작과 구분한다.

## UI 품질의 구체적 관찰점

1440폭에서 A의 경계·여섯 부분·B·선택 상세를 읽을 수 있어야 한다. 패널이 B를 가리거나 매 클릭마다 전체맞춤으로 글씨를 작게 만들면 실패다. 포함 경계와 선이 겹쳐 관계 대상을 오해하면 실패다. 선택/변경/미확인 상태는 색 하나에만 의존하지 않는다. 버튼 이름·키보드 초점·390폭에서 핵심 정보를 찾는 방법을 제공한다. 데스크톱 캔버스를 무작정 줄여 모바일 통과로 보고하지 않는다.

## 반환과 수용

먼저 가능한 시각 구성 두 가지를 짧게 비교하고 하나를 선택한 이유를 설명한다. 그 한 구성을 클릭 가능한 파일로 반환한다. 선택을 바꿀 구체적 약점도 쓴다. 작성자 코드/상태 검사와 실제 브라우저 화면 검사를 분리하고 테스트 파일·출력을 함께 반환한다. 렌더링을 하지 못했다면 그대로 미실행이라 보고한다. 총괄이 독립 검토·실행 담당과 수용 여부를 판단한다.
