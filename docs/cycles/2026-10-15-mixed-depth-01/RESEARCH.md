# 탐색 메커니즘 조사와 총괄 판단

확인일: 2026-10-15 · 질문 Q03·Q04 · 입력 SHA 73fc284026f2f5140e9c972a496c77ca0931eabf.

웹 ChatGPT UI Pro가 네 사례를 조사했고 총괄이 아래 공식 원문을 직접 대조했다. 이는 문서의 작동 설명 확인이며 해당 서비스 안에서 세 합성 장면을 실행한 결과가 아니다. 코드나 라이브러리를 가져오지 않았다.

## 네 분야의 비교

| 사례와 원문 위치 | 원래 문제와 확인한 작동 | AgentFlow 적용 판단 | 맞지 않는 조건과 비교 장면 |
|---|---|---|---|
| [Workflowy Navigate around](https://workflowy.com/help/navigate-around), Zoom into a node / Expand and collapse | 긴 개요에서 한 가지를 펼치거나 항목 내부에 진입하고 경로로 부모·전체에 복귀 | 펼침과 진입을 분리하고 부분별 깊이를 유지 | 진입하면 바깥이 숨겨지므로 B 관계 유지 장치가 별도 필요. S1의 B 공존, S3 복귀 검사 |

| [Structurizr Implied relationships](https://docs.structurizr.com/dsl/implied-relationships), 예제 / Configuring implied relationships | 명시적 하위 관계에서 상위 관계를 유도하고 규칙을 설정 | 하위 관계의 접힌 표현을 만들되 원래 끝점·의미를 보존 | 기본 중복 억제 규칙을 그대로 쓰면 여러 관계 의미·개수를 잃을 수 있음. 상위 관계에서 모든 자식 연결을 생성하는 근거가 아님 |

Kumu는 Pro 조사에서 원문 열기가 실패해 검색 수집 본문에 의존했으나, 총괄의 직접 열기에서는 도입부와 Focus direction 본문을 확인했다. 확인의 수준을 문서 근거로 상향하며 실제 UI 조작 경험으로 확대하지 않는다.

## 총괄 선택

안 A의 전체 공간에서 부분별 펼침을 기본으로 삼고 안 B의 부분 집중·경로 복귀를 보조로 제공한다. A가 세분화되고 B가 세분화되지 않은 상태를 직접 비교하기 쉽고, 집중이 필요한 A2에서는 B를 외부 참조로 남길 수 있기 때문이다. 이는 세 합성 장면에 대한 설계 선택이며 실제 사용자 효율 우위가 입증된 것은 아니다.

전역 상세 단계는 보류한다. 첫 장면에 필요하지 않고 A와 B의 다른 깊이를 일괄 수준으로 맞출 위험을 더하기 때문이다. 확대 비율은 구조의 상세 수준과 독립적으로 둔다.

관계를 접는 행위는 표시를 바꾸는 것이다. E03 이후 집약의 근거는 A2·A4·A6의 명시된 끝점이며, E01~E02의 상위 관계는 하위 대상 미확인 상태다. 둘을 같은 ‘3개 연결’로 표시하지 않는다.

## Claude 반례의 채택과 수정

[Claude Opus 5.5 높음 검토 세션](https://claude.ai/chat/6253f2e8-4c9a-4ae6-81e1-76250803bd93)의 반례 3개를 검토했다.

1. 상위 관계가 펼침 중 사라지거나 나중에 네 번째 관계로 중복될 수 있다. 미확인 단계는 A 영역에 붙이고 E03의 명시적 구체화 이후 세 실제 끝점으로 표시한다. 이전 상위 관측은 이력에 남긴다. 이 입력의 구체화 조건을 모든 상위 관계 자동 삭제 규칙으로 일반화하지 않는다.
2. A2의 결정 변경이 B 쪽에서 숨겨질 수 있다. 접힌 A·관계 목록·B 상세에 ‘A2 관련 결정 변경 1건’을 참조로 노출한다. Claude의 ‘관계 자체 변경’ 해석은 그대로 채택하지 않는다. 이 사례는 끝점 유지와 관련 정책 변경을 구분한다.
3. 재방문과 인계가 A2 패널 속에만 있으면 다시 탐색해야 한다. 변경에서 A2로 바로 이동하고 인계문에 A2·B 맥락·현재 결정·미결을 포함한다. 작업 W2·후보 SESSION-02와 준비·미전달 상태를 별도로 둔다.

별도 Codex 계약 검토에서 찾아낸 열람 기준 갱신 모호성, 접힌 표시 시점 조건, S2 이름 중복은 INPUT.md에 수정했다. Claude의 반례 검토 후 같은 Claude가 시안을 구현하므로 구현 후 자기 검사는 독립 검토로 세지 않는다.
