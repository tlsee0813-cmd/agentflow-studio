# UI 디테일 연구 — 의미 비교 다음 단계

2026-10-15. 사용자는 Dify 이상의 완성도를 지향하되 AgentFlow 목적에 맞춘 계층·부분별 깊이·관계·변경 경험을 반복 연구하도록 요청했다. 현재 prototype.html은 의미 보존용이며 완성 UI가 아니다.

## Dify 관찰·조사·판단의 구분

총괄은 사용자가 연 Dify 편집 화면의 선택 동작과 화면 구성을 관찰했다. 넓은 점무늬 캔버스, 작은 카드와 곡선 연결, 선택 표시, 우측 상세, 선택 대상으로 이동하는 조작이 있었다. 실행·발행은 수행하지 않았다. 사용자 앱 내용·계정 화면은 프로젝트 자료에 복제하지 않는다.

웹 Pro가 공식 고정 코드 3파일을 정적으로 조사했고 내부 독립 검토자가 같은 원본을 읽어 [근거와 제한](EVIDENCE_CROSSCHECK.md)을 확인했다. w-60은 비컨테이너 카드에 적용되고, 테두리는 선택 외 상태에도 사용된다. 패널 폭 관측은 드래그 크기 조절의 증거가 아니다. 시각 패턴 참고이며 코드 재사용 허가 판정은 하지 않았다.

| 항목 | 다음 시안의 총괄 지시 | 피해야 할 실패 |
|---|---|---|
| 정보 위계 | 카드에는 이름·짧은 목적·세분화 상태·변경 종류. 전문은 선택 상세 | 카드에 모든 기록을 쌓거나 세션을 구조의 자식으로 배치 |
| 포함과 관계 | A 내부 여섯 부분, B는 밖. 실제 A2/A4/A6–B만 | B의 가짜 하위, 근거 없는 방향 화살표 |
| 접힌 표현 | 표시 집계와 원본 관계 분리. 끝점 목록에서 대상 이동 | 상위 관계를 모든 자식으로 복제, 숫자만 보이고 대상 못 찾음 |
| 선택과 펼침 | 카드 선택과 펼침 조작 분리, 현재 경로 명확히 | 선택 때마다 구조가 변해 위치를 잃음 |
| 패널과 공간 | 자동 전체맞춤/재배치 없이 선택·외부 B를 유지 | 패널이 B를 가리거나 전체 축소로 글씨가 안 보임 |
| 변경·인계 | 현재·변경·인계 연결, 프로젝트와 작업 목적 구분 | A2 결정 변경을 관계 자체 변경으로 읽음, 준비를 전달로 표시 |

Pro의 ‘하위 관계 3개’ 표현은 이번 입력에 맞지만 다음 시안에는 ‘연결된 하위 3곳’과 실제 목록을 사용한다. 관계 수와 서로 다른 끝점 수는 다르다. 같은 A2–B에 두 종류 관계가 있어도 하위 부분이 4곳이 되지 않는다.

## 변화 표시·인계의 보조 근거

[GitHub Viewed 표시](https://docs.github.com/en/pull-requests/how-tos/review-pull-requests/reviewing-proposed-changes-in-a-pull-request#marking-a-file-as-viewed)는 봤다고 표시한 파일에 새 변경이 생기면 표시를 되돌린다. Pro 조사 후 총괄이 원문을 확인했다. 수신·반영·열람을 분리하는 원리만 반영하고 모든 변경의 수동 확인 의무는 채택하지 않는다. S3 E03 열람/E04 반영은 합성 고정값이며 실제 열람 측정이 아니다.

고정 커밋 링크는 기준을 재현하지만 수신·읽음·이해·수행을 증명하지 않는다. [공식 근거](EVIDENCE_CROSSCHECK.md)에 따라 W2 인계는 A2 범위·입력 버전·B 참고·현재/이전 결정·이유·미결·완료조건을 명시한다. SESSION-02는 후보이고 준비·미전달이다. 결과 수신과 완료 수용도 구분한다.

## OSS는 채택 보류

[React Flow·X6 조사](UI_OSS.md)는 공식 버전·예제·라이선스와 자체 구현 경계를 확인했다. 중첩·선택은 기반 후보지만 원래 끝점·표시 집계·외부 맥락·복귀 상태는 제품이 작성해야 한다. X6 전체 공개 예제는 중첩 접힘 상태를 고려한다. React Flow 고급 접기 예제는 별도 Pro 콘텐츠이고 dagre 그룹 안팎 연결 배치 한계도 있다.

라이브러리 채택·제품 재작성은 결정하지 않았다. 추가 계층 탐색 조사와 실제 화면 검사로 현재 조합을 바꿀 구체적 실패가 있는지 확인한다.

## yEd·Blender 보조 연구의 통합

별도 Pro 결과를 독립 검토자가 [yEd 공식 Grouping Support](https://yed.yworks.com/support/manual/hierarchy.html)의 원문과 대조했다. yEd는 같은 공간에서 그룹 열기/닫기와 내부로 진입하기를 구분하며, 닫을 때 대표되는 기존 연결을 다시 열면 복원한다고 설명한다. Structure View의 전체 계층과 Overview의 현재 그래프 축소판은 다른 역할이다.

이 문서는 이전 선택·스크롤·배율의 일괄 복원, 외부 B의 지속 참조, 실제 끝점 수와 목록을 보장하지 않는다. 그 요소는 AgentFlow 자체 요구로 남긴다. Blender는 Pro가 확인한 2.90 Outliner·4.1 Local View의 검색 노출 본문에 한정된 보조 참고다. 최신 직접 검증이나 yEd와 합산한 실행 증거로 쓰지 않는다. yFiles 데모도 yEd 기능으로 합치지 않는다.

현재 선택은 관계 비교에는 부분 펼침, 긴 설명/결정 읽기에는 명시적 집중이다. ‘이전 화면’이라는 방문 복귀와 ‘전체’라는 구조 경로는 의미를 구별하면서 목적지의 직전 보기 상태를 보존한다. 비교 장면은 A4를 보다가 A2 변경과 B 관계를 읽고 A4로 돌아오는 것으로 좁혔다.
