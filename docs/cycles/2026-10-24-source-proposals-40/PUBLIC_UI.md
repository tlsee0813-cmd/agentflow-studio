# 공개40 총괄 화면 확인

2026-10-24 KST, source44cfc9ade567b3b7cfe66af57d9762d5bf1ead39, 배포d2ecd38141384ce54b69563f2512a15beb4a53f8. 기존 https://tlsee0813-cmd.github.io/agentflow-studio/ 를 실제 in-app browser에서 조작했다. [HTTP19파일 일치](HTTP_VERIFICATION.json)는 별도 네트워크 확인이다. 첫 게시 직후 BUILD는 이전판200을 반환했고, 전파 후 같은 검사에서 최종source·19파일 모두 일치했다.

1. 빈 프로젝트 홈에서 ‘기록 제안 검토 열기’→빈 검토→명시 ‘검토 예제 열기’→E01 원문을 읽었다. quote hash 재계산 일치와 원본 행 hash 미검증 문구가 구별됐다.
2. ‘C1 제안으로 돌아가기’→‘닫고 돌아가기’ 후 홈의 검토 진입 버튼으로 초점이 돌아왔다. 검토가 프로젝트 목록에 생기지 않았다.
3. 같은 공개 홈에서 ‘동네 미용실 예약’ 예제→‘시간 고르기’ 하위 영역→요청 읽기→‘작업 화면으로’→후속 확인 작업문 초안 화면→‘출발한 지도 보기로’를 실행했다. 원래 영역의 요청 버튼으로 돌아왔다.
4. ‘예제 닫기’ 후 프로젝트 목록은 여전히 비어 있었다. ‘새 프로젝트’를 누르자 예제 내용 없이 목적·요청 빈칸과 첫 작업 대기 화면이 열렸다. 이 명시 동작으로 브라우저 안에 빈 ‘나의 프로젝트’가 새로 생긴 것은 정상이다. 실제 AI 호출/외부 실행은 하지 않았다.

공개 확인은 현재 IAB 크기의 정상 왕복이다. 1280×720·1440×900의 기하·초안/전체storage bytes·분리·변조·HTML 반례는 별도 [독립 실행](independent40/REPORT.md)과 대표PNG에 있고, 공개에서 그 전체 검사를 재실행했다고 하지 않는다. 기존 지도 저배율 글씨 한계와 사람 사용성 미검증은 남아 있다.
