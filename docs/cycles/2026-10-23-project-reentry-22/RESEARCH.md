- [VS Code Source Control](https://code.visualstudio.com/docs/sourcecontrol/overview)는 바뀐 파일, 버전 diff, 파일 이력을 각각 다룬다. 원문에서 제공하지 않는 열람 기준을 추정하지 않는다. 코드diff를 사용자 프로그램 의미의 자동차이로 바꾸지도 않는다.

## Dify 실제 제한 재진입 관측
2026-10-23 KST 총괄은 기존 Dify 탭에서 User Input 설정 패널을 연 뒤 Studio→같은 프로젝트 카드→워크플로로 돌아왔다. 같은64%와400px 설정 패널이 다시 보이는 것을 AX와 화면으로 확인했다. 정확pan좌표·다른세션·새변화/읽음 비교·전체서비스 사용성을 검증한 것은 아니다. 내용 입력·실행·게시·설치 없이 마지막에 패널을 닫았다. 자동저장 시각이 바뀌어 viewstate 저장 가능성은 배제하지 않으며 데이터 바이트 불변을 주장하지 않는다.
