## 총괄의 제품 결정

- 지도를 기본 작업 공간으로 삼고 부분 선택과 들어가기를 구별한다. 넓은 지도, 우측 선택 맥락, 명시적인 부분 열기/작업 이어가기를 연결한다.
- PC 지도 위쪽에 여러 안내/관리 행을 쌓지 않는다. 프로젝트 이름/경로/저장상태는 간결한 shell, 예제는 비저장 표시와 종료/내 프로젝트 시작을 유지한다. 상세 목적/관리/원문은 요청 시 펼친다.
- 작업 이어가기는 현재 부분/작업과 초안/전달 행동을 먼저 보여 준다. 목표/요청/보고/조건의 중복된 요약을 기본 화면에 연속 배치하지 않는다. 실제 수행/미검증 경계는 숨기지 않는다.
- 지도 글자를 화면에 맞춘다는 이유로 8~11px로 축소하지 않는다. 기존 가독성 연구의 충돌/긴 이름/끝점 위험을 반영한다. 저장된 카메라/선택/접힘은 다시 맞추지 않는다.
- 홈은 새 프로젝트/예제의 의미를 명료하게 연결하는 작은 조정만. 신규 기능, 연결기, 출처 검토 확장, domain/storage 계약 변경은 제외.
