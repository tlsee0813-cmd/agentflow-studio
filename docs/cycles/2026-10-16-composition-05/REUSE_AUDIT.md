## cycle05에 남길 의미 있는 검증 — 최대8개

아래는 **제안·미실행**이다. 1440×900/390×844에서 같은 작은 흐름을 시작하되 각 위험에 필요한 장면만 남긴다. 새 입력에 없는 미결·관계·수신자를 시험용 실제 사실로 발명하지 않는다.

1. **입력 의미와 첫 이해 경계:** 대상·문서 기준·변경 소유·관련/미지정의 의미가 원자료와 맞고 합성 cycle01 사실이 섞이지 않는지 대조한다. 첫 화면 노출은 실제 이름/설명/참조를 나눠 기록하며 노출 픽셀을 사람 이해 성공으로 판정하지 않는다.
2. **혼합 깊이 보존:** 다른 영역 두 곳을 서로 다른 깊이로 직접 조정하고 부분 선택→집중까지 진행한다. 해당 조정·현재 선택·외부 대상의 동일 ID가 유지되는지 전후 비교한다. 임의 전 영역 접힘/확장/전체맞춤은 실패다.
3. **미결 소유·집계:** 실제 입력에 미결이 있으면 접힌 요약→끝점 목록→상세에서 같은 항목·소유·직접 이동을 확인한다. 같은 미결 중복 집계, 다른 대상 전파, 기준 전 시점의 미래 미결 노출은 실패다. 입력에 없으면 해당 없음으로 남긴다.
4. **관계 의미·끝점:** 선택/깊이 변경 뒤 정확한 끝점 ID 집합·소유를 비교한다. 개수만 같음은 부족하다. 외부 참조 복제·미지정의 무관함 승격·관련 영역으로의 변경 소유 전파는 실패다. 높이가 바뀌면 재선택 없이 선 끝도 확인한다.
5. **비초기 근거 닫힘:** 실제 휠로 읽던 위치에서 하나를 열고 버튼 닫기→재열기→Escape로 닫는다. 닫기 직후 보정 스크롤 전에 출발 문장 rect/읽기 위치/초점과 패널·링크 제거를 대조한다. 새 전체 재렌더 경계에서 낡은 참조가 남는지도 이 장면에 포함한다.
6. **준비의 실제 읽기·닫기:** 같은 대상의 준비 하단까지 필요한 만큼 실제 스크롤하고 닫는다. 대상·보존 조건·미확인/미송신, 출발 초점·위치를 확인한다. 한 번 재열어 실제 시작 위치를 기록하되 기존 코드의 초기화 의도를 통과 근거로 쓰지 않는다.
7. **전체 복귀 한 번과 짧은 반복:** 비초기 지도 위치/제공된 비기본 배율에서 진입·복귀한다. 사용자 조정 깊이·선택·정확한 대상 rect·실제 transform/native scroll을 보조 이동 전에 비교한다. 짧은 근거 열기/닫기 후 재복귀 한 번으로 누적·상쇄를 확인한다. 설명 참조 복귀가 있다면 전체 복귀와 기대 초점을 구분한다.
8. **관측 증거 신뢰성:** 실제 최초 브라우저 HTTP 응답 body SHA를 대상 HTML에 결합한다. 필수 장면 미완주/FAIL/pageerror/fatal/cleanup 오류와 **실제 자식 종료**를 기록하고 실패를 nonzero로 연결한다. 바뀐 집계 경로만 작은 음성 확인을 붙인다. 파일 사전 해시 실패를 브라우저 실패로 쓰거나 종료 수집기의 exit0을 합격 신호로 쓰지 않는다. 미관측·못 읽음·미실행·FAIL을 분리한다.
