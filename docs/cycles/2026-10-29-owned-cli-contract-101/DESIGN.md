## 다음102 구현 범위와 통과 조건

작성자는 createStudioHandler에 서버 주입 경계와 상태 표시를 좁게 추가하고, Node 전용 실험 실행자는 cycle 경로에 격리한다. 기본 경로는 주입이 없을 때 지금과 같아야 한다. 브라우저 프로젝트 적용 권한과 기존 저장 기록의 의미는 유지한다. 접수 시 서버가 정한 실행자 ID·CLI 판본/바이너리 hash·reasoning/권한 설정·deadline 정책 hash를 원 operation과 함께 내구 저장한다. 조회/재시작 때 현재 설정으로 바꾸지 않는다. 필요한 선택적 실행 metadata만 추가하고 구형100 기록은 당시 HTTP 계약으로 읽는다. 이 결속을 기존 model/prompt만으로 충족했다고 간주하지 않는다. 공용 라우터를 복제하거나 Worker로 child_process를 들여오지 않는다.

새 adapter는 AbortSignal과 deadline을 모두 실제 child에 연결한다. 완료/취소가 경합하거나 close가 오지 않으면 결과를 ready로 바꾸거나 슬롯을 재사용하면 안 된다. 실행자 입장과 실제 child 수명을 결속한다. 특히 Node가 비정상 종료돼100 소유권이 풀려도 옛 CLI child가 살아 있을 수 있다. 따라서 재시작의 interrupted 표시만으로 새 작업 입장을 허용하지 않는다. 프로세스 수명과 함께 정리되는 검증된 OS 소유권 또는 내구 실행 lease/미종료 격리를 사용하고, 이전 child 종료를 입증할 수 없으면 다른 ID의 신규 실행도 fail closed한다. PID 재사용을 무시한 강제 종료나 사용자 프로세스 전체 정리는 금지한다. 검증된 완결 wire만 run.call에서 반환하고 원 ask/model/prompt/hash·reading identity를100 저장소에 맡긴다. 현재 페이지가 바뀌어도 요청 signal로 작업을 끊지 않는다.

모델 없는 검증은 새 경계에 한정한다: 정상 child→정확 ready, 잘린 UTF-8/무효 JSON/도구 event/비정상 종료 거절, 취소 후 늦은 완료, cutoff 직전·직후 경합, close 미수신의 후속 입장 거절, 중복 POST 단일 invocation, ready 재시작·keyoff 회수, 실행 중 종료 뒤 interrupted 및 재호출0, 옛 child 생존/종료 불명 상태에서 재시작한 새 operation도 실행0. 공용 HTTP 보안·기본 공급자와 Worker import 경계에 대한 회귀도 확인한다. 기존100 검사를 그대로 되풀이한 결과만으로 CLI 연결 완료라 하지 않는다.

독립 검토와 새 경계 검증이 끝나기 전 실제 모델은 호출하지 않는다. 이 단계의 완료는 preview 실행자 구현/검증이며 생성 품질 수용이 아니다. 실행자 설계가 결국 옛 격리 CLI의 timeout만 바꾸는 형태라면 반려한다.

## 이후 실제 관측의 순서 — 아직 실행 승인 전

구현 검증 뒤 총괄이 exact SHA/app/CLI binary 판본·prompt·원본 ask·실행자·정책을 동결하고 호출 여부를 별도 결정한다. token/cost 제한을 확인할 수 없으면 그 사실과 허용할 운영 제한을 명시적으로 판정한다. 확인되지 않은 cap을 전제로 진행하지 않는다.

첫 후보는 기존에 최종 응답을 받지 못한 Zephyr 한 건이다. 새로운 내구 경로의 정상 UI에서 접수하고 다른 프로젝트 편집/새로고침 후 같은 ID의 결과를 회수한다. 형식/의미 실패 또는 cutoff이면 후속 자료 호출은0으로 종료한다. Z1–Z4와 FAST/default/sleep 같은 독립 사실, B1/B72 대응, always-on 제한, 정확 근거 왕복·저장·백업을 함께 확인한다. raw를 수선하거나 일부 조건만 보고 통과시키지 않는다.

통과하더라도 Zephyr 한 표본의 범위 결과다. 현재 전체 경로의 실제 지시/micro, 문단·배치 반례 및 복잡한 PC 경험은 별도 관문으로 남는다. 89의 앞선 두 성공을 이번 새 CLI/prompt/내구 전달의 성공으로 소급하지 않는다. 공개73 갱신·PR 병합·배포·인수인계5/8 완료는 이번 결정에 포함하지 않는다.
