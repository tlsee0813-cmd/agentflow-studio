# 105 — 실제 지도에서 변경 요청으로

104에서 수용한 Zephyr 지도를 재생성하지 않고, 기존 변경안·선택 범위 검토·요청문 경로로 이어간다. 총괄이 제안한 관측용 변화는 화면 리본 라벨에 맞는 빌드 대상을 안내하는 작은 PC 도구다. 이는 실제 소유 보드나 이미 구현된 도구의 사실이 아니며, 원문에 근거한 새 구상이다.

104의 CLI는 FIRST만 지원한다. plan/scope까지 제공한다고 위장하거나 자동 fallback을 추가하지 않는다. 같은 지도 백업을 기존 정상 DeepSeek 경로에서 명시적으로 이어 쓴다. 제품 runtime은104와 같고, 새 실행자·환경 설치·계정 변경은 없다. 기본 DeepSeek plan.3과 scope 지침을 그대로 사용한다. 첫 지도 재생성0, 계획1회, 의미 통과 뒤 범위 검토1회만 선택한다. 둘 중 실패하면 같은 호출을 반복하거나 응답을 수선하지 않는다. 반환 기록의 map 관측은 아직 선택하지 않는다.

관측 구상:

> reel board의 화면 리본 라벨을 입력하면 맞는 빌드 대상을 안내하는 작은 PC용 도구를 새로 만들고 싶어요. HINK-E0213과 HINK-E0213A22에 대해 화면·컨트롤러·ssd16xx·보드 지정의 대응을 함께 보여 주세요. 라벨이 비어 있거나 모르는 값이면 대상을 추정하지 말고 확인이 필요하다고 알려 주세요. PCB 버전만으로 대상을 고르지 마세요. 실제 빌드나 플래싱은 실행하지 않고, 센서·회로·전원 제어와 절전 기능은 바꾸지 않습니다. 현재 문서에 적힌 Low Power 절전 불가 제한은 안내에 유지해 주세요.

합격은 유효 JSON에 그치지 않는다. 두 라벨 대응과 미상 라벨의 보류, PCB판본 비추정, 센서·회로·전원·절전 기능 비변경, 실제 빌드/플래싱 미실행, 알려진 절전 불가의 보존을 확인한다. 기존 도구 부재나 구현 완료를 원문 없이 단정해서도 안 된다. 선택 결과가 요청문에 고정되고 기존 지도·원문과 구별돼야 한다. 후속 구현은 정확 요청문을 받아 제한된 로컬 도구로 만들고 실제 수행한 증거만 되돌리는 관문으로 남긴다.

[동결 기록](evidence/frozen.json). 입력은104 전체 백업 SHA dcda9cc2...이며 원문 두 건과 실제 생성 지도는 비공개로 보존한다. 공개73/미수용74/UI75 구별, 기존 키·작업 보존. 공개 범위의 독립 검토는 기존 Sol 세션에서 읽기 전용으로 진행하며 결과는 총괄이 선택한다.
