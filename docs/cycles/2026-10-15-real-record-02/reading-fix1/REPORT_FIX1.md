## HTML 변경 (diff 3곳)

1. **닫힘 결함:** `.pv-body{display:flex}`가 UA의 `[hidden]{display:none}`보다 우선해, `hidden=true`인데도 본문과 닫기 버튼이 넓은 화면에 남아 있었다. 전역 `[hidden]{display:none !important}` 한 줄을 추가했다. 좁은 화면은 시트 자체가 `display:none`이어서 v0에서도 실제로 보이지 않았다.
2. **A f15·f16:** 앞 문장 ‘그 끝점 목록’에 기대지 않도록 H1과 위치를 문장 안에 넣었다. 숫자·출처·사건·B 행은 그대로다.
   - f15: “H1의 접힌 A 끝점 목록 A2 행(위치 L1)에도 A2 소유 미결 참조가 없다.”
   - f16: “H1의 B 상세 끝점 A2 행(위치 L2)에는 변경·미결 참조가 없다.”
3. 바닥글 버전 표기(fix1). 머리글 제목 ‘v0’은 바꾸지 않았다.

## 검사 변경

- **browser_check.py:** 열림·닫힘을 `hidden` 속성이 아니라 실제 표시로 판정하는 PANEL-INIT / PANEL-OPEN / PANEL-CLOSED-BTN / PANEL-CLOSED-ESC / PANEL-CLOSED-KEY를 추가했다. 판정 기준은 `checkVisibility`, 레이아웃 박스, elementFromPoint 클릭 가능성, 실제 `focus()` 가능성이다. 넓은 화면에서는 빈자리 안내만 보여야 하고, 좁은 화면에서는 시트가 없어야 한다. 1280×720을 추가해 1440×900, 390×664, 390×844와 함께 네 화면을 본다. 기존 ‘닫힘’ 항목은 이름을 ‘상태값(hidden 속성)’으로 바꿔 표시 판정과 구분했다. 변형 판정에 쓰는 항목에는 고정 ID를 붙였다.
- **static_check.py:** T24를 추가했다(f15·f16이 H1과 위치를 스스로 밝히고, 지시어로 시작하지 않음).
- **check_links.sh:** 추출한 링크가 0개이거나 기대 개수(기본 11)와 다르면 실패하고 종료 1로 끝난다. 음성 확인 로그 2개를 남겼다(빈 HTML, 기대 12).
- **mutation_check.py:** 원본 기준선이 먼저 통과해야 변형 결과를 해석한다. 변형마다 예상 실패 ID와 화면을 정해 두고 DETECTED / MISSED / FATAL을 구분하며, ABORT(시나리오 중단)는 판정에 쓰지 않고 따로 표시한다. 변형 m6(hidden 수정 제거)을 추가했다. v0의 기존 mutation 로그 5개는 폐기하지 않는다.

## REPORT에 추가로 남길 판단 (총괄 지시)

- **B 모바일 ‘나란히 대조’ 조건 미충족:** 390폭에서 근거 시트를 열면 시트 위에 출발 셀(관측) 정도만 남는다. 같은 표의 비교 상대 행은 시트 위에서 함께 유지되지 않는다(v0 PNG와 코드에서 확인됨). 행별 근거 읽기와 복귀는 검증되지만, 이 장면을 B의 모바일 비교 우위나 대조 성공으로 세지 않는다. 별도 비교 엔진이나 컨트롤은 만들지 않았다.
- **선택의 뜻:** ‘선택’은 근거 버튼을 누른 사실을 강조로 남기는 현행 동작이다. 미리보기를 닫은 뒤와 A/B 전환 뒤에도 유지된다. 미리보기를 열기 전의 다른 선택을 복원하는 기능은 아니며 그렇게 부르지 않는다. 검사 이름도 ‘근거 버튼으로 고른 사실의 선택 표시 유지’로 바꿨다.
- 상태 14종과 QA 중심 부담은 이번에 손대지 않았다.
- 같은 유형(대상 버전을 문단 맥락에 기대는 A 문장)이 f07·f08·f10·f17·f20에 남아 있다. 지시 범위 밖이라 고치지 않았고, static_check INFO로 표시만 한다.
