1. **전체 완료로 압축:** A의 ‘H1 수정 완료’ 한 문장이나 B의 녹색 합계가 E07의 좁은 수용을 전체 완료로 바꾼다. 본문·표의 판단을 해당 범위로 제한한다.

3. **미결을 잘못 귀속:** 예제 정책 미정, UI 참조 누락, 독립 검사 미실행을 하나의 실패나 사용자 할 일로 합친다. B/A4/A6에 A2의 정책 소유를 전파하거나 이미 승인된 배정으로 표시하지 않는다.

## 두 표현에 공통으로 적용할 확인 방식

각 핵심 판단을 선택하면 어떤 사건·자료·버전·검사 범위에 기대는지 추적할 수 있어야 한다. A의 한 문장을 출처가 전부 지지하지 않으면 문장을 나누거나 범위를 좁힌다. B는 같은 범위만 대응시키며, 대응하지 않는 자료를 대칭 셀로 억지 비교하지 않는다. 두 안의 정보량·출처 접근 조건을 다르게 만들어 우열을 유도하지 않는다.

전체 맥락과 선택 대상, 근거를 읽던 출발 지점을 보존한다는 것은 후속 시안의 확인 항목이다. 인용·미리보기 클릭이 실제 대상 선택이나 결정 변경을 몰래 수행해서는 안 된다. 여기서는 후속 화면을 열람·조작하지 않았으므로 **내용 구현 합격, 복귀 성공, 사용성 우위 모두 판정하지 않는다.**
