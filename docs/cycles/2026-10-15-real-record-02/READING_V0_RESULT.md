# 실제 기록 읽기 v0 — 원본 회수와 독립 검토

2026-10-16 · 상태: 닫힘 결함 확인, 좁은 fix1 수정 배정 · A/B 채택 미확정

## 총괄 판단

v0는 같은 동결 기록을 두 표현에 놓았으며 주요 사실·출처 경계를 보존한다. 그러나 넓은 화면에서 근거 미리보기를 닫아도 실제 본문이 남는 결함이 확인됐다. 작성자 203개 조작 검사가 통과했어도 닫힘의 실제 표시 상태를 검사하지 않아 놓쳤다. 이 버전은 읽기 비교의 조작 기준을 통과한 것으로 수용하지 않는다.

모바일 B는 근거를 읽는 동안 비교 상대 내용이 남지 않는다. 따라서 현재 390 화면을 ‘나란히 대조가 유지되는 후보’로 평가하지 않는다. 행별 읽기와 복귀의 검증은 가능하지만 그것이 대조의 효용을 증명하지는 않는다. 이번 fix1에서 새 비교 엔진이나 별도 조작을 추가하지 않고, 모바일 대조 조건 미충족을 남긴다. A의 f15/f16은 출발 문장만 읽을 때 H1 기준이 빠지므로 문장을 자체 식별 가능하게 보완한다.

이 판단은 이번 실제 AI 개발·검증 기록 한 건에 한정한다. 사람의 이해도·부담·선호, 프로그램 전체 이해·조정·위임 성공은 아직 관측하지 않았다. 상태 표기 14종과 반복되는 근거 버튼의 부담도 후속 관찰 대상이며, 새 기능 목록으로 바꾸지 않는다.

## 총괄 실제 재현

임시 HTTP 원본 응답의 SHA256은 위 고정 파일과 같았다. Codex in-app browser, 실제 viewport 1280×720에서 수행했으며 정확한 브라우저 엔진 버전은 이 관측에서 기록하지 않았다. 아래 수치는 페이지 DOM의 계산된 표시·실제 박스 관측이고 핸들러를 직접 호출하지 않았다.

1. 최초 화면부터 `pvBody.hidden=true`인데 computed display는 `flex`, 박스는 약358.4×118.3px이고 닫기 버튼이 존재했다.
2. 실제 `ab-f14` 버튼을 눌러 E09 근거를 열었다.
3. 실제 `pvClose` 버튼을 누른 뒤 `preview.closed=true`, `pvBody.hidden=true`, 초점은 `ab-f14`로 돌아왔다. 그러나 computed display는 여전히 `flex`, 본문 박스는 약358.4×436.75px, 닫기 버튼 높이는38px였다.
4. 화면 이미지에서 빈 자리 안내와 이전 E09 본문이 동시에 보였다. 이는 초점 복귀와 실제 닫힘이 별개라는 재현이다. 해당 조작의 [Cloud 독립 재현 원본](https://github.com/tlsee0813-cmd/agentflow-studio/tree/7e79392080157be693429da40d54c2a206b8aa7b/docs/transfer/real-record-02/v0-preflight)은 같은 결함을 두 화면 크기에서 확인했다. 위 총괄 관측 수치를 Cloud 실행 수치로 간주하지 않는다.

Cloud는 Playwright1.57.0·시스템 Chromium154.0.8037.57로 실제 HTTP에 접속했다. HTML 응답은200이고 해시가 일치했다. pageerror는 없으며 console의404는 favicon 요청이다. [닫힌 뒤 원본 PNG](https://raw.githubusercontent.com/tlsee0813-cmd/agentflow-studio/7e79392080157be693429da40d54c2a206b8aa7b/docs/transfer/real-record-02/v0-preflight/1440x900-after-close.png)와 실제 종료코드·재현코드는 위 공유 폴더에서 회수할 수 있다. 코드와 증거의 독립 감사는 별도 기록한다.

## fix1 한정 배정

Opus에 실제 숨김을 보장하고 속성뿐 아니라 표시·레이아웃·조작 가능성을 검사하도록 요청했다. 같은 v0가 좁은 회귀 검사에서 실패하는지와 수정본의 초기/열림/닫기/Escape를 확인한다. A f15/f16의 H1 맥락과 링크0건 성공·변형 실패 원인 구분도 보완한다. 선택은 근거 버튼이 선택한 사실을 닫은 뒤 유지하는 현재 동작으로 명시하며, 미리보기 전 다른 선택을 복원했다고 표현하지 않는다.

새 시안의 최종 표현을 정하거나 본 제품·main·공개 배포를 바꾸는 배정이 아니다. fix1 작성자 원본을 수신했고 [reading-fix1](reading-fix1/REPORT_FIX1.md)에 별도로 보존한다. HTML SHA256은 `9add34fc341db08e6ef54e6e99d1fbfac6b39e7de61f5d8bd6415b32fa28ed1d`다. 작성자 308/0, 정확 v0 296/12 및 정적24/0은 수신 주장으로 분리하며 독립 감사·실제 브라우저 검증을 진행한다. 완료 여부는 최신 [ACTIVE](../ACTIVE.md)에서 읽는다.
