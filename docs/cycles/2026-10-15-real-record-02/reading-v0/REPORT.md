## 시안의 구성

**공통(두 표현 동일):** 맥락(이 화면·제품 목적 한 줄·합성 예제·산출물 H0/H1·기록자 가명·상태 표기), 동결점 기준 요약 4줄(INPUT ‘이 표본의 현재 상태’), 근거 미리보기, 글자·간격·색·버튼. 맥락은 넓은 화면에서 왼쪽 열, 좁은 화면에서 접힌 상세로 둔다. 프로그램 계층 그림은 만들지 않았고 A2·A3는 이름으로만 언급한다.
**사실 단위:** E01~E10을 25개 사실로 나누고 A의 문장 단위와 B의 행을 1:1로 대응시켰다. 각 사실의 사건·출처·상태 표기·미리보기 내용은 두 표현에서 같다.
**A:** 주제 4개 아래 문단으로 서술. 문장 단위마다 상태 표기와 ‘근거 Exx’ 버튼.
**B:** 같은 주제·같은 소주제의 표. 행의 주어는 자료·위치·검사, 칸은 대상 / 관측 / 범위·한계·기록된 판단. 이전/현재 열이나 승패 열이 없다. 좁은 화면에서는 행이 카드가 된다.
**미리보기:** ‘근거’(▸, 이 화면 안에서 읽기)와 ‘원문 열기 ↗ GitHub · 새 탭’(실제 이동)을 다른 모양·문구로 나눴다. 미리보기는 출발 문장/셀 인용 → 동결 INPUT의 사건 기술(“원문 자체가 아님”) → 출처 순. P01~P03은 링크 대신 ‘원문 링크 미제공’과 이유를 보인다. 닫기(버튼·Esc)는 출발 버튼으로 초점을 돌리고 출발 버튼의 화면 높이를 복원한다. 넓은 화면은 오른쪽 열, 좁은 화면은 하단 시트(최대 62vh)이며 열 때 출발 문장을 시트 위로 올린다.
**A/B 전환:** 선택한 사실(없으면 화면 맨 위 사실)을 같은 화면 높이에 맞춰 다른 표현으로 옮긴다. 미리보기가 열려 있으면 같은 사실을 유지하고 출발만 새 표현의 셀/문장으로 바꾼다. 읽음·승인·수정 표기는 만들지 않는다.

## 작성 중 발견한 문제

**시안에서 고친 것**
1. 정적 대조 첫 실행에서 실제 실패 4건이 나왔다. A 문장이 문단 앞 문장에 기대어 A3·위치 C/L1/L2/B·소유 A2를 생략했고(f02·f03·f18·f22), 문장을 명시적으로 고쳤다. B는 E08 독립 브라우저 행의 ‘대상’ 칸에 INPUT에 없는 ‘H1’을 채워 넣었고, ‘독립 환경’으로 고쳤다. 고정 칸이 빈자리를 근거 없이 채우게 만드는 압력은 B의 실제 위험 사례로 남긴다. 같은 실행의 2건은 부정문 안의 ‘완료율’·‘승인된 변경’을 잡은 검사기 오탐이었고, 검사를 부정문 제외로 좁혔다.
2. 실제 Chromium 390폭에서 앞 미리보기 안의 스크롤이 다음 미리보기에 남아 출발 인용이 안 보이는 결함을 스크린샷으로 발견했다. 고치고 이를 잡는 검사를 추가했으며, 수정 전 사본에서 그 검사가 실패함을 확인했다(m5).

**입력·표현 문제(조건과 함께 보고, 고치지 않음)**
- 사건 번호 충돌: S01의 합성 예제에도 합성 사건 E01~E05가 있다. 합성 E04는 A2 결정 변경과 정책 미결이고, 실제 기록 E04는 목록 복귀 결함이다. 시안은 ‘합성 사건 E04’로 구분해 표기했다.
- 표기 충돌: E10의 ‘S2/S3’는 캔버스 장면인데 출처 S02/S03과 모양이 비슷하다. R1·S06의 용례로 장면임을 판단해 ‘장면 S2/S3’로 적었다.
- INPUT은 A2 실패 알림 정책 미결의 출처 위치를 적지 않았다. 작성자가 S01 16행에서 확인했고, 미리보기에 ‘작성자 확인, INPUT 미기재’로 표시했다.
- E10 수치의 유일한 공개 고정 링크인 R1에는 동결점 이후 fix2/fix3 통과도 함께 있다. 미리보기에 그 사실과 ‘최초 JSON 아님’을 표시했지만, 원문을 여는 순간 동결 이후 정보가 보인다.
- S07은 작성자를 가명이 아닌 실제 모델명으로 지칭한다. INPUT도 링크 원문의 비식별화를 보증하지 않는다고 적었다.
- E08의 기록자 ‘다·라’는 INPUT에서 나뉘지 않아 두 행 모두 ‘(다·라)’로 두었다.

**표현 관찰(작성자 관찰이며 비교 결과 아님)**
- 같은 사실이라도 B는 행마다 대상·한계를 반복해 글자량이 많다. 390폭에서는 카드가 길어져 시트 위에 남는 맥락이 A보다 적다. 공간 규칙은 같지만 정보 밀도 차이가 남는다. READING_TRIAL에 따라 기록만 하고 표현 우위로 귀속하지 않는다.
- A는 문단 맥락에 버전·기준을 기대므로 출발 인용 한 문장만으로는 대상이 덜 드러날 수 있다(예: f15·f16의 H1).
- 넓은 화면 미리보기에서 출처와 원문 열기는 사건 기술 아래에 있어 미리보기 안 스크롤이 필요하다.
- 상태 표기가 14종이다. 사람 관찰 전 축소 후보다.
- 전환 위치 맞춤은 페이지 끝에서 잘릴 수 있다. 검사는 그 경계를 허용했다.

## 데이터 엄수 대응

H1(fix1)·E10 동결: fix2/fix3는 ‘넣지 않음’ 설명과 R1 경고에만 나온다(정적 T10). A3: ‘산출물 표기 차이 + 작성자 설명’, 정정 요청·시각·승인은 ‘기록 미확인’ 표기를 쓴다. 개명·원래 명칭은 없다(정적 T13). A2: 합성 내용 미결(f21)과 실제 UI 보완 대기(f22)를 다른 사실로 두고, B 미결 구역의 직접 이동은 총괄의 조작 보완으로 구분했다(f17). 수치: 5사례 통과는 위치 검사에서 ‘범위 밖’, 13사례/90단언은 합산하지 않으며 합산·완료율 표현은 없다(정적 T11). P01은 전달 발췌·무링크, P02/P03은 사유와 함께 무링크다. R1은 ‘재실행 결과, 최초 JSON 아님’이다. 링크는 INPUT 고정출처 11개뿐이다(정적 T14). ‘상충’은 없다. 미실행·기록 미확인·범위 밖·실패는 다른 표기를 쓴다.
