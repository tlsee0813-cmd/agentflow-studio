# cycle03 후속 — 검사기 종료 코드 결함 보완

2026-10-16 · 작성자(Claude Opus 5.5) · 범위는 `check/flow_check.py`의 종료 처리 하나. HTML·화면·입력은 바꾸지 않았습니다.

## 결함과 수정

- **결함(독립 검토 지적 그대로):** `Run.step`은 실패·예외를 FAIL로 기록했지만 `__main__`은 결과를 저장·출력만 했습니다. 그래서 단계가 FAIL이어도 프로세스는 exit 0으로 끝났습니다.
- **수정 1 — 종료 코드:** `main(argv)`가 종료 코드를 반환하고 `sys.exit(main(...))`로 끝납니다. 아래 중 하나라도 있으면 exit 1입니다.
  - 필수 단계 중 FAIL. 필수 단계는 뷰포트마다 14개로, `1–7`, `8.2–8.7`, `8`입니다.
  - 필수 단계 기록 없음(미완주). 2·7단계 실패로 흐름이 중단된 경우와 뷰포트 실행이 예외로 죽은 경우를 포함합니다.
  - `pageerror` 1건 이상.
  - 브라우저 시작·종료 예외. 이 경우에도 로그는 쓰고 실패로 끝냅니다.
- **수정 2 — 로그:** 로그 끝에 판정 줄과 실패 사유를 남깁니다.
- **수정 3 — 구조:** 전역 인자 처리를 `main` 안으로 옮겨 모듈 import가 가능하게 했습니다. 프로브가 검사기를 수정하지 않고 쓰기 위해서입니다.
- **바꾸지 않은 것:** 판정 항목과 단계 내용은 그대로입니다. 새 검사를 추가하지 않았습니다.
- **판정에 넣지 않은 것:** `pageerror`와 별도로 console error 목록도 기록하지만, 요청 범위에 맞춰 종료 판정에는 넣지 않았습니다. 이번 두 실행에서는 둘 다 0건입니다.
