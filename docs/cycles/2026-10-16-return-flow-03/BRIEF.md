# 공간으로 돌아오는 작은 흐름 — 작성 범위

2026-10-16 · 구현 전 배정 기준. 현재 배정·실행 상태는 [ACTIVE](../ACTIVE.md)에 모은다.

## 이번 결과물

연구용 단일 HTML `return-flow-study.html`로 **변화 확인 → 한 부분 이해 → 필요할 때 근거·인계 준비 → 전체 복귀**를 실제 조작할 수 있게 한다. 이전 읽기 시안 전체를 지도 옆에 붙이지 않는다. 기본 공간에서 프로그램의 부분과 관련 영역, 짧은 설명을 먼저 이해하고, 정밀 근거는 필요할 때 한 단계 더 들어가 읽게 한다.

입력은 기존 AgentFlow 제품의 FIX058 변경을 보고한 문서다. 이는 도서 대여 예제 검사 기록과 다른 성격의 실제 개발 보고이며, 원 요청부터 실제 인계 완료까지 갖춘 기록은 아니다. [INPUT](INPUT.md)에 고정한 사실만 사용한다. 현재 AgentFlow 제품 소스나 과거 HOLD 기능의 재개가 아니라, 이 과거 기록을 읽는 별도의 연구 시안이다.

## 화면과 조작의 방향

- 첫 화면에서는 어떤 프로그램 부분을 보고 있고 무엇이 달라졌는지 짧게 읽을 수 있어야 한다. ‘목적 정정은 별도로, 작업 지시는 그대로’라는 변경과 연결된 홈·작업문·다음 요청·복구를 사용자 언어로 드러낸다. 이름의 목록이나 긴 보고서를 공간에 흩뿌린 것으로 대신하지 않는다.
- 공간의 목적은 관계와 현재 위치의 이해다. 동일 대상을 복제해 여러 주인처럼 그리지 않는다. 보기용 묶음과 실제 포함·영향 관계를 구별한다. 원문에 없는 모듈 트리나 자동 영향 분석 결과를 만들어내지 않는다. 한 영역에 집중해도 다른 영역의 펼침과 원래 선택·위치를 보존할 수 있게 한다.
- 선택 부분에서는 짧은 목적·변경 설명과 관련 부분을 남긴다. 문장 근거 미리보기와 실제 출처 이동은 구별한다. 둘 이상의 범위를 대조할 필요가 있는 경우에만 간결한 대조를 제공한다. 모바일에서 비교 상대가 사라지는 대조를 성공으로 포장하지 않는다.
- ‘필요한 판단’은 실제 자료가 요구하는 것만 둔다. 이 입력에 근거 있는 사용자 결정 요청이 없으면 억지 승인함·경고 목록을 만들지 않는다. 원 요청이 미확인인 사실은 상세의 출처 경계에서 밝히되 사용자에게 조사 숙제로 배정하지 않는다.
- 인계는 **준비하는 제안**까지만 구현한다. 선택 부분의 목적·범위·기준 기록·보존할 조건·미확인 사항을 짧게 살필 수 있게 하고, 실제 발송·수신·수락·구현 성공으로 표시하지 않는다. 입력을 수정하는 조작을 추가한다면 연구 세션의 가상 편집임을 분명히 구분해야 하며, 이번 필수 경로는 인계 준비 하나로 충분하다.
- 전체 복귀는 현재 상세의 상위로 가는 것과 다르다. 출발 부분·다른 영역의 펼침·지도 위치·초점이 이어져 재탐색을 줄이는지 확인한다. 근거를 닫은 것과 전체로 돌아오는 것을 각각 시험한다.

## 읽기 부담과 시각 품질

기본 화면에 사건 ID·해시·검사 수·14종 상태 범례·모든 출처 버튼을 노출하지 않는다. 중요한 자료 기준과 불확실성을 숨기라는 뜻은 아니다. 첫 화면의 짧은 맥락, 선택 부분의 설명, 필요한 근거라는 깊이로 나눈다. 화면마다 같은 긴 주의문을 반복하지 않는다.

Dify의 선택·연결 강조, 기존 공간 연구의 부분별 깊이·원래 관계, VS Code의 제자리 읽기와 이동 구분을 메커니즘 참고로 사용한다. Home Assistant·Penpot·Zotero의 조사에서 확인한 사용자 값·자동 원본·변경 판별의 구분도 유지하되 실행 워크플로·인스턴스 체계·충돌 엔진을 복제하지 않는다. 라이브러리를 새로 도입하기보다 이 한 흐름에 필요한 단순한 정적 구성을 우선한다.

색·글자·간격·선택·호버·초점·키보드·접힘·모바일 복귀를 일관되게 다듬는다. 무의미한 장식 카드와 배지 밀도를 줄인다. 1440×900과390×844에서 본문·지도·조작의 역할이 분명해야 한다. 두 크기에 같은 축소된 화면을 강요하지 않되 동일 사실·출처·복귀 의미를 유지한다. 구현 후 실제 스크린샷을 보고 스스로 읽기 부담을 지적한다.

## 반환과 경계

원본 HTML, 짧은 작성 보고, 필요한 재실행 코드와 실제 로그, 대표 PNG 최대3장, 파일 해시를 하나의 작은 묶음으로 반환한다. 기본 지도·선택 후 집중·복귀가 무엇인지 이미지에 대응시킨다. 실제 브라우저 HTTP 검사를 했는지, 스텁·DOM 대역·정적 검사인지 구별하고 실제 프로세스 실패를 실패로 남긴다. 외부 원문 차단은 재진단하거나 우회하지 않는다. 모든 기록을 완벽하게 보이게 만드는 자동 반복이나 의미 없는 검사 수 늘리기는 하지 않는다.

원격 쓰기·main/공개 배포·새 서버 제품·DB·연결기·유료 모델 실행·실제 인계 발송·사용자 설정 변경은 포함하지 않는다. 작성자 구현/검사와 총괄의 통합 판단·독립 검증은 별도다. 한 안의 실제 흐름을 만들고 검토 결과에 따라 좁게 수정한다. 최종 제품 구조나 Dify 이상 품질을 선언하지 않는다.
