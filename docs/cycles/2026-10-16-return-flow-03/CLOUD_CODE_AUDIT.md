## 남길 작은 한계

- 반복 준비는 JSON에서 이미 `scrollTop=57`인 상태로 열려 하단을 추가 휠 없이 관측했다. 매번 준비 스크롤이 0으로 초기화됐다거나 반복 때도 새로 하단까지 휠을 했다고 쓰지 않는다. 위 계약 관측을 뒤집는 실패로 판정하지는 않았으나, 준비 재열기의 시작 위치 보장은 이 증거로 주장할 수 없다.
- 390의 `edges()`는 SVG 숨김과 related 영역 4개를 검사한다. **4개 모바일 표시의 실제 가시성/hit-test까지 검사한 것은 아니다.** 목적 선택 전후 깊이 보존은 해당 JSON 스냅샷 대조로 확인되지만 별도 전후 단언은 아니다.
- 콘솔 오류 한 건은 서버 기록의 `favicon.ico` 404와 부합한다. JavaScript pageerror와 구분되며 코드도 일반 console error를 종료 실패로 합산하지 않는다.
- 제목·목표 문장·도움말의 화면 상자와 일부 텍스트를 확인한 결과를 프로젝트 이해·숙제 부담의 사람 사용성 성공으로 바꾸지 않는다. 외부 원문 왕복, 실제 손가락 스와이프, 실 AI, 실제 인계/수신·수락, 새 작업 복원은 미실행이다. 이번 감사자는 코드를 읽고 기존 JSON을 대조했으며 새 브라우저 관측을 추가하지 않았다.
