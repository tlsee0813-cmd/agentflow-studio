**판정:** Python 주검사기의 기존 ‘단계 FAIL인데 exit 0’ 결함은 코드에서 수정됐으며, 회수된 정상/의도적 실패 로그는 실제 프로세스 종료 기록 0/1과 일치한다. 다만 증거를 모으는 셸 래퍼 자체의 실패 반환은 남아 있다.

## 조치할 잔여 항목

**P2 — `check/run_exit_proof.sh:28–30`은 증명 실패여도 마지막 `cat` 성공으로 exit 0이 된다.** 또한 정상=0, 프로브=임의 nonzero만 요구하므로 다른 원인의 프로브 충돌도 성공 문구를 만들 수 있다. 향후 이 파일을 자동 합격 판정에 쓸 때는 실패 분기에 nonzero를 반환하고, 기대 코드 1 및 프로브 JSON의 의도한 단계/체크 실패를 함께 판정해야 한다. **이번 회수 증거는 아래처럼 의도한 실패까지 맞아 유효하며, 래퍼 문제 때문에 폐기할 것은 아니다.**
