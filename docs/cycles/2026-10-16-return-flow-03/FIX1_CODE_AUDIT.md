**판정:** 지정된 목표 문장·기본 식별자 제외·중복 안내 축소에 맞는 변경이다. 기존 선택/깊이/배율/집중·전체 복귀/근거/준비 동작 함수의 변경은 없다. 화면 배치 영향은 별도 Cloud 관측으로 남는다.

- **실제 diff:** 로컬 v0→fix1 비교는 `html_fix1.diff`와 원본/대상 헤더의 경로·시각을 제외하고 전부 일치한다(7개 변경 구간). CSS는 헤더 목표/연구 표시, 요약 문단, 접힌 도움말의 배치만 바뀐다. HTML은 프로젝트 목표 1문장, 요약의 영역 이름 문장화, 기본 안내의 FIX058 제거, 영향 영역 설명 축소와 새 native `details.help`다. 스크립트는 저장 복구의 상세 설명에서 `FIX059·FIX061`을 뺀 문자열 한 곳 외 동일하다.
- **기본 식별자 제외:** HTML 기본 안내와 영역 카드의 자세히 설명에서는 지정 식별자를 제거했다. 단, FIX1_REPORT의 ‘식별자는 근거 미리보기/출처/준비본에만’은 엄밀히 좁혀야 한다. **접힌 비교표에도 FIX058 보고가 남아 있다**(fix1 HTML 510·513행). ‘기본 화면에서 제외하고 상세 비교·근거·출처·준비에 남김’이 정확하다. 기본 화면 제외 요구와 충돌하는 새 결함은 아니다.
- **파일 무결성:** manifest 10개 항목 모두 일치한다. HTML은 42,241 B, SHA256 `af748df1dfacb7ed6b4ae3709d5ced26ef43f96bc45a9e6c2c05cdc02e9cc77e`다. 로그가 명시한 검사기 SHA256 `5ec3234d306cc7eea16d04779ca4cd0ee3e976ffa61cd5f45c67a97e79c4b108`은 보존된 checker-followup 검사기와 일치한다. fix1 묶음 자체에는 검사기 사본이 없다.
- **실행 귀속:** `logs/run_record.txt`의 실행 전 HTTP200/42,241 B 응답 해시, 실행 후 응답 해시, 로컬 전후 해시와 JSON의 HTML 해시가 모두 위 값이다. 실행 시각은 02:11:59로 JSON/TXT와 맞고, 기록된 실제 종료코드와 JSON verdict는 0이다. JSON은 두 화면 각각 14단계/110하위 체크 전부 PASS, pageerror/console error/외부 요청 0이다. TXT=stdout 바이트 일치, stderr 0 B다.
- **귀속의 한계:** 전후 HTTP 해시는 작성자가 남긴 별도 기록이다. 그 해시를 만든 실행 코드/명령·응답 본문은 묶음에 없고 주검사기의 `page.goto()` 응답 바이트를 해시해 실패 조건에 연결한 것도 아니다. 따라서 작성자 실행의 전후 동일성 기록은 보강됐지만, 독립적으로 같은 응답을 실행했다고 재확인한 결과로 쓰지 않는다. 외부 GitHub 원문 왕복·사람 관찰도 미실행이다.

**Cloud에 남길 관측:** 새 `details.help`(236행)를 열고 닫을 때 지도 높이와 관련 선 끝점이 실제 영역 헤더를 따라가는지, 해당 도움말 상태에서 집중→전체 복귀가 지도 좌표·배율·다른 깊이를 보존하는지 확인한다. 기존 `ResizeObserver`→`layout()` 경로(437·480행)는 그대로 있으나 이것만으로 실제 선 좌표를 통과시키지 않는다. 늘어난 모바일 헤더 높이와 기본 지도/읽기 복귀 가림도 같은 8단계 실행에서 관측한다. 이 감사에서는 새 제품 P1/P2 결함을 확정하지 않았다.
