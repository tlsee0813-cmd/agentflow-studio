## 시작 조건과 범위

같은 HTML 바이트를 **1440×900, 390×844, 브라우저 확대 100%**의 독립 시작 상태에서 각각 연다. 파일 SHA256·브라우저 버전·실제 제공 URL·입력 문서 버전을 기록한다. 시작 전체 지도에서 목적 정정 부분, 관련 영역, 다른 영역의 서로 다른 펼침 깊이, 지도 위치·스크롤과 기존 선택을 전후 대조 기준으로 남긴다. 구체 명칭·관계·화면 조작은 시안 도착 후 실제 구현과 문서에 결합하며, 문서에 없는 포함·의존·배정 관계를 기대값으로 만들지 않는다.

명시적으로 다른 부분을 고르는 **새 선택**과 직전 보기로 **복귀**하는 동작은 다르다. 전체 복귀의 선택 기준은 2에서 목적 정정 부분을 고른 뒤 읽기 공간에 들어가기 직전이다. 1의 다른 영역 깊이·지도 위치와 함께 대조하되, 사용자가 의도해 바꾼 선택을 무조건 1의 이전 선택으로 되돌리라고 요구하지 않는다.

판정 대상은 **전체에서 문서 보고 변화 파악 → 목적 정정 부분 선택 → 필요한 근거와 인계 준비 → 전체 복귀**의 한 흐름이다. 자동 수집·조정 저장·병합·실제 인계 엔진은 요구하지 않는다. FIX058은 문서 보고 사례다. 사용자 원발화·승인·실제 인계 수신/수락은 미확인이며, 구현 담당 전환의 이유는 문서상 Work 연결 장애다. 사용자 목적 변경이 담당자를 바꿨다는 인과로 그리지 않는다. 방문 기준이 없으므로 ‘지난 방문 이후’ 대신 문서의 기준 시점을 읽을 수 있어야 한다.

## 근거 이동과 기록 방식

미리보기와 실제 외부 원문 이동은 별도다. 외부 원문을 열 경우 출발 지점·읽기 상태를 기록하고 실제 페이지에서 돌아오는 행동까지 관측해야 그 왕복을 기록할 수 있다. 스텁 응답·URL 새 탭 생성·원문 링크 존재만으로 실제 원문 왕복을 통과시키지 않는다. 이 작은 흐름이 내부 근거 읽기만 제공하면 외부 왕복은 **미실행**으로 명시하며 새 네트워크 작업을 선행 조건으로 만들지 않는다.

전후 화면 짝과 짧은 조작 기록을 흐름 단위로 남긴다. 특히 처음 전체/최종 전체, 열린/닫힌 근거, 준비/닫힘의 차이가 실제로 보이게 한다. 페이지 속성·상태 객체만으로 가림·닫힘·접근을 판정하지 않는다. DOM 스크롤 보조를 사용했다면 실제 휠·터치 접근과 구분해 적고, 화면 밖 요소를 자동 이동시킨 성공을 모든 위치의 무가림으로 확대하지 않는다.

상태는 **수행·관측된 좁은 통과 / FAIL / 못 읽음·미관측 / 미실행**으로 구분한다. 기능이 아직 없거나 환경상 수행하지 못한 단계는 성공으로 채우지 말고 범위·사유를 적으며, 필수 단계가 남으면 전체 흐름의 수용 완료로 쓰지 않는다. 사람 이해·숙제 부담은 실제 사람을 관찰했을 때만 결과로 쓰며, 작성자·AI 검토자의 읽기 판단은 별도다. 단언 수·검사 묶음 수·화면 수를 합산해 사용자 흐름의 성공률이나 우승자를 만들지 않는다.

이 문서는 브라우저 실행 결과가 아니다. 기존 TLS 차단 재진단·환경 설정·서버 시작·새 하네스·원격 반영은 이 계약 작성 범위에 없다.
