선택한 요청 범위:
- 폴더 안 마크다운 문서 일괄 변환
폴더 단위로 여러 마크다운 문서를 한 번에 변환하도록 한다. 기존 단일 파일 입력 경로 읽기, 변환기, 내보내기 흐름은 파일별로 재사용한다.
- 파일 하나가 실패해도 나머지 계속 처리
파일 하나의 변환 또는 내보내기 오류가 나머지 파일 처리를 멈추지 않게 한다. 실패한 파일은 실패로 남기고 다음 파일로 진행한다.
- 마지막에 파일별 성공·실패 요약 표시
일괄 처리 마지막에 파일별 성공과 실패를 모아 보여준다. 현재 터미널 실행에서 어떤 결과가 표시되는지는 제공된 자료로 확인되지 않아, 기존 터미널 접점에서 표시 형식을 정해야 한다.

이번에 맡기지 않은 항목:
- 없음
위 미선택 항목은 이번 요청 범위가 아닙니다. 원자료의 전체 구상에 언급되어도 추가 요청으로 해석하지 마세요.

선택 범위의 전제:
선택 범위 재검토: 기존 단일 파일 읽기·변환·내보내기 흐름과 출력 이름 충돌 시 오류 반환은 파일별로 재사용할 근거가 있다. 다만 폴더에서 여러 마크다운 파일을 찾아내는 처리와, 실패해도 계속한 뒤 파일별 결과를 모아 보여주는 동작은 제공된 기록에서 확인되지 않는다.
- 전제 후보: 폴더에서 변환 대상 마크다운 파일 목록을 얻는 입력 처리 — 원문은 현재 입력 경로 하나에서 문서를 읽는다고만 하며, 폴더째 처리는 다음 구상이지 지금 구현된 것이 아니라고 명시한다. 기존 단일 파일 흐름을 파일별로 재사용하려면 여러 대상 파일을 식별하는 최소 수단이 필요하다. [N01, M01, M05]. 요청 범위에 자동 포함하지 않았습니다. 기존 수단과 근거를 확인하고 필요한 최소 범위를 판단해 주세요.

유지할 조건:
- 원본 파일과 기존 출력 파일을 덮어쓰지 않는 규칙
- 출력 파일 이름이 겹치면 오류로 알리는 동작
- 마크다운 본문과 표 내용을 유지하는 변환

전체 구상의 미정 (선택 범위 추가가 아님):
- 폴더 하위 디렉터리까지 포함할지 여부
- 대상으로 삼을 마크다운 파일 확장자와 제외 규칙
- 파일별 성공·실패 요약의 표시 형식과 정렬 기준
- 실패가 있을 때 종료 코드나 추가 재시도 여부
- 일괄 처리에서 PDF와 docx 중 어떤 출력 형식을 지원할지
- 폴더 입력과 기존 단일 파일 입력을 어떻게 구분해 받을지

선택 범위 검토의 미확인:
- 일괄 변환이 PDF와 docx 모두를 대상으로 해야 하는지, docx 출력 경로가 실제로 가능한지는 확인되지 않았다. 원문은 단일 문서 한 개의 PDF 출력만 확인했다고 보고한다.
- 폴더 처리 범위(하위 폴더 포함 여부, 마크다운 파일 식별 기준, 출력 파일 위치)가 자료에 없다.
- 실패로 집계할 범위(읽기·변환·내보내기 오류, 출력 이름 충돌 포함 여부)와 기존 터미널 접점에서 파일별 성공·실패 요약을 어떤 형식으로 표시할 수 있는지는 확인되지 않았다.
