## 사용자 흐름

## 합성 사례와 두 PC
정상 UI의 A/B/실제 인계 템플릿으로7일 외부 설명을 받고 A 설명을 ‘안내의 실제 표시는30일, 이전7일 설명 오류, 보관 정책 변경 요청 아님’으로 정정한다. 기존 A 이해/다음행동에는 ‘현재 안내 표시는7일’, 범위/확인에는 ‘실제 보관 동작7일 유지·배포금지’와 보존 marker를 직접 넣는다. 표시와 동작이 다른 명시 합성 사례다.

과업은 정정된 표시를 반영한 다음 인계 준비다.1280×720·1440×900에서 현재 설명/정확 과거H/현재 네값을 구별해 필요한 이해/다음행동의 표시만30으로 수정하고 실제 파일용 clipboard/H를 대조한 뒤 지도로 돌아온다. 보관 동작7과 배포금지, 무관한 값·기준·B·과거H·원보고는 보존한다.

정정 직후 네값이 그대로인 상태의 ‘수정한 작업문’ 라벨과 미리보기도 관찰한다. 전체 전달문 변경이 네값 자동 갱신을 뜻하지 않는다. 현재 설명을 새 확정 조건으로 승격하지 않는다. 재정리의 MOCK 의미 품질을 새로 평가하지 않는다.

완료 여부 외에 설명을 다른 화면에서 기억해 와야 하는 장면, 화면 전환/왕복/스크롤을 구체 기록한다. 자동화가 기존 경로를 안다는 사실을 숨기지 않는다. 코드/저장 자료는 검증에만 쓰고 UI에서 못 본 내용을 사용자가 알 수 있다고 세지 않는다. 기존으로 충분하면 무변경도 가능하며, 한 맥락에서 대조하기 어려운 구조가 보이면 그 장면에 한정한 개선을 검토한다. 새 경고·검토 체크리스트·전체 보고 제외·자동 의미 판정은 이번 범위 밖이다.
