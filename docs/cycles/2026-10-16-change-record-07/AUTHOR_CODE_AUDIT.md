## 종료와 독립 실행에 남길 소수 보완

`run_checks.py`는 실제 child를 기록·전파하고 `run_all.sh`가 **실제 collector 반환값**을 파일로 기록·전파한다. 파일은1/0/0으로 child와 맞다. launcher 자체를 바깥에서 다시 관측한 별도 종료 파일은 없다. checker는 FAIL/fatal/파일변경/두 폭 미완주를 nonzero로 처리한다. 서버 cleanup은 명시 오류 집계가 아닌 terminate/wait/kill이며 이번−15는 정상 SIGTERM 기록이다.

Cloud에서는 기존3경로 안에서 **지도 복귀 raw before/after(3대상·선·computed·scroll·보기/선택)**를 남기고, **P2 편집→P1 기본문→다시P2 편집 생존**을 확인하면 주요 빈칸을 메울 수 있다. 현재 renderer의 표시 label/책임도 비교 보기와 함께 읽는다. 새 기능·대규모 검사 수 목표는 필요 없다. 실제 터치·사람 이해·VS Code 실동작/CI·되돌림 완료·실 AI/인계는 미실행이다.
