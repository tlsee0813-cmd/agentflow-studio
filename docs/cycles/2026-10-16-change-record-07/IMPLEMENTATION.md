## 준비와 상태 보존
선택한 한 부분의 준비문은 목적, 선택 대상, 1/16 고정 변경과 이후 기록, 확인되지 않은 후속 상태를 담는다. ‘공통화 완료’나 ‘되돌림 완료’의 재실행 지시가 되어서는 안 된다. 요청은 그 부분의 필요한 확인·수정 제안이어야 하며 조건 검토만 나열하지 않는다. 관련 부분은 맥락이고 자동 수정 권한은 아니다. 공통 계산 선택 시 두 화면에 영향이 없다고 보장하지 않는다.

새 준비문은 해당 대상의 고정 변경 범위를 기준으로 한 번 생성하고 직접 편집을 보존한다. 비교 전후 전환은 준비문의 기준/내용을 자동 교체하지 않는다. 선택 대상을 바꾸면 기존 대상의 편집이 새 대상에 섞이지 않아야 한다. 실제 송신/인수 수락은 없다.

부분 진입 전에 지도 선택·배율·native 스크롤·비교 보기와 대상 배치를 저장한다. 전체 복귀는 이를 되돌리되 편집 내용은 되돌리지 않는다. 전체맞춤은 별도 새 보기다. 좁은 화면에서 관련 상대의 위치를 보고 ‘읽던 곳으로’ 돌아올 때 출발 선택·초점·읽기 위치·기준 행을 보존한다. 과거 상태 읽기와 공간 탐색 복귀는 다르다.

## 좁은 조작 합격 조건
1440×900과390×844 두 크기에서 아래 세 경로를 실제 조작한다. 사람이 의미를 이해했는지와 조작 성공을 구별한다. 같은 환경에서 모두 실행한 최신 결과를 기본으로 하고 이전 일부 성공을 합산하지 않는다.

1. **전후 비교:** 세 대상과 두 기존 관계의 ID/개수·좌표/크기·선택을 기록하고 비교 전후를 왕복한다. 바뀐 책임/남은 표시 역할이 실제 화면에 있으며 ‘새 계산/새 선’으로 바뀌지 않는지 내용과 렌더를 확인한다. 후속 요청 접근이 두 비교 보기에서 유지되는지 본다.
2. **부분·후속 기록 왕복:** 공통 계산을 선택해 실제 관련 메뉴 위치를 보고 읽던 곳으로 돌아온다. 읽기 영역이 자연스럽게 스크롤되면 실제 휠로 비초기 위치를 만들고 출발 행의 원시 rect·scroll·focus를 비교한다. 내용이 안 넘치면 미측정으로 남기며 검사 때문에 문장을 늘리지 않는다. 동일 근거/후속 기록을 버튼 닫기와 재열기/Escape로 오가며 본문·링크·닫기 요소의 실제 제거, 출발 위치/초점을 기록한다.
3. **준비·전체 복귀:** 실제 확대/이동한 지도에서 한 메뉴를 선택해 들어가 편집 전 준비문을 확인한다. 의미 있는 요청 문장을 실제 입력하고 닫기/비교 전환/재열기 뒤 보존을 확인한다. 두 번째 대상의 준비가 첫 대상 편집을 물려받지 않는지도 좁게 확인한다. 전체로 두 번 돌아가 원래 세 대상 rect·computed transform·native scroll·비교 보기·선택을 대조한다. 초점만 돌아온 것을 전체 보기 복원으로 세지 않는다.

원시 전후 rect·computed transform·native scroll·값·실제 표시/잘림을 남긴다. dataset/inline 값만으로 렌더 복원이라고 하지 않는다. 가시성은 viewport와 overflow 조상, 실제 클릭/표본 hit를 구별해 관측한다. 제품 내부 함수·state 또는 DOM 스크롤 값을 검사기가 주입하지 않는다. 클릭을 force하거나 복귀 직후 휠로 위치를 맞추지 않는다.
