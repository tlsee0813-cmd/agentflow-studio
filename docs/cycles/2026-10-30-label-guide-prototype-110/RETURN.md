## 1. 선택 항목별 구현 보고

**선택 항목: 리본 라벨 입력 시 빌드 대상·절전 제한 안내 도구 → 구현함(시제품).**

- 형태: 로컬 브라우저 PC 화면이다. 요청문에는 형태가 정해져 있지 않아 작업자가 선택했다. `index.html`을 직접 열거나 127.0.0.1에서 제공하며, 의존성은 없다.
- `HINK-E0213`을 입력하면 Good Display GDEH0213B1 / SSD1673 / ssd16xx / `reel_board`가 함께 표시된다.
- `HINK-E0213A22`를 입력하면 Good Display GDEH0213B72 / SSD1675A / ssd16xx / `reel_board@2`가 함께 표시된다.
- 매칭: 앞뒤 공백만 무시하고 라벨 전체를 대소문자 구분으로 정확히 비교한다. 짧은 라벨이 긴 라벨의 접두어로 잡히지 않는다.
