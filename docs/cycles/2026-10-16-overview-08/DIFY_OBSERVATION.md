# cycle08 Dify 화면 관측 — 출처 구분

2026-10-16(KST). **보조 담당 직접 UI 관측은 NOT_RUN**, 아래 실제 화면·조작은 **root가 직접 관측해 전달한 기록**이다.

보조 세션에서는 두 차례 연결 시도와 빈 브라우저 목록으로 실제 화면 접근을 하지 못했다. 이는 보조 세션의 도구 한계이며 Dify 실패가 아니다. 총괄은 기존 탭에서 아래 내용을 직접 관측했고 보조는 전달받은 관측을 정리했다.

root 관측: **1430×900**, Agent 설정 패널이 오른쪽 **400px** 폭으로 열리고 설정 탭이 선택돼 있었다. 우하단 미니맵, **64%** 배율, 상단의 선택 노드로 스크롤하는 버튼이 보였다. 작은 노드 3개·연결선 2개이며 선택 Agent의 테두리가 강조됐다. 입력 노드는 짧은 필수 입력, Agent는 작업 본문 대신 인라인 설정 한 줄, 출력 노드는 출력 한 줄이었다. 긴 설정은 오른쪽 패널에 분리되고 패널 뒤 오른쪽 노드 일부가 가려졌다.

root는 64% 메뉴만 열어 **200/100/75/50/25%**, **화면에 맞게 확대(Ctrl+1)**, 미니맵 항목을 확인했다. 맞춤은 실행하지 않았다. Escape로 닫고 기존 Agent를 다시 클릭해 선택·패널·64% 유지를 확인했다. 배치·내용·실행·게시 조작은 없었다. 단, 자동저장 표시가 **02:44:42→06:19:47**로 갱신됐으므로 저장이 전혀 없었다고 단정하지 않는다. 실행 취소는 계속 disabled였다.

참고 범위는 작은 노드와 상세 분리·선택 강조·명시적 맞춤/미니맵의 존재까지다. 맞춤 결과·이전 보기 복귀·층위 지원은 **미관측**이다. 이미지는 root 도구 출력에서만 실제 열람했고 보관 PNG는 수집하지 않았다. 사용자 워크플로우 이름·작업 문장·UUID·비밀은 기록하지 않았다.
