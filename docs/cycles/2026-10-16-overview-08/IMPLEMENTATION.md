## 화면 계약
1. 기본 지도에는 세 역할의 이름·역할 한 줄, 두 기존 호출, 책임 이동의 핵심만 둔다. 기본에 파일경로/P·E ID·검사 수·긴 근거 문장은 없다. 짧은 이름을 쓰더라도 네이티브 메뉴/설정 메뉴/공통 계산의 구별이 남는다.
2. 누락 확인·경과 계산은 비교 시점의 실제 담당 부분에만 나타난다. 변경 전 공통 카드에 책임이 있는 것처럼 회색 행을 채우지 않는다. 표시 역할과 기존 시간 추정은 남고, 두 호출은 전후 모두 유지된다. 짧은 변화 설명으로 이동이 삭제/신설로 오해되지 않게 한다.
3. 선택한 부분의 기존 상세 영역에서 두 책임과 인자·남은 역할을 읽는다. 카드 펼침 때문에 다른 카드/선 위치가 밀리지 않는다. 비교 전후의 대상 외곽·배치는 같은 viewport에서 고정한다. 축약은 새 독립 기능이나 가짜 하위 노드를 만들지 않는다.
4. 제목/목적·1월16일 고정 변경 범위·후속 요청의 존재를 기본에 짧게 유지한다. 모든 안내를 지워 예쁜 지도만 남기는 것도 부적합하다. 상세의 원문/후속 상태·준비문을 현재 최종 상태나 되돌림 지시로 바꾸지 않는다.
5. **1280×720·1440×900 초기**에서 세 역할명·핵심 변화·관계 양끝이 가려지지 않게 한다. 390×844도 기본 요약에서 세 역할과 두 호출을 함께 확인할 수 있도록 설계하되 글자 일괄 축소/관계 숨김/긴 사건 목록으로 대신하지 않는다. 좁은 화면 배치를 바꾸는 것은 가능하며 이 입력의 세 부분까지만 적용한다. 큰 지도 일반화를 주장하지 않는다.
6. 전체맞춤은 명시 공통 도구, 관련 부분 위치 찾기/출발 복귀는 필요한 문맥에 둔다. 맞춤에 패널이 차지한 영역을 반영한다. 배율은 표시할 책임 정보를 자동 교체하지 않는다. 상세 진입 때 저장한 지도 보기로 복귀하되 직접 편집한 준비문은 유지한다. 새 이력 관리자/저장 버튼은 만들지 않는다.

## 필요한 관측 두 흐름
세 폭에서 같은 최신 한 실행으로 아래를 본다. 기존 검사 수를 복제/확대하는 것이 목표가 아니다. 변경된 표현·맞춤과 기존 핵심 왕복만 포함한다.
- **첫 조망·전후·맞춤:** 초기 화면의 세 역할·두 관계 양끝·이동 단서가 viewport/overflow 조상 안에 실제 노출되는지 기록한다. 비교 전후 raw 카드/선 rect와 문구를 대조한다. 실제 배율/스크롤 이동 뒤 전체맞춤을 눌러 다시 읽히는지 확인하되 맞춤을 원래 보기 복원으로 세지 않는다. 선택/비교 기준/준비문은 맞춤으로 바뀌지 않아야 한다. 글자 자체가 작아진 정도와 내용 노출을 구별한다.
- **한 부분 이해·명시 왕복:** 부분 선택 후 두 책임/현재 호출과 남은 역할을 읽고 관련 부분의 위치를 찾아 돌아온다. 390은 지도·상세 전환의 대상 맥락을 잃지 않는지 확인한다. 기존 근거/준비를 열어 의미 있는 요청 편집→닫기→전체 복귀에서 진입 전 지도 raw 상태/비교 보기와 편집값을 각각 확인한다. 보기 복귀가 편집까지 되돌리면 실패다. 바뀌지 않은 후속 근거 종류를 전부 다시 반복하거나 검사 숫자를 늘리지 않는다.

actual computed transform/native scroll/raw before+after·실제 clip/hit를 기록한다. no hidden app state/DOM scroll injection/force click/복귀 직후 보정. 자연 스크롤 여유가 없으면0·미관측으로 남긴다. 첫 HTTP status/body bytes/SHA와 파일 전후 SHA, 실제 child/collector 종료를 남기고 failure/fatal/미완주/cleanup을 성공으로 덮지 않는다. launcher 자기보고를 외부실제종료로 포장하지 않는다.
