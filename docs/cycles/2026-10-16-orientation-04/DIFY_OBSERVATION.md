# cycle04 — Dify 총괄 조작 관측의 제한된 해석

2026-10-16 · 관측 시각 02:44 KST · 총괄 CUA 전달 기록에 근거한 보조 검토

**귀속:** 아래 화면·DOM 값은 총괄이 실제 CUA 조작으로 관측해 전달했다. 이 메모 작성자는 직접 조작하거나 이미지를 열람하지 않았다. 공유용 PNG는 별도로 저장되지 않았다. 현존 클라우드 버전의 SHA는 미확인이므로 과거 Dify 소스 커밋과 같은 구현이라고 판단하지 않는다.

## 세 장면에서 확인된 것

환경은 1440×900, 캔버스 배율 64%, 이미 열려 있던 Market Research 워크플로의 Agent 선택 패널이다. 깨끗한 첫 진입이나 워크플로 재방문 실험이 아니다.

1. **기존 패널 열림:** UserInput→Agent→Output의 곡선이 보이고 Agent는 파란 선택 테두리였다. 오른쪽 약400px 패널 뒤로 Output의 오른쪽 일부가 가렸다. 프로젝트명은 ‘Agent: Market R…’로 줄었고 큰 캔버스 노트 일부는 화면 밖이었다. 캡처 직후 읽은 Agent 버튼 rect는 x719.5175170898438, y412.5833435058594, w134.1645965576172, h15.303906440734863이었고 activeElement가 Agent 버튼임을 확인했다.
2. **닫기 직후:** 패널과 Agent 선택 테두리가 사라졌고 입력·출력·곡선이 노출됐다. Agent 버튼 rect는 x719.5175, y412.5833, w134.1646, h15.3039였다. 조상의 테두리 class가 transparent로 바뀌었으며 배율은 64%였다. activeElement의 aria-label은 null이지만 실제 초점 대상은 미확인이다.
3. **Agent 다시 선택:** 같은 버튼 rect가 정확히 일치했고 selected-border가 생겼다. activeElement가 Agent 버튼임을 확인했으며 패널 separator는 1개, 배율은 64%였다. 패널은 설정/마지막 실행 탭, 해당 노드 인라인 설정, UserInput/company 참조 토큰, 출력 변수·오류 처리·다음 단계 Output을 포함했다. 프로그램의 변화·판단을 설명하는 본문보다 실행 노드 설정이 중심이다.

총괄의 추가 전달로 첫 패널 열림 때의 rect 관측도 확인했다. 세 장면에서 같은 Agent 버튼의 rect가 일치했다는 증거다. 전체 노드 좌표나 화면 전체의 복원을 대조한 결과는 아니며, 닫을 때 선택 표시가 사라졌으므로 우리 시안의 선택 보존 복귀와 동일하지 않다.

## A/B 판단에 보태는 것과 한계

**A(관련 범위 먼저)**에는 패널이 없어도 입력·처리·출력의 연결이 남는 실제 예를 보태지만, 그 선만으로 프로그램 목적을 이해했다는 증거는 아니다. **B(설명에서 관련 대상으로 연결)**에는 설정 안의 참조 토큰과 다음 단계 표시가 대상 대응의 단서가 될 가능성을 보태며, 실제 탐색 연결이나 변경 설명의 효용은 이번에 확인하지 않았다. 패널이 이웃 노드를 가리고 닫으면 선택이 풀리는 장면은 ‘전체 맥락 유지’와 ‘선택 보존 복귀’를 따로 관측해야 한다는 반례다. 어느 후보의 우위를 입증하지 않으며, 실행 워크플로의 관계를 FIX058 영향 영역이나 프로그램 포함 구조로 옮길 근거도 아니다.

## 변경·미실행 경계

설정값 편집·워크플로 실행·게시를 수행하지 않았고 원래 Agent 패널이 열린 상태로 끝냈다. 다만 클릭 뒤 자동저장 표시 시각이 21:51:41→02:44:29로 바뀌었으므로 **원격 쓰기가 전혀 없었다고 단정하지 않는다**. 어떤 데이터가 저장됐는지는 미확인이다. 모바일, 전체 좌표, 재진입 복원, Escape, 사람 이해도는 관측하지 않았다. 이 기록으로 기능 채택·사용성 성공·완전한 비변경을 선언하지 않는다.
