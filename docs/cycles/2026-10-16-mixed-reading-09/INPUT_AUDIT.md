**입력 재사용을 막을 새 사실 불일치는 발견하지 못했다.** F1–F11은 과거 계약·검사 보고로 귀속하면 유지 가능하다. F1은 목적을 별도 배경에 넣는 정책 변경([원문 L52](https://github.com/tlsee0813-cmd/agentflow-studio/blob/5416decfbe9f38a45323de0badc4fc58ec6e4bcd/docs/flow091-background-contract.md#L52)), F2–F9는 명시 새 요청·고정 사본·반환 대응·배경 분리·직접 수정 우선권([L10–17](https://github.com/tlsee0813-cmd/agentflow-studio/blob/5416decfbe9f38a45323de0badc4fc58ec6e4bcd/docs/flow091-background-contract.md#L10-L17)), F10은 기존 사본 유지와 옛 형식의 null 이관([L18–22](https://github.com/tlsee0813-cmd/agentflow-studio/blob/5416decfbe9f38a45323de0badc4fc58ec6e4bcd/docs/flow091-background-contract.md#L18-L22)), F11은 MOCK 검사 속 A/B 순서([L33–41](https://github.com/tlsee0813-cmd/agentflow-studio/blob/5416decfbe9f38a45323de0badc4fc58ec6e4bcd/docs/flow091-background-contract.md#L33-L41))에 해당한다. 원대화·승인·인계 수신 증거가 아니며 실제 AI 준수도 미검증이다.

## 그대로 사용할 구성 경계

보기용 묶음은 **구상과 목적 / 요청 맥락 / 전달할 내용 / 결과 연결 / 저장·복구** 다섯 개다. 기존 세분화와 변경 소유 **C32 ‘작업문과 미리보기’**를 유지한다. C32는 이번 읽기에서 강조한 정책 변경의 소유이며 FLOW091 전체 변경 파일이나 모든 변경 기능의 완전한 목록이라는 뜻은 아니다. 이름·상하위 포함은 AI 제안이고 현재 수행할 확정 업무가 아니다.

기존 여섯 관계는 다음 조건까지 보존한다: 구상→배경 고정은 **명시 새 요청 때만**, 배경 고정→AI 입력과 →작업문은 **그 요청의 사본**, 작업문→저장·복구는 **내보내기 기록의 사본**, 저장·복구→파일 반환은 **일치하는 반환 식별자**, 배경 고정→일반 보고는 **정확히 연결된 대상 작업**. 이들은 원문 계약을 설명하는 관계이며 포함·실행 순서·자동 영향 전파선이 아니다. 전체 영향망이 아니므로 선이 없는 부분을 무관하다고 확정하지 않는다.

## 요약→실제 끝점→준비에서 막을 왜곡 세 가지

| 위험한 오독 상황 | 최소 문구 | 증거·대조 조건 |
|---|---|---|
| **접힌 ‘전달할 내용’의 변경 표시를 묶음 전체의 변경으로 승격.** AI 입력까지 바뀐 것으로 읽거나 그 묶음을 준비 대상으로 넘긴다. | ‘안의 작업문·미리보기에서 배경 분리 정책이 바뀜.’ | 접힘·펼침·집중에서 변경 표시는 같은 C32를 가리켜야 한다. 부모의 집계와 자식의 변경 소유를 구별하고, 준비 대상에 C31 또는 묶음 전체가 자동 추가되지 않는지 대조한다. 실제 모듈 소유라는 설명은 금지한다. |
| **집계선의 보이는 양끝을 실제 반환 대상으로 취급.** ‘결과 연결’ 한 덩어리로 줄이면서 일반 보고와 파일 반환의 서로 다른 대응 조건을 지우거나 최신 선택 작업에 붙인다. | ‘일반 보고는 연결된 작업, 파일 반환은 일치하는 반환 기록의 사본.’ | 기존 관계 식별자·종류·실제 끝점의 대응이 요약과 상세에서 같아야 한다. 두 경로의 조건을 각각 확인할 수 있어야 하며 옛 기록에 사본이 없으면 없음으로 유지한다. 집계는 새 관계나 모든 자식의 연결을 만들지 않는다. |
| **탐색·현재 구상·준비 편집을 명시 새 요청 또는 과거 기록의 갱신으로 취급.** C32를 골랐다는 이유로 최신 배경을 옛 작업에 채우거나, 제안 구성을 승인된 구현 범위로 적는다. | ‘이 부분의 확인·조정을 준비합니다. 기존 작업의 배경 사본은 그대로입니다.’ | 지도 선택·펼침·재내보내기는 F2의 새 요청이 아니다. 사본은 요청 대상 영역 하나이며 현재 지도 선택과 다르다. 준비문은 배경과 실행 범위를 구별하고 직접 수정 우선권을 유지한다. 실제 보내지 않은 준비를 전달·수락·완료로 표시하지 않으며 null이나 자료 부재를 ‘미결 승인 필요’로 바꾸지 않는다. |

이는 기존 의미가 축약 후에도 이어지는지 보는 조건이지 새 기능 목록이 아니다. cycle05 RESULT의 G1/G5 준비 가능 범위 정정도 유지한다. ‘묶음은 모두 준비 불가’라는 일괄 규칙을 새로 만들 필요는 없다. 기존 혼합 깊이·관계·준비를 다시 발명하거나 새로운 사건을 채우지 않고, 08의 간결한 기본 읽기를 적용할 때 위 세 경계만 대조하면 된다. 현재 UI가 이를 충족한다거나 사람이 이해했다는 판정은 아직 하지 않는다.
