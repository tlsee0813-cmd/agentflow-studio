## 바꿀 표현
1. 기본 화면은 진짜 공간 지도다. 5묶음의 공간 위치·이름·짧은 역할을 남기고, 전달할 내용 안의 두 자식 중 작업문과 미리보기가 강조된 변경 부분임을 보인다. 390×844 초기 화면에서 이 위치 관계를 읽을 수 있게 헤더/범례/노드 정보량과 반응형 배치를 조정한다. 다섯 이름만 나열한 목차로 대체하지 않는다. 모든 상세와 여섯 선 라벨의 동시 노출, 글자 축소만을 통한 맞춤은 요구하지 않는다. 필요한 관계 선/접힌 대표점은 지도에 남긴다. 초기 이름/짧은 역할은 화면에 실제 보이는 글자 기준으로 평가한다.
2. 기본 깊이 G2=접힘/G3=펼침/G4=접힘. 사용자가 각각 독립적으로 바꿀 수 있다. G3를 접어도 ‘안의 작업문과 미리보기 변경’이 남고 다른 자식까지 변경됐다고 표시하지 않는다. 새 미결을 만들지 않는다.
3. 노드 선택은 강조와 짧은 선택 설명을 바꾼다. 선택만으로 지도 카드 크기·배치·선 경로·깊이를 바꾸지 않는다. C32에는 짧은 역할, 이번 변화, 받은/넘긴 실제 관계의 일상어 이름, 준비 진입을 둔다. 내부 C32/R3/F1 같은 식별자와 검사 수가 기본 설명의 주정보가 되지 않게 한다. 긴 사실/근거/제약은 명시 상세에서 읽는다.
4. **관계 참고와 지도 선택을 분리한다.** C32 선택 설명의 받는 관계를 열면 C21→C32의 실제 이름·소속·전달 종류와 ‘명시 새 요청 때 고정한 그 요청의 사본’ 조건을 볼 수 있다. G2는 접힌 채이고 C32 지도 선택과 준비 대상은 그대로다. 참고창은 읽기용이다. 닫기 버튼/Escape는 본문을 실제 숨기고 호출 버튼으로 초점을 돌린다. 명시적으로 ‘지도에서 새 요청의 배경 고정 선택’ 같은 이름 있는 버튼을 눌렀을 때만 C21을 선택하고 G2를 펼칠 수 있다. 이동은 요청 송신/사본 갱신/변경 소유 이전/기존 준비 편집 전송이 아니다. 기존 직접 선 클릭의 typed relation/bundle 선택은 유지한다.
5. 단건 R3는 실제 양끝을 바로 볼 수 있고, G2/G3 모두 접힐 때 겹치는 R2/R3 묶음은 두 원래 관계를 구분해 선택한다. 집계선을 새로운 관계로 만들거나 G2전체를 실제 끝점으로 바꾸지 않는다. 기존 rep/bundles/drawEdges·data-rels·원래R1–R6와 ResizeObserver 원칙을 재사용한다.
6. 기존 명시 집중 읽기와 대상별 4필드 준비를 유지한다. 집중에서는 지도 대신 소속·복귀를 두어 읽기 공간을 확보해도 된다. 모바일에서 소속이 사라지는 기존 fpath 숨김은 보완한다. 기본 지도에 거대한 상세를 항상 고정하지 않는다. 준비는 보내지 않은 편집문이다. G1/G5도 원본대로 준비 가능하고 자식 있는 G2/G3/G4만 구체 자식을 고르게 한다. C32 편집을 C21에 재사용하지 않는다.
7. 진입 전 깊이/배율/mapScroll/mainScroll/typed선택/호출 초점·읽기 위치 복원과 준비 편집 보존을 분리한다. focusId와 지도 sel, view=map/focus, 기존 snapshot mainSt를 보존한다. 08의 3노드 고정치 fit/5필드/문자열 선택/이전이후 view를 복사하지 않는다. 배율 기능을 추가·수정하면 기존 단계 확대와 모순 없게 처리하고 증거를 남긴다. 새 전체맞춤 기능은 필수 아니다.

## 최소 실제 검증: 1280×720와390×844에서 같은 세 흐름
A. 초기/첫 선택: 새 페이지에서 초기 깊이와 실제 렌더링 확인. 이름·짧은 역할·C32 이름/변경 표시를 각 글자 Range, 조상 clip, 겹침/hit 관측으로 확인하고 PNG. 최초 무선택→C32 선택 전후 노드 bounds/선 path/깊이를 원시로 남겨 선택 자체가 크기를 바꾸지 않음을 확인한다. DOM에 존재/컨테이너만 안쪽이라는 이유로 글자가 보인다고 처리하지 않는다.
B. 관계 분기/참고: G3를 접어 변경 집계를 확인하고 실제 R2/R3 묶음 클릭→R3 선택→실제 C32 끝점 선택. G3만 다시 펼치고 G2/G4는 유지. C32 선택 설명에서 R3 참고를 열어 실제 C21/C32와 요청시점 조건을 관측한다. 닫기와 Escape 각각 실제 본문 hidden/화면 부재·focus복귀·C32선택/준비 대상 보존. 원래6관계의 ID/실제끝점/대표끝점 대응을 결과에 남긴다. 중복을 사전으로 제거하기 전 원래 ID 배열도 남긴다. 명시 C21 선택으로 이동하는 경로도 확인하되 이를 참고 유지 성공으로 혼동하지 않는다.
C. 비초기 복귀/편집: 기본과 다른 깊이 하나+실제로 변경된 배율을 만든다. 이동 가능한 지도/main스크롤에서 실제 이동 후 값 저장(이동할 여지가 없는 축은 사유·extent를 기록하고 움직였다고 주장하지 않는다). C32 집중→근거 참고 열닫기→준비에 식별 가능한 E 입력→닫기→지도복귀→재진입. 진입 직전/복귀 raw 상태·bounds·scroll·focus/읽기 위치를 비교하고 E는 별도로 남는지 확인한다. 1280에서 C21 준비와 격리도 확인. 복귀를 이전 준비문으로 되감으면 실패다. E 편집·재진입 뒤 기존 근거 참고를 한번 열고 닫아 E가 남는지도 확인한다. 편집 전 기본값끼리만 비교하지 않는다.

1440×900은 초기 조망/겹침만 보조 관측한다. 과거 검사 수를 반복·합산하지 않는다. actual child exit code와 외부 실행 수집자의 exit code를 기록하고, 항목 수는 실제 assertions만 센다. 실패 실행도 보존하고 원인/수정/재실행 범위를 구분한다. 동일 실행 source HTML SHA와 HTTP수령bytes/SHA, viewport, 원시값, PNG 파일을 연결한다. 검사 스크립트가 보는 속성만 통과해도 실제 본문 잔존/잘린 문구/다른 노드로 준비 이동이 있으면 실패다.
중요 기능/표현 결함은 직접 수정한 뒤 관련 흐름만 재검증한다. 무관한 디자인·새 기능을 추가하지 않는다. 이것은 작성자 검사이며 독립검증과 사람 사용성 검증은 별개다.
