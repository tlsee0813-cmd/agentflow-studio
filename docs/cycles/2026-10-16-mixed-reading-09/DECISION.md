# cycle09 선택과 근거
2026-10-16 구현 전 판단. 실행 상태는 [ACTIVE](../ACTIVE.md)에 모은다.

## 채택할 작은 흐름
cycle05의 공간 지도·독립 펼침·실제 관계를 유지하고, cycle08의 짧은 기본＋명시 상세를 적용한다. 전체의 다섯 역할과 변경 위치 → 전달할 내용만 펼친 상태의 작업문과 미리보기 → 접힌 요청 맥락 안의 실제 상대를 참고 → 선택 부분의 준비 → 진입 전 지도로 복귀한다. 기본 지도와 선택 설명을 간결하게 한다. 명시적으로 들어가는 집중 읽기에서는 기존처럼 공간을 확보하고 소속·복귀를 남긴다. 390 화면에 큰 지도를 영구 고정하여 상세 공간을 압박하지 않는다.

## 비교 후 바꾼 판단
[Pro A](https://chatgpt.com/c/6ad14ec4-7c30-83ee-88ed-494c789fb0a1)는 JupyterLab 목차와 Perfetto 트랙 고정을 비교해 다섯 역할 목차＋선택 상세를 추천했다. 총괄은 이 안이 공간 배치와 선을 잃는다는 자체 한계를 핵심 목적에 대조해 문자 목차 채택을 거절했다. Pro 후속은 그 추천을 철회하고 간결한 공간 지도, 선택 관련 선·접힌 대표점, 실제 끝점과 전달 종류의 대응을 제안했다. 전체 윤곽과 상세의 분리만 채택한다. 핀 복제·시간축·실행 중첩은 가져오지 않는다.

[Pro B](https://chatgpt.com/c/6ad14ee9-98ac-83ee-a198-6c86d267b78f)는 VS Code Peek의 참고/이동 구분과 Cytoscape expand-collapse의 실제 끝점/복수 선 구분을 비교했다. 기존 cycle05 관계 엔진을 유지하고 C32를 준비 대상으로 둔 관계 참고를 추천했다. 이를 채택한다. 직접 선을 고르는 기존 관계/묶음 선택은 그대로 두되, 선택 부분 안에서 ‘받는 배경 사본’을 참고할 때는 C32 선택·준비를 유지한다. 실제 C21로 지도 선택을 옮기는 버튼은 이름을 밝힌 별도 행동이다.

이것은 외부 코드의 선택 보존을 복사하는 일이 아니다. VS Code는 참고 내부 선택을 갱신하며 Cytoscape 선 접기는 선택을 해제한다. 우리 보존 조건은 별도 구현·검증한다. 원문 대조는 [정보량 감사](DENSITY_SOURCE_AUDIT.md), [관계 감사](RELATIONS_SOURCE_AUDIT.md). SDK를 도입하지 않는다.

## 의미와 표현
기본에는 다섯 보기용 묶음의 이름·짧은 역할, C32가 전달할 내용 안의 변경 부분이라는 표시를 남긴다. 원자료 식별자·검사 수·긴 제한 목록은 기본 지도의 주정보로 쓰지 않는다. 이 다섯 묶음은 AI 해석 제안이며 지도 선은 계약의 전달 관계이지 실행 순서나 변경 영향 전체가 아니다. C32 강조는 이번 읽기의 변경 주제이고 전체 개발 계약의 유일한 변경이라고 주장하지 않는다.

R3는 명시 새 요청 때 고정한 그 요청의 배경 사본을 전달한다. 지금 지도에 보이는 최신 구상을 가져오는 행동이 아니다. R4는 작업문에 넣은 사본의 내보내기 기록이며 전문 저장이나 외부 수락이 아니다. 접힌 G2 대표점과 실제 C21 끝점을 구별한다. 참고했다고 G2 전체가 수정 범위가 되지 않는다. C21로 명시 이동해도 C32 변경 소유와 C32 준비 편집은 C21에 붙여넣지 않는다.

## 무엇을 실제로 보았는가
총괄은 기존05를 1280×720/390×844에서 직접 조작·관측했다([기록](BASELINE_OBSERVATION.md)). 외부 자료는 공식 문서와 고정 코드 대조가 중심이다. 총괄은 [Perfetto 공식 정지 이미지](https://perfetto.dev/docs/images/debug-tracks/pivot-counter-tracks-results.png)의 트랙 행·핀 아이콘 배치와 [VS Code 1.93 공식 정지 이미지](https://code.visualstudio.com/assets/updates/1_93/ts-web-peek-refs.png)의 원 편집기 주변과 내부 미리보기·참조 목록 공존을 실제 열람했다. 핀/더블클릭/복귀 동작을 서비스에서 직접 실행한 것은 아니다. Pro UI의 모호한 ‘생성된 이미지’ 표시는 증거로 채택하지 않았다. Jupyter GIF 열람 실패, Cytoscape 과거 제보 이미지/현재 재현 한계를 별도 감사에 남긴다.

## 감수하는 손실과 이번 판정 범위
상세를 한꺼번에 펼치지 않으므로 더 읽으려면 명시 행동과 스크롤이 필요하다. 모바일에서 다섯 역할과 한 묶음의 자식을 공간적으로 배치하면 관계 선의 경로가 좁아질 수 있다. 글자를 과도하게 축소하거나 전체를 목차로 바꿔 성공 처리하지 않는다. 1280/390의 초기 글자·선·첫 선택·실제 끝점·준비/복귀를 실제 화면으로 검사한다. 사람 이해나 더 큰 프로그램 적합성은 이번 기술 검사로 확정할 수 없다. 최종 설계 확정이 아니라 다음 비교가 가능한 좁은 시안이다.
