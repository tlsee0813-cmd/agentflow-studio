## 반드시 지킬 상태 의미

- 복귀 상태는 탭 내 출발점 하나다. 프로젝트·실재하는 보기/선택/좌표/배율/읽기 위치/호출 초점을 돌려준다. 명시 변경한 이어갈 기록·저장한 수정은 되돌리지 않는다.
- 삭제·보관·다른 프로젝트 전환 등 출발점 무효 시 안전하게 상위 보기로 가되 다른 대상을 임의 선택하지 않는다. 기존 view 상태에 없는 새 상태 체계를 만들지 않는다.

## 2026-10-16 12:56 KST — 복귀 기준 보완 (fix2 실행 전)
독립 실행에서 영역 화면의 긴 구상을 펼친 뒤 편집하고 돌아오면, fix1은 펼침을 복원해도 호출 위치가 달라졌다. 두 PC폭 중1280은 창 y900→846으로 제한됐고1440은 y450이 그대로여도 호출 항목의 화면 y가−67.59px 이동했다. 읽기만 한 복귀는 두 폭 모두 회복됐다. 위쪽 내용의 정확한 변화 원인은 별도 DOM 대조 중이다.

복귀의 목적은 **읽던 자리를 되찾는 것**이다. 내용과 높이가 같으면 기존 창 스크롤 값을 유지한다. 명시적으로 이어가기·편집해서 내용 높이가 달라졌다면, 호출 항목의 화면 내 위치를 기준으로 스크롤을 보정하고 지도 자체 좌표·배율·선택을 유지한다. 현재 작업·수동값·새 상태 설명을 과거로 되돌려 높이를 맞추지 않는다. 임의 빈 여백이나 저장 스키마를 추가하지 않는다. 호출 항목이 없어졌거나 영역이 무효하면 기존 안전 복귀를 사용하고 다른 작업을 대신 선택하지 않는다.

검사는 복귀 직후 보조 스크롤 전에 호출 항목 rect·가시성·클릭 가능성·초점과 실제 창 y를 함께 기록한다. 내용 변화로 창 y가 달라진 사실을 숨기지 않으며, 정상 내용 변화와 시야 복원 실패를 구별한다. 같은 내용에서의 스크롤 보존 조건은 남는다. 작성자 지도 패널 경로와 독립 영역 화면 경로는 별개로 확인한다.

fix1의 전문 검사 실패 일부는 검사기가 새 전문 펼침을 열지 않은 조작 누락이었다. 원본 실패를 보존하고, 정상 클릭을 보완한 동일 검사 v2로 v0와fix1을 비교한다. 제품 누락과 검사기 오류를 합산하지 않는다.
