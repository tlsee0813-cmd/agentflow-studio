## 판단
[제품 후보 ce546a0](https://github.com/tlsee0813-cmd/agentflow-studio/commit/ce546a01091e5ec00e04aac328082a7296f1fc48)는 USE106에서 화면 코드·스타일·관련 검사 네 파일만 바꾼 첫 제품 연결이다. 작성자 검사를 통과했지만 아래 누락이 있어 아직 수용하지 않았다. 새 연구 HTML이나 전면 설계를 추가하지 않고 같은 흐름에서 좁게 고친다.

### 전문 접근 누락 — P2
선택한 작업의 이해·범위를 200자로 자른 뒤 전문을 펼칠 경로가 없다. 다음 행동·완료 조건 상세와 요청 원문은 나중에 저장한 수동 이해·범위의 전문을 대신하지 못한다. 특히 A를 읽고 현재 R에서 계속하는 경우, 작업 화면도 A 전문의 대체 경로가 아니다. 읽는 Task의 두 필드를 읽기 전용으로 펼쳐야 한다. Sol·Astra와 총괄이 코드를 대조한 발견이며 이 시점에 독립 브라우저 재현은 진행 전이다.

### 자동 검사 연결 누락 — P2
새 pc12_browser.py는 루트 verify.yml의 명시 실행 목록에 없어 기존 CI에서 실행되지 않는다. 기존 두 OS 환경·진입 정책을 유지하며 해당 검사만 연결한다. Windows 성공을 아직 주장하지 않는다.

### 펼친 구상에서 복귀 — 재현할 반례
긴 구상 전체보기를 펼쳐 아래 요청까지 스크롤한 뒤 떠나면, 복귀 때 details가 닫혀 창 높이와 읽던 위치가 달라질 수 있다. origin이 windowY만 기억하고 해당 펼침 상태를 보존하지 않기 때문이다. 실제 조작·수치로 재현한 뒤 필요한 보기 상태만 탭 메모리에 더한다. 정적 가능성을 확정된 실행 결함으로 세지 않는다.

## 유지할 부분
영역은 구상 읽기를 기본으로 하고 편집을 명시적으로 연다. 최근 보고를 자동 선택하지 않는다. 선택한 Task의 필드별 수동/AI·MOCK/낡아서 제외된 문구를 구별한다. 현재 R(parent A)에서 A를 이어가면 R을 유지하고, 다른 RB에서 A를 이어가면 A로 전환하는 기존 정책과 실제 manual 저장 경로가 유지된다. 기존 FLOW090 네 변경은 새 조작으로 이동한 것이며 원문 동등·미검증·R 유지 등 보호 판정은 남았다.

PNG 네 장은 실제로 열어 확인했다. 읽기 기본과 출처 구별은 보이나 큰 제목·상단 정보가 지도와 본문보다 많은 높이를 차지하는 부담은 남는다. 이번 결함 수정에 전면 재배치를 섞지 않는다. 사람의 이해나 부담 감소는 이 이미지·코드 검토만으로 입증되지 않는다.
