## GitHub 전달 경로

사용자가 GitHub 전달 전용 공간을 제안했다. 브라우저 GitHub 계정과 기존 연결 계정이 달라 새 저장소의 접근성을 가정하지 않고, 연결된 프로젝트에 `delivery/ui02-fix3-evidence` 브랜치와 `docs/transfer/ui02-fix3/` 경로를 만들었다. Cloud의 [원본 전달](https://github.com/tlsee0813-cmd/agentflow-studio/tree/9afe18444d92cf5930e0af5406ad7efce309d7c7/docs/transfer/ui02-fix3)이 완료됐다. Cloud에는 이 경로의 원본 증거와 별도 검증기 보완 업로드만 위임했다. 연구 브랜치 통합은 총괄이 담당한다. 실행 보고와 독립 감사가 같은 단계가 아니다.

향후에도 작은 결과는 전달 경로에 원본·버전·파일 해시·실행 범위를 함께 둔다. 같은 자료의 ZIP과 개별 파일을 불필요하게 중복 저장하지 않는다. 계정·키·다른 작업의 파일은 포함하지 않는다. 새 저장소가 반드시 필요한 크기·권한 조건이 생기면 그때 분리한다.
