# UI·UX59 · 부분의 현재 모습과 바꾸려는 모습

지도에서 부분을 선택하고, 같은 대상의 현재 설명과 바라는 모습을 가까이에서 읽도록 바꿨다. 홈에는 실제 구성을 드러내고, 지도에는 책임별 제목과 조밀한 부분 목록을 둔다. 내부 진입과 펼치기를 구별하며, 긴 기록은 필요할 때 연다. 입력 수집·출력 기능은 확장하지 않았다.

## 이번 선택

작성자와 분리한 Claude의 초기 시각 검토는 구매 매력을 반려했다. 꼬리표와 긴 문단만 늘고 읽기 면이 지도를 가린다는 지적을 채택했다. 여러 비교 카드를 동시에 놓은 후속 후보도 빈 공간과 숨겨진 설명 때문에 반려했다.

총괄과 Astra는 **실제 대상 이름으로 전체 범위를 알리고, 한 대상의 현재/의도를 비교하는 방식**을 선택했다. 공간이 충분하면 대상 곁에서, 부족하면 지도 공간을 확보한 비교 면에서 읽는다. 자료에 없는 구조나 관계를 만들어내는 제안은 채택하지 않았다. 선택 대상과 배율을 유지하고, 근거 왕복이나 수동 이동 뒤 복귀를 보정했다.

선택적 `presentation`은 실제 대상·인용·근거 참조를 검사한다. 없는 자료는 기존 설명으로 표시하며 새 구조를 실행하지 않는다. 인용의 형식 검증이 의미와 사실의 정확성을 보증하지는 않는다.

**이번 수정 배포는 전체 제품 완성이나 구매 가치 수용이 아니다.** 최종 Claude 후속 시각 판단은 아직 회수 전이며 사용자 품질 목표는 진행 중이다.

OSS 자체를 설치·실행하거나 전체 구조를 자동 이해한 결과가 아니다. 자동 지도 생성·실제 구조 변형은 구현하지 않았다. 비공개 키·운영 원문·전체 실행 로그는 이 폴더에 포함하지 않는다.
