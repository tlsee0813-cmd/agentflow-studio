## 알고 있는 것과 모르는 것
- README는 두 제한과 설정 예제, 알려진 제한을 설명한다. 이는 문서이며 실행 검사 결과가 아니다.
- 제공된 eval docstring은 MemoryLimitError와 TimeLimitError를 이미 구별해 명명한다. 두 오류의 식별 자체가 없다고 간주해 새 기능으로 만들지 않는다.
- 발췌된 본문은 parse→compile→VM 실행, 제한 인수 전달, 복사하지 않는 globals 공유, Python 결과 변환을 보인다.
- 예외의 세부 메시지/생성자, 전체 VM 구현, 호출자의 처리, 실제 런타임/검사는 발췌에 없다. 자료 미기재를 부재나 안전 보증으로 바꾸지 않는다.

## 한 번의 판정
실행 전 실제 UI가 보낸 전체 ask·맥락·정확 source·prompt·모델/한도와 해시를 동결하고, 일치한 요청 한 건만 제공자에 보낸다. 실제API와 화면 재생을 구별한다. 최대1회이며 첫 계약/의미 실패에서 원본을 남기고 중단한다. 원문·지시·모델·예산 변경, 재시도, 응답 수선, 첫 지도 생성은 하지 않는다.

지시어가 가리키는 평가 파이프라인과 실제 직접 변경 대상은 별도로 판정한다. 관련 제한/오류 부분을 다룬다고 곧 실패가 아니며 선택 ID 일치만으로 성공도 아니다. 이미 있는 두 예외 계약을 재사용하고 요청된 설명의 공백만 근거 있게 읽어야 한다. 기존 기능이면 변화 없음이나 확인 필요도 허용한다. eval 순서·globals 공유를 바꾸는 추가 작업을 만들지 않는다.

응답을 수용할 수 있을 때만 정상 제품 경로에서 같은 응답을 읽는다. 비교면의 현재 근거·바라는 결과·미확인을 구별하고 필요한 원문 한 번 왕복 후 같은 초안/선택/범위로 돌아오는지 확인한다. 새 코드 실행·요청 전달·반환 보고로 넓히지 않는다.

## 현재 상태
실제 제공자 호출은0이다. 검토자 작성 0항목 응답의 오프라인 거절을 확인했고, 정당한 ‘제안 없음’을 읽을 계약·화면·보존 경계를 먼저 수리한다. 이 수리의 검증 뒤 정확 ask/source/prompt를 동결한다. 작은 연결이 통과하더라도 일반 정확도·첫 지도 품질·전체 제품 완성으로 판단하지 않는다.
