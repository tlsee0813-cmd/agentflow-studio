‘설문 응답 정리’ 영역의 첫 작업을 해 주세요.
목표: 로컬 CSV 설문 응답을 읽어 응답자ID·시간·응답 열을 확인할 수 있는 정리된 결과를 얻는다.
이번 범위: 로컬 CSV 파일을 읽어 응답자ID, 시간, 응답 열이 어떻게 들어 있는지 확인하고, 응답 건수와 응답자별 응답 목록(같은 응답자ID가 여러 번 나오는 경우 포함)을 보여준다. 중복 응답을 제거·선택·변경하는 처리는 하지 않고, 중복이 되는 응답자ID가 있는지와 몇 건인지만 탐지해 보고한다. 원본 파일은 수정하지 않는다. 확정 결정 D2에 따라 로컬에서만 처리한다.
완료 조건: 결과의 전체 응답 건수가 CSV에서 읽은 행 수와 일치한다. 응답자별로 묶인 응답의 합이 전체 응답 건수와 같다. 중복으로 보고된 응답자ID의 건수와 실제 반복 횟수가 일치한다. 원본 CSV 파일의 내용·수정 시간이 그대로다.
아직 정하지 않은 것 (임의로 정하지 마세요): 중복 응답 처리 정책(제거·선택·유지 중 무엇을 할지)은 아직 정하지 않았으므로 이번 초안에서는 정하지 않는다.
AI가 정한 기본값 (사용자 결정 아님 · 바꿀 수 있음): 결과는 화면에 표로 보여주고 필요하면 정리된 CSV로 내보낸다. / 응답자별 묶음은 응답자ID 기준으로 정렬한다. / 시간 열은 원본 형식을 그대로 표시한다. / 중복 탐지는 응답자ID가 두 번 이상 나오는 경우로 판단한다.
