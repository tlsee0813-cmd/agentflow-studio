‘연습 결과’ 영역의 첫 작업을 해 주세요.
목표: 연습에서 나온 박자 시각과 그에 대응하는 키 입력 시각을 나란히 보여줘, 사용자가 각 입력이 박자에 얼마나 가까웠는지 차이를 스스로 이해할 수 있게 한다.
이번 범위: 이번에 할 것: 연습 1회분에 대해 박자 시각 목록과 각 박자에 대응하는 키 입력 시각을 짝지어 표시하고, 각 짝의 시간 차이(밀리초)를 함께 보여준다. 입력이 없는 박자는 입력 없음으로 표시한다. 이번 직접 지시는 없고 앞선 질문에 대한 답에서 허용오차를 아직 정하지 않는다고 했으므로, 성공/실패 판정이나 허용오차 값은 만들지 않는다. 대응 규칙 등 세부는 defaults를 따른다. 하지 않을 것: 성공/실패 판정, 허용오차 값 지정, 점수·등급·요약 통계 산출, 개인 연습 기록 저장, 네트워크 사용.
완료 조건: 박자 시각과 키 입력 시각이 각각 짝지어 표시되고, 각 짝에 시간 차이가 밀리초로 함께 보인다. 입력이 없는 박자는 입력 없음으로 보인다. 화면 어디에도 성공/실패 판정이나 허용오차 값, 점수·등급이 나타나지 않는다. 표시된 항목 수가 연습에서 발생한 박자 수와 일치한다. 저장된 기록이나 네트워크 호출이 없다.
아직 정하지 않은 것 (임의로 정하지 마세요): 성공/실패 판정과 허용오차 값은 사용자가 아직 정하지 않음(이번 요청에서는 판정 없음).
AI가 정한 기본값 (사용자 결정 아님 · 바꿀 수 있음): 대응 규칙: 각 박자에 대해 그 박자 시각 이후 가장 가까운 키 입력 하나를 짝짓고, 이미 짝지어진 입력은 다시 쓰지 않는다. / 시간 차이는 부호 있는 밀리초(예: +35ms, -40ms)로 표시하고, 이른 입력은 음수로 표시한다. / 박자 시각과 키 입력 시각은 밀리초 단위, 소수점 없이 표시한다. / 짝 목록은 박자 시각 오름차순으로 정렬한다. / 한 화면에 목록으로 표시하고, 시각 비교를 위해 박자 시각과 입력 시각을 같은 열에 나란히 둔다.
