# 공통 과업과 운영 기록

다섯 평가자는 새 에이전트로 전체 대화 이력 없이 생성했다. 공통 과업 문장은 동일했고 역할 문장만 각각 초보(코딩 경험 거의 없음), 주니어(작은 단일 기능), 미들(여러 기능·변경 관리), 시니어(기존 코드·제약), 스태프/리드(병렬 작업·인계)였다.

> 작은 합성 프로젝트 ‘소규모 공방 예약 안내’(결제·회원은 아직 미정)를 만들고 첫 요청을 정리해 외부 개발 도구에 전달할 자료를 찾는다. 이후 네 경험 수준대로 영역 하나 추가, 기존 요청 확인, 새 요청과 이전 결과 구분, 중단 후 돌아오기, 실수한 기록 안전 복구/정리를 시도한다. 클릭 순서는 스스로 UI로 결정한다. 실제 외부 도구에 보내거나 AI API를 호출하지 않는다. 자동 실행 여부에 대한 자신의 기대와 UI 관찰을 기록한다. 12~20 행동 또는 명백한 막힘에서 종료하고, 예상/관찰/재현과 목표 완료/부분/미도달 및 도움 필요를 구분한다.

앱 소스·개발문서·테스트·다른 평가 기록·다른 프로필을 읽지 말도록 했다. 역할별 새 프로필 경로, 전용 제어 포트, UI 도구의 일반적인 selector와 동작 형식, 화면·트리의 한계, 로컬 정적 배포 대체의 이유만 기술 안내했다. 앱의 UI 명칭이나 클릭 순서는 제공하지 않았다. 보고서는 각자 폴더에 작성하도록 했다.

| 역할 | 모델/추론 요청 | 프로필 | 제어 포트 |
|---|---|---|---:|
| 초보 | gpt-6.1-sol / high | novice | 8801 |
| 주니어 | gpt-6.1-sol / high | junior | 8802 |
| 미들 | gpt-6.1-sol / high | middle | 8803 |
| 시니어 | gpt-6.1-sol / high | senior | 8804 |
| 스태프/리드 | gpt-6.1-sol / high | staff | 8805 |

모두 spawn 도구에서 수락됐다. backend 모델을 별도 조회하지 않았고 대체 모델도 사용하지 않았다. 단순 환경 정리 에이전트는 gpt-6-luna / max. 종합 비평은 새 gpt-6.1-sol / high 에이전트에 한 번 요청했고 수락됐다. 두 표현 보정을 반영한 뒤 종료했으며 두 번째 리뷰는 하지 않았다.

도구는 `/workspace/work/use105/profiles/<role>`을 각자 생성했고 기존 로그인 프로필을 사용하지 않았다. 애플리케이션의 origin은 같아도 브라우저 프로필이 달라 스토리지가 분리된다. 파일시스템 전체는 공유하므로 보안 장벽은 아니다. 다른 평가 자료를 읽지 않았다는 각 평가자의 진술과 폴더별 조작 기록이 근거이며, OS 수준의 접근 감사는 하지 않았다.

총괄은 환경 확인·반응형 점검·사후 재현용으로 environment_check, confirmation_check, purpose_check 프로필을 따로 사용했다. 역할 평가가 끝난 뒤에만 목적 저장 현상과 확인창을 재현했다. 결과를 역할 평가자에게 정답 경로로 되돌려주지 않았다.

후속 전달은 기술 보정으로 한정했다. 미들·시니어·스태프에 native confirm/prompt 자동 취소 사실을 전달해 앱 무반응 판정을 금지하고 미검증으로 남기게 했다. 주니어에도 같은 보정을 알렸지만 해당 세션은 확인창 조작이 없었다. 시니어는 17행동에서 종료했고 다른 역할은 20행동이다. 초보는 종료 전 보정을 받지 않았고 확인창 조작도 없었다. 미들 보고서의 ‘전체 문맥 상속’ 추정 문장 한 곳은 실제 fork_turns none 실행 기록에 맞춰 메타데이터만 정정했다. 평가 행동을 다시 시키지 않았다.

`tools/browser.py`는 첫 사용에 사용한 원래 도구다. `tools/browser-confirm.py`는 사후 재현용 확인창 기록 변형이며 첫 사용 결과에 소급 적용하지 않았다. 스크립트의 절대 경로는 당시 임시환경 위치다. 실행 시 Chromium·Playwright와 localhost 소켓 실행 권한이 필요하며, 저장된 프로필·쿠키는 보고서에 포함하지 않는다.
