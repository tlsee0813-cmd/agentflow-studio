(103파일), runtime fingerprint는 `546bd875c4556613aebb97c800bc1bd4a2e3e52870c62c73f691b2c1895a8224`다.
앱 밖에 진입 문서와 시제품을 추가했으므로 저장소 전체 지문이 이 원본 지문과 같다는 뜻은 아니다.

관련 계약은 [INIT009 CONTRACT](../app/docs/init009/CONTRACT.md), 과거 대화 품질 관찰은
[INIT008 ACTUAL_QUALITY](../app/docs/init008/ACTUAL_QUALITY.md)에 있다. 각 단계의 제출 시점 문서는 역사 기록이다.

독립 코드/패키지 검토에서 INIT009의 실질 차단 결함은 없었다. Windows Node22.16.0/npm10.9.2에서

동기화 때 새 타입검사·빌드와 IDEA013 구조12검사가 통과했다. 첫 루트 배치의 전체 Node278검사는

나머지276검사는 같은 제품 바이트로 이미 통과했다. 이후 최종 배치 커밋 `c6dc5ea44de628583ae5f34cccadc7c2a398c2e2`의 [GitHub Actions 38123052025](https://github.com/tlsee0813-cmd/agentflow-studio/actions/runs/38123052025)가 completed/success로 완료됨을 GitHub API로 확인했다.

## 탐색 작업

[IDEA012](../prototypes/idea012-rehearsal/README.md)는 대기예약의 해석 차이를 체험하고 선택한
고객 결과를 다음 변경에 재사용하는 두 파일짜리 시제품이다. 기존 앱과 연결되지 않았고,
준비된 모의 불일치 장면은 실제 코드에서 탐지한 결함이 아니다. 좁은 독립 소스 검토에서
중요 결함은 없었다. 작성자의 클릭 검사와 독립 실제 앱 검증은 구분한다.

[IDEA013](../experiments/idea013/README.md)은 강한 기본 프롬프트와 개선안을 비교한 독립 실험이다. 개발6사례와 별도4사례의 첫20회 및 명시적 합성 답변 후속4회, 총24회 실제 deepseek-flash 호출을 완료했다. 모두 HTTP200/stop, 재시도 없음. 첫 구조·출처 검사 기본안7/10·개선안8/10, 후속각2/2이며 의미 품질 합격이나 사용자 효용 입증은 아니다. [실제 비교 결과와 한계](research/idea013-results.md)를 참조한다.

[IDEA014 rev1](../experiments/idea014/README.md) 실행자료를 준비하고 Cloud에 전달했다. 명시 요청과 기존 확정을 구분하며, 요청자가 명확히 기존 결정을 바꾸라고 지시한 경우 재승인을 강제하지 않도록 수정했다. 작성자는 Node22.16에서 구조24검사 통과를 보고했고, 별도 좁은 검토에서는 해당 변경·시험답변 경계9검사를 확인했다. 이는 모델의 자연어 의미 품질을 보장하지 않는다.

Cloud는 첫28회·후속4회 실제 호출을 완료했다. 첫 응답 계약검사는 기본11/14·개선14/14, 후속각1/2다. 개선안에도 임의 보류·과다 질문·미제공 필드·시험답변 출처 문제가 남았다. 총괄은 최종보고와 표시된 결과 JSON을 확인했고 전체 원문은 회수 중이다. [결과와 한계](research/idea014-results.md)를 참조한다. 새4사례는 실행 전 Pro에 공개하지 않았으며 모두 합성 사례다. [공유 범위](../experiments/idea014/REPOSITORY_SCOPE.md)를 참고한다.

IDEA015는 기준 소스 다운로드가 Git DNS 오류로 막혀 문서 검토 뒤 중단됐다. 총괄이 기준 커밋 `b7db1324794341075b64065cb43464b2bee19415`의 추적 파일145개를 단일 폴더 ZIP으로 전달해 같은 Pro 세션을 재개했다. app/ 원본103파일의 파일별 해시 일치를 확인했다. 구현 결과·새 검증은 아직 없다.

흐름은 자유 요청 → 필요한 확인·선택 → 실행 도구용 인계 → 결과·다음 변경 이어받기다. [Claude의 완료된 독립 제품 검토와 총괄 판단](research/idea015-product-review.md)을 재개 지시에 반영했다. 실제 사용자 평가나 제품 방향 확정은 아니다. Cloud는 IDEA014 텍스트와 주요 실패 원문 발췌를 반환했고 현재 대기 중이다. 총괄은 발췌를 읽었지만 전체32응답의 로컬 파일 회수는 앱 다운로드 제약으로 완료하지 못했다.

제품 방향은 탐색 중이다. 작은 고객 흐름의 반복 사용 가치와 더 단순한 기존 도구 절차를 함께 비교한다.
