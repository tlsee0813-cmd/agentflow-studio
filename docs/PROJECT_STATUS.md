## 탐색 작업

[IDEA012](../prototypes/idea012-rehearsal/README.md)는 대기예약의 해석 차이를 체험하고 선택한
고객 결과를 다음 변경에 재사용하는 두 파일짜리 시제품이다. 기존 앱과 연결되지 않았고,
준비된 모의 불일치 장면은 실제 코드에서 탐지한 결함이 아니다. 좁은 독립 소스 검토에서
중요 결함은 없었다. 작성자의 클릭 검사와 독립 실제 앱 검증은 구분한다.

[IDEA013](../experiments/idea013/README.md)은 강한 기본 프롬프트와 개선안을 비교한 독립 실험이다. 개발6사례와 별도4사례의 첫20회 및 명시적 합성 답변 후속4회, 총24회 실제 deepseek-flash 호출을 완료했다. 모두 HTTP200/stop, 재시도 없음. 첫 구조·출처 검사 기본안7/10·개선안8/10, 후속각2/2이며 의미 품질 합격이나 사용자 효용 입증은 아니다. [실제 비교 결과와 한계](research/idea013-results.md)를 참조한다.

[IDEA014 rev1](../experiments/idea014/README.md) 실행자료를 준비하고 Cloud에 전달했다. 명시 요청과 기존 확정을 구분하며, 요청자가 명확히 기존 결정을 바꾸라고 지시한 경우 재승인을 강제하지 않도록 수정했다. 작성자는 Node22.16에서 구조24검사 통과를 보고했고, 별도 좁은 검토에서는 해당 변경·시험답변 경계9검사를 확인했다. 이는 모델의 자연어 의미 품질을 보장하지 않는다.

Cloud는 첫28회·후속4회 실제 호출을 완료했다. 첫 응답 계약검사는 기본11/14·개선14/14, 후속각1/2다. 개선안에도 임의 보류·과다 질문·미제공 필드·시험답변 출처 문제가 남았다. 총괄은 최종보고와 표시된 결과 JSON을 확인했고 전체 원문은 회수 중이다. [결과와 한계](research/idea014-results.md)를 참조한다. 새4사례는 실행 전 Pro에 공개하지 않았으며 모두 합성 사례다. [공유 범위](../experiments/idea014/REPOSITORY_SCOPE.md)를 참고한다.

IDEA015 첫 구현 ZIP을 회수했고 Opus 5.5 High 코드 리뷰와 Cloud 실행 검증을 병렬 배정했다. 기준145파일을 보존하고 `app/continuity/`에22파일을 추가했다는 작성자 보고이며, 새 코드는 아직 이 저장소에 반영하지 않았다. 입력 ZIP SHA256은 `6bf9bdd41f55164a80cdd6ef355f045809024749f1f3b1ed1b2394ac5946a046`이다.

흐름은 자유 요청 → 필요한 확인·선택 → 실행 도구용 인계 → 결과·다음 변경 이어받기다. 브라우저 자동 저장·JSON 백업 복구와 별도 서버 진입점이 포함된다. 기존 설정·오류·제한·정적 파일 처리 등을 재사용하며 기존 화면과 평가기·gate는 변경하지 않았다고 보고됐다.

작성자 자체검사: 신규 상태·HTTP·제공업체32/32, 기존 관련141/141 및 I9.01/I9.02 두 검사 통과. DOM8/8은 HTTP·저장소 대역을 사용했으므로 직접 브라우저 통신·CSP·실제 저장 지속성을 입증하지 않는다. 클린 npm ci는 캐시 부족으로 실패했고 기존 전체 npm test는 시간제한으로 중단됐다. 이 미완료 검증을 Cloud에 배정했으며, 실제 DeepSeek 연결·품질은 아직 IDEA015에서 검증하지 않았다.

Opus는 같은 ZIP의 독립 리뷰와 재현 가능한 결함의 최소 수정을 담당한다. Cloud는 원본을 변경하지 않고 클린 설치·전체검사·실제 Chromium 통신/재방문/백업복구를 모의 AI로 검증한다. Pro는 산출물 반환 후 대기한다. [완료된 제품 검토와 총괄 판단](research/idea015-product-review.md)은 설계 참고이며 사용자 효용 입증은 아니다.

IDEA014 주요 원문 발췌는 읽었지만 전체32응답의 로컬 파일 회수는 앱 다운로드 제약으로 완료하지 못했다. 과거 실험과 이번 구현 검증은 별도 기록이다.

제품 방향은 탐색 중이다. 작은 고객 흐름의 반복 사용 가치와 더 단순한 기존 도구 절차를 함께 비교한다.
