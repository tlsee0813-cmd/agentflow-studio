# IDEA-013 무상 구조검사 결과

**범위:** 새로 만든 실험 요청 묶음의 로컬 구조검사. 작성한 Pro 세션에서 수행했으며 독립 리뷰가 아니다.

환경: Linux, Node v22.16.0. 외부 패키지 설치 없음.

| 실제 수행한 항목 | 결과 |
|---|---|
| `node --check scripts/assemble.mjs` | 통과 |
| `node --check scripts/structure.test.mjs` | 통과 |
| `assemble.mjs initial`로 개발용 요청 파일 생성 | 6사례 × 2전략 = 12행 |
| `node --test scripts/structure.test.mjs` | 12 tests / 12 pass / 0 fail |

구조검사에서 확인한 내용: 6개 입력의 형태와 출처 ID, 예약 사례 제외, 쌍별 동일 user 데이터와 공통 출력 계약, 서로 다른 두 전략, 사전 조립 파일과 코드 결과 일치, 평가용 추가 필드·중복 ID·미확정 잠금 거절, 고객 문자열의 user 메시지 보존, 세 출력 경로의 형태, 잘못된 인용·출처 거절, 후속 assistant 원문 보존, 미제공 답변·질문 불일치·잘못된 JSON 거절, 원본 변경·두 번째 후속 거절, 시험답변과 실제 고객답변의 상태 구분, 보류·모르겠음 상태, CLI의 기존 출력 덮어쓰기 거절.

테스트 안의 입력·assistant 응답·답변은 **합성 구조 fixture**다. 실제 DeepSeek 응답이나 실제 고객답변이 아니며 모델 요청 파일에 포함되지 않는다. 검사기는 문장이 실제로 인용에서 도출되는지, 중요한 충돌을 모두 찾는지, 장면이 균형 있는지를 자동 판정하지 않는다.

**실행하지 않은 것:** DeepSeek/API 호출, 모델 가용성·생성 품질 평가, 별도 미공개 4사례 확인, 실제 앱/브라우저 검사, 사용자 조사, 기존 제품 수정·통합, 원격 쓰기·배포. 비밀키를 요청하거나 사용하지 않았다. Cloud에서의 응답 저장·재시도 비활성화는 인계 지시이며 이 로컬 검사로 실행 확인한 것이 아니다.
