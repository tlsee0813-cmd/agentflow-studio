# 저장소 공유 범위

이 디렉터리는 Pro의 IDEA014 rev1 실행 자료 중 새 소스·프롬프트·계약·개발 입력·검사·분석 문서를 보존한다. 기존 앱과 IDEA013 자료를 변경하지 않는다.

원본 ZIP의 `reference/` 과거 전사본과 검사 로그는 중복 게시하지 않았다. CAUSES.md의 `reference/...`와 `R:L` 표기 및 REV1_CHECK.md의 로그 경로는 원본 ZIP을 가리키므로 이 저장소만으로 과거 화면 전사 재검사를 재현할 수 없다. 작성자 보고와 독립 검토 범위는 docs/PROJECT_STATUS.md에서 구분한다.

새 독립4사례와 평가 메모는 공개하지 않았다. 준비된20요청은 기존10사례의 요청이며, Cloud에서 별도4사례를 추가한다. 실제 실행 결과와 사용자 효용을 입증한 자료가 아니다.
