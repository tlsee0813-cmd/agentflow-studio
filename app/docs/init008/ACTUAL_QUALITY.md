**작게 포함한 개선 후보:** 실제 source ID 표와 답변→sourceId 연결 안내, 불필요한 placeholder 제거,
현재 결정은 구조화 항목에서 요약하고 AI 자유문장은 별도 원문으로 분리한다. 이미 제공된 핵심은

**미검증:** 새 prompt의 실제 ID 오류 감소율, 질문 부담 감소, 초안 충실성·한국어 자연스러움,

그 출처가 내용을 지지함을 증명하지도 않는다.
