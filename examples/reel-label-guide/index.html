reel board 리본 라벨 → 빌드 대상 안내

화면 리본 케이블에 적힌 라벨을 입력하면 고정 문서 판본에 적힌 화면·컨트롤러·드라이버·보드 지정을 함께 보여 줍니다.

리본 라벨 입력

라벨 전체를 대소문자·하이픈까지 그대로 입력하세요. 앞뒤 공백만 무시합니다. 일부만 맞거나 대소문자가 다르면 대상을 추정하지 않고 확인이 필요하다고 알려 드립니다.

문서에 있는 라벨:

PCB 버전(예: 1507.1, 1507.2)으로는 대상을 고르지 않습니다.

입력하는 즉시 결과가 바뀝니다. Esc로 입력을 지웁니다.

기준:

제공된 고정 문서 판본의 표를 보여 줄 뿐이며, 현재 유통 중인 보드나 실제 기기에서 확인한 결과가 아닙니다. 이 도구는 빌드·플래싱을 실행하지 않고 보드에 접근하지 않습니다.

조회 결과

확인 필요

입력한 라벨:

화면 모델 Display
— 리본 라벨에 대응하는 전자잉크 화면
컨트롤러 Controller
— 화면에 들어 있는 구동 칩
드라이버 Driver
— Zephyr 디스플레이 드라이버
보드 지정 Board Designation
— 애플리케이션 빌드 때 사용할 보드 지정
